# CHEMVERSE AI — демо тексеру тізімі

Сайт: **https://chemverse-ai.vercel.app** · Сценарий: BLUEPRINT 14-бөлім (5 минут) · Резерв: 14.1-бөлім

> Басып шығарып, сахнаға алып шығыңыз. Әр жолдың қасына ✓ қойып отырыңыз.

---

## 1. Бір күн бұрын

- [ ] **Демо деректер жаңартылды:** `npm run seed:demo` (8А сыныбы, нәтижелер, тапсырмалар, ҚМЖ, QR)
- [ ] **AI жауаптары кэштелді:** `npm run cache:ai`
- [ ] **AI жауаптарын оқып тексердім:** `docs/demo/ai-answers.md` — әр жауапта ☐ → ☑ (қате болса түзетеміз)
- [ ] **QR карточкалар басып шығарылды:** мұғалім → `/kk/teacher/qr` → «Басып шығару» (H₂O, CH₄, CO₂, NH₃, бензол, кофеин, O, Na, ҰБТ)
- [ ] **Слайдтағы QR:** H₂O AR QR-ын (`/kk/teacher/qr`-дағы) скриншотпен слайдқа қойдым, телефонмен сканерлеп тексердім
- [ ] **Резерв видеолар** (әрқайсысы 20–30 сек), слайдқа салынды:
  - [ ] QR → AR молекула үстелде (телефон экранын жазу)
  - [ ] Қол қимылымен молекуланы айналдыру / шымшу / жұдырық
  - [ ] AI мұғалімнің қазақша жауабы
  - [ ] Live сабақ: телефондар қосылады, диаграмма өседі
  - [ ] AI ҚМЖ генераторы
- [ ] **Телефонда:** APK орнатылған (`dist\chemverse-ai.apk`) немесе Chrome → «Басты экранға қосу»
- [ ] **Репетиция №1 / №2 / №3** (таймермен, 5 минут)

## 2. Демоға 30 минут қалғанда

- [ ] Ноутбук пен телефон **толық зарядталған**, HDMI/USB-C адаптер, зарядтағыш
- [ ] **Жеке мобильді интернет (hotspot)** қосулы — залдағы Wi-Fi-ға сенбеңіз
- [ ] Ноутбукта **демо мұғалім** болып кірдім: `/kk/demo` → «Мұғалім»
- [ ] Ноутбукта мына қойындылар **ретімен** ашық:
  1. Слайдтар (презентация)
  2. `/kk/molecules/h2o` — 3D су молекуласы
  3. `/kk/gesture-lab` — камераға рұқсат берілген, қол танылады
  4. `/kk/ai-tutor` — бос чат
  5. `/kk/teacher/live` — **сессия ашылған, лоббиде тұр** (5 сұрақ, 20 сек), «Үлкен экран» дайын
  6. `/kk/teacher/lesson-studio` — тақырып жазылып тұр: «Химиялық байланыс түрлері»
  7. `/kk/teacher/classes/…` — 8А сыныбы (әлсіз тақырыптар, нәтижелер)
- [ ] Камера: **жарық жақсы**, артқы фон біркелкі, қол толық кадрға сыяды
- [ ] Дыбыс өшірулі, хабарландырулар өшірулі (Windows: «Назар аудару» режимі)

Пилот болса — тек нақты сандар (BLUEPRINT 15-бөлім): «N оқушы, орташа балл X → Y».

## 5. Жиі кездесетін ақаулар

| Белгі | Себебі | Шешімі |
|---|---|---|
| AI «жауап бере алмады» | Gemini лимиті не интернет | Кэштегі сұрақты қойыңыз (жауап бірден шығады) |
| Live-та аттар келмейді | Realtime үзілді | 4 секундта өзі жаңарады; болмаса бетті жаңартыңыз |
| Камера ашылмайды | Рұқсат жоқ / басқа бағдарлама қолданып тұр | Chrome адрес жолындағы 🔒 → Камера → Рұқсат беру; Zoom/Teams жабу |
| AR батырмасы жоқ | iPhone/Android ескі не AR қолдамайды | 3D режимінде көрсетіңіз → видео №1 |
| Демо кіру қатесі | Supabase баяу | 10 сек күтіп қайталаңыз; болмаса алдын ала кірген қойындыны қолданыңыз |
| Сайт мүлде ашылмайды | Интернет | Hotspot → болмаса барлығы видеомен |
