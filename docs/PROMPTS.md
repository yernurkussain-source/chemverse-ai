# Claude Code-қа күн сайын жіберетін хабарламалар

Әр күні жаңа сессия ашып (Claude панеліндегі «New session»), сол күннің хабарламасын көшіріп жіберіңіз.
Claude Code `CLAUDE.md` файлын өзі оқиды. Үлкен тапсырма алдында төменгі жақтағы режимді **Plan** етіп қойсаңыз, Claude алдымен жоспар көрсетеді — оқып, «Accept» басыңыз.

---

## 1-күн · Foundation
```
@CLAUDE.md @docs/BLUEPRINT.md @design/prototype.html оқып шық.
Бүгін 1-күн: Foundation. Мына папкада Next.js жобасын құр (TypeScript, Tailwind, App Router, src/ папкасы, ESLint).
Ескерту: папкада CLAUDE.md, docs/ және design/ бар — create-next-app «папка бос емес» десе, жобаны уақытша папкада жасап, файлдарды осы папкаға көшір, менің файлдарымды өшірме.
Содан кейін:
1) prototype.html-дегі түстерді (ашық + қараңғы режим) және қаріптерді Tailwind theme-ге көшір, режим ауыстырғыш батырма жаса;
2) shadcn/ui орнат;
3) next-intl қосып, kk (әдепкі) және ru тілдерін жаса;
4) жоғарғы мәзір (компьютер) және төменгі навигация (телефон) жаса;
5) prototype.html-дегі басты бетті React компоненттерімен қайта жаса (3D бөлігін әзірге орын ретінде қалдыр);
6) git init жасап, бірінші commit жаса.
Соңында қалай іске қосып, нені тексеру керегін айт.
```

## 2-күн · Auth + деректер базасы
```
2-күн: Supabase қосамыз. Алдымен маған Supabase-те жоба ашу және кілттерді .env.local-ға салу жолын қадамдап түсіндір, мен дайын болғанша күт.
Содан кейін: BLUEPRINT 8-бөліміндегі кестелер үшін SQL миграциялар (RLS-пен), login/register беттері, /demo (бір батырмамен демо аккаунтқа кіру), onboarding (рөл: оқушы/мұғалім, сынып), seed деректер: 5 тақырып, 50 тест сұрағы (химия 8–11 сынып, қазақша, мен кейін тексеремін).
```

## 3-күн · 3D молекулалар + периодтық кесте
```
3-күн: 3D Molecule Engine. 3Dmol.js-пен /molecules (каталог) және /molecules/[id] беттері.
10 молекула: H2O, CO2, CH4, NH3, C2H5OH, бензол, NaCl, H2SO4, глюкоза, кофеин — SDF файлдарын PubChem-нен жүктеп public/molecules/sdf ішіне сал.
Атомды басқанда — элемент аты (қазақша), массасы. Шар-таяқша / көлемді стиль. Басты беттегі 3D орнын осы компонентпен алмастыр.
Сонымен қатар /periodic-table: интерактивті кесте, элементті басқанда ақпарат.
```

## 4-күн · Қол қимылы + AR
```
4-күн: /gesture-lab — MediaPipe Hand Landmarker арқылы камерадан қолды тану. Қимылдар: сұқ саусақ — айналдыру, шымшу — zoom, жұдырық — келесі молекула, ашық алақан — тоқтату. Бұрышта камера терезесі мен қол нүктелерін көрсет. Камераға рұқсат сұра, рұқсат болмаса тышқанмен басқару қалсын.
Содан кейін AR: scripts/sdf-to-glb.ts (SDF → GLB, Three.js GLTFExporter), /ar/[id] беті model-viewer-мен. Телефонда қалай тексеретінімді түсіндір.
```

## 5-күн · QR + ҰБТ тесті
```
5-күн: QR жүйесі (BLUEPRINT 6-бөлім): /teacher/qr — QR жасау және басып шығаруға бет; /q/[token] — серверде тексеріп бағыттау; /scan — телефон камерасымен QR сканер.
Содан кейін Exam Engine: /exam/unt, /exam/session/[id] (таймер), /exam/result/[id] (тақырып бойынша әлсіз жерлер). Бағалау тек серверде.
```

## 6-күн · AI мұғалім
```
6-күн: /ai-tutor. Vercel AI SDK, стриминг жауап, KaTeX формулалар. RAG: rag_documents кестесі (pgvector) және scripts/seed-rag.ts — docs/rag/ папкасындағы менің материалдарымды жүктейді (папканы жаса, мен мәтін салам).
Жүйелік нұсқау: тек химия, қазақша, қадамдық, дереккөз көрсет. Rate limit қос. Қай AI провайдерін таңдау керегін және кілтті қайдан алатынымды түсіндір.
Уақыт қалса: /scan ішінде ChemScan (есептің суретін AI-ға жіберу).
```

## 7-күн · Виртуалды зертхана + мұғалім кабинеті
```
7-күн: /virtual-lab/titration — prototype.html-дегі титрлеу зертханасын React-қа көшір (Recharts немесе canvas), нәтижені lab_attempts-қа сақта.
Содан кейін /teacher: сыныптар (join code), тапсырмалар, /teacher/lesson-studio — AI ҚМЖ генераторы (JSON schema → бет → PDF экспорт).
```

## 8-күн · Live сабақ
```
8-күн: Live Class. /teacher/live — мұғалім тест таңдап сессия ашады (6 санды код + QR); /join/[code] — оқушы тіркеусіз атымен қосылады; Supabase Realtime арқылы сұрақ ауысады, жауаптар диаграммада тірі жаңарады, соңында рейтинг. Проекторға арналған үлкен экран режимі.
```

## 9-күн · Тоқтату (feature freeze), телефон, APK
```
9-күн: жаңа функция қоспаймыз. Барлық беттерді телефон өлшемінде тексер, қателерді түзет. PWA (Serwist): manifest, иконкалар, офлайн кэш. Capacitor арқылы Android APK жаса — әр қадамды түсіндір. Vercel-ге deploy жасау жолын көрсет. Lighthouse mobile тексер.
```

## 10-күн · Демо дайындығы
```
10-күн: демо аккаунтты нақты деректермен толтыр (сынып, нәтижелер, сабақ жоспарлары). Демо сұрақтарына AI жауаптарын кэште. BLUEPRINT 14-бөліміндегі демо-сценарий бойынша барлық сәтті тексеретін тізім жаса. README.md жаз.
```
