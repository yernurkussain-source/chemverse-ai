# AI Lesson Studio: ҚМЖ генераторы — техникалық тапсырма

Мақсат: мұғалім 1 минутта тақырыпты таңдайды → AI мектептің бекіткен пішіміндегі қысқа мерзімді жоспарды (ҚМЖ) толтырады → мұғалім браузерде түзетеді → **DOCX** (Word) және PDF ретінде жүктеп алады. Пішім мұғалімнің өз ҚМЖ-сынан алынды: `reference/teacher-sample.pdf`.

BLUEPRINT-тағы орны: `/teacher/lesson-studio`, кесте `lesson_plans`, API `/api/ai/lesson-plan` (P1).

## 1. Осы папкадағы файлдар

| Файл | Не үшін |
|---|---|
| `KMZH_SPEC.md` | осы құжат |
| `PROMPTS_KMZH.md` | Claude Code-қа жіберетін 3 сессия |
| `AI_SYSTEM_PROMPT.md` | генератор модельінің жүйелік промпты және кіріс үлгісі |
| `kmzh.schema.json` | ҚМЖ-ның JSON схемасы (AI шығысы да, редактор да, DOCX та осыған сүйенеді) |
| `values-calendar.json` | «Адал азамат» бағдарламасының айлар бойынша құндылықтары (2025–2026) |
| `generator/kmzh-docx.mjs` | **тексерілген** DOCX генераторы (`docx@9.5.1`), пішімді дәл қайталайды |
| `generator/validate-kmzh.mjs` | схема + педагогикалық ережелер тексергіші (`ajv@8.17.1`) |
| `examples/sample-7-lab2.json` | мұғалімнің ҚМЖ-сы JSON түрінде (тест үшін және AI-ға үлгі) |
| `reference/teacher-sample.pdf` | мұғалімнің түпнұсқа ҚМЖ-сы (PDF көрінісі) |
| `reference/generated-from-sample.docx/.pdf` | генератор осы JSON-нан жасаған нәтиже — түпнұсқамен салыстыр |

Генераторды тексеру (жоба түбірінде, тәуелділіктер орнатылғаннан кейін):
```
node docs/kmzh/generator/validate-kmzh.mjs docs/kmzh/examples/sample-7-lab2.json
node docs/kmzh/generator/kmzh-docx.mjs docs/kmzh/examples/sample-7-lab2.json tmp/test.docx
```

## 2. Пішім (өзгертуге болмайды)

**Бет:** A4, альбомдық (16838 × 11906 twip). Жиектер: жоғары 567, оң 1134, төмен 850, сол 1134 twip. Қаріп Times New Roman 12 pt, барлық абзац «Интервалсыз» (after 0, line 240 auto). Кестелер солға −743 twip шығып тұрады, торы жай сызық (single 4).

**1-кесте (шапка)** — 2 баған: 3573 | 12304 twip. Жолдар:
1. **Бөлім:** | **{section}** (қалың)
2. **Педагогтің аты-жөні:** | {teacher}
3. **Күні:** | {date → 15.09.2026}
4. **Сыныбы:   {grade}** | Қатысушылар саны: … Қатыспағандар саны: …
5. **Сабақтың  тақырыбы:** | {topic}      **{topicNote}**  «{topicNoteTitle}»
6. **Оқу  бағдарламасына сәйкес оқу  мақсаты** | әр мақсат бөлек жолда: `{code} - {text}`
7. **Сабақтың мақсаты:** | {lessonGoal}
8. (бос) | **{monthTitle}** / Құзыреттілік: … (сұр 3D3D3D) / түлек сипаттамасы (ені бойынша туралау) / **Аптаның дәйек сөзі:** «…» (автор)
9. бос жол (`headerEmptyRow`)

Одан кейін «Сабақтың барысы:» (сол жақтан 709 twip шегініспен).

**2-кесте (Сабақтың барысы)** — 5 баған: 1277 | 7087 | 3402 | 2693 | 1985 twip, layout fixed. Тақырып жолы (қалың емес): «Сабақ кезеңі/Уақыты», «Педагогтің  іс-әрекеті», «Оқушының іс-әрекеті», «Бағалау», «Ресурстар».
Әр `row`:
- 1-баған: `stage` (+ келесі абзацта «N мин»); `stageAccent` болса — қалың көк 4F81BD. Жалғасы жолдарда `stage: ""`.
- 2-баған: **title** (қалың; `titleInline` болса бірінші абзацпен бір жолда) → `teacher` блоктары → «**Күтілетін жауап:** …» → «**Саралау тәсілі:** …» → `valueNote`.
- 3-баған: `student`.
- 4-баған: `assessment.label` (қалың; бір ғана элемент болса және ұпай жоқ болса — сол жолда) → `items` → бос жол → **Жалпы балл - N** → бос жол → `extra`. `accent` болса label мен балл көк.
- 5-баған: `resources`.
- Кесте соңында `trailingEmptyRows` (әдепкі 2) бос жол.

Ұяшық ішіндегі блок түрлері: мәтін (`**қалың**`, `*курсив*`, `__асты сызылған__`, `\n`), ішкі кесте (`{table:{header, rows, widths}}`, тақырып жолы қалың), сурет (`{image:{src, widthCm, alt}}`, тек мұғалім жүктеген файл).

Пішімді өзгерту тек `generator/kmzh-docx.mjs` ішіндегі `LAYOUT` арқылы. Жобаға көшіргенде бұл константалар мен рендер логикасы сақталсын.

## 3. Пайдаланушы сценарийі

1. `/teacher/lesson-studio` — жоспарлар тізімі (күні, сынып, тақырып, күйі) + «Жаңа ҚМЖ» батырмасы.
2. Жаңа ҚМЖ формасы (бір экран, телефонда да ыңғайлы):
   - Сынып (7, 8, 9, 10, 11), Бөлім, Тақырып — мұғалімнің сақтаған тізімінен таңдау немесе қолмен.
   - Оқу мақсаттары: код + мәтін (сақталған тізімнен таңдау; жаңасын қосу). **AI кодты ойдан шығармайды.**
   - Сабақ түрі: жаңа сабақ / зертханалық жұмыс / практикалық жұмыс / есеп шығару / қайталау / БЖБ.
   - Зертханалық жұмыстың нөмірі мен атауы (сабақ түрі зертхана болса).
   - Күні (айдың құндылығы автоматты таңдалады), ұзақтығы (әдепкі 45 мин), топ саны (3).
   - Белгілер: ЕБҚ тапсырмасы, Функционалдық сауаттылық, Зертхана (әдепкі — бәрі қосулы).
   - «Қосымша тілек» өрісі (мысалы: «Наурыз мерекесімен байланыстыр», «әлсіз сынып»).
   - «Жасау» → прогресс (≈20–40 с) → редакторға өтеді.
3. Редактор `/teacher/lesson-studio/[id]`:
   - Үстінде шапка (1-кесте) — өрістер тікелей өңделеді.
   - Төменде «Сабақтың барысы» кестесі — DOCX-тегідей 5 баған; әр ұяшық өңделеді (қарапайым rich-text: қалың/курсив/асты сызу, тізім жолдары, ішкі кесте қосу/өшіру).
   - Әр жолда: ⬆⬇ орын ауыстыру, ➕ жол қосу, 🗑 өшіру, ✨ «Осы жолды қайта жаса» (тілек жазуға болады), 🖼 сурет жүктеу (Supabase Storage, `lesson-assets` бакеті).
   - Үстіңгі панель: уақыт есептегіші (қосынды / 45 мин; сәйкес болмаса қызыл), жалпы балл, валидатор ескертулері, «Сақтау», «DOCX жүктеу», «PDF», «Көшірме жасау».
   - Телефонда кесте көлденең айналады; әр жолды «карточка» түрінде өңдеуге ауыстырғыш.
4. Баптаулар `/teacher/lesson-studio/settings`:
   - Педагогтің аты-жөні, мектеп (DOCX-ке ғана қойылады).
   - «Қолданылған ЖИ» тізімі (әдепкі: «Chat gpt, Claude ai, Grok, Diffit»).
   - Айлардың құндылығы: `values-calendar.json` негізінде, әр айдың құзыреттілігі, түлек сипаттамасы, апталық дәйек сөздер тізімі — мұғалім толтырады.
   - Сақталған бөлімдер/тақырыптар/оқу мақсаттары (CSV/Excel-ден импорт: `grade;section;topic;code;text`).

## 4. Деректер базасы (Supabase, RLS қосулы)

`lesson_plans` (бар кестені кеңейт):
```
id uuid pk, teacher_id uuid → auth.users, grade text, section text, topic text,
lesson_type text, lesson_date date, status text default 'draft',   -- draft | ready
content_json jsonb not null,   -- kmzh.schema.json
validation jsonb,              -- {errors, warnings}
model text, generation_ms int, created_at, updated_at
```
`lesson_plan_versions` (id, plan_id, content_json, created_at) — әр сақтауда соңғы 20 нұсқа.
`teacher_kmzh_settings` (teacher_id pk, full_name, school, ai_tools text, values jsonb, updated_at).
`curriculum_objectives` (id, teacher_id, grade, section, topic, code, text) — мұғалімнің өз тізімі.
Storage бакеті `lesson-assets` (жеке, RLS: тек иесі).
RLS: барлық кестеде `teacher_id = auth.uid()`.

## 5. API

- `POST /api/ai/lesson-plan` — кіріс (zod): `{grade, section, topic, lessonType, labTitle?, objectives[{code,text}], lessonDate?, lessonMinutes=45, groupCount=3, includeSEN, includeFunctionalLiteracy, includeLab, teacherNotes?}`.
  Қадамдар:
  1. Айдың құндылығын `lessonDate` бойынша `teacher_kmzh_settings.values` (жоқ болса `values-calendar.json`) ішінен алу.
  2. RAG: бар білім қорынан тақырып + оқу мақсаты бойынша 6–8 үзінді; файл атауы сынып нөмірімен басталатындарды (`8-…md`) басымырақ ал. Үзінділерді `[1] файл — бөлім` түрінде промптқа қос.
  3. Модельге: system = `AI_SYSTEM_PROMPT.md` «Жүйелік промпт» + үлгі `examples/sample-7-lab2.json` (кэштелетін бөлік); user = «Кіріс үлгісі». Vercel AI SDK `generateObject` + zod схемасы (kmzh.schema.json-ның көшірмесі). Провайдер `oneOf`-ты қабылдамаса — `z.union` / `anyOf` қолдан.
  4. `validateKmzh` → қате болса бір рет «Қайта түзету хабарламасы» арқылы түзеттіру → әлі қате болса, жоспарды `validation` ескертуімен сақтап, редакторда көрсету.
  5. Мета өрістерін сервер өзі қояды: `teacher` (баптаудан, AI-ға жіберілмейді), `date`, `value` (күнтізбеден), ресурстағы оқулық жолы.
  6. `lesson_plans`-қа сақтап, `{id}` қайтару. Уақыт шегі 60 с; ағынмен (stream) прогресс көрсетуге болады.
- `POST /api/ai/lesson-plan/[id]/row` — бір жолды қайта жасау (`{index, wish}`), нәтижесі валидатордан өтеді.
- `GET /api/lesson-plan/[id]/docx` — `buildKmzhDocx` (TS нұсқасы), суреттерді Storage-тан жүктеп, `Content-Disposition: attachment; filename="KMZH_{grade}_{topic}_{date}.docx"` (файл атауы латынша транслитпен, түпнұсқасы `filename*=UTF-8''…`).
- PDF: редактордағы «Басып шығару көрінісі» беті (`/teacher/lesson-studio/[id]/print`) — сол кестелер HTML-де, `@page { size: A4 landscape; margin: 1cm 2cm 1.5cm 2cm }`, Times New Roman 12pt; браузердің «PDF-ке сақтау» мүмкіндігі. (Vercel-де LibreOffice жоқ, сондықтан серверлік PDF жасама.)

## 6. Қауіпсіздік және этика

- AI-ға педагог пен оқушылардың аты-жөні жіберілмейді.
- AI кодтарды, ресми бағдарлама мәтінін, дәйек сөздерді, сілтемелерді, суреттерді ойдан шығармайды (промпт + валидатор).
- Мұғалім жоспарды «Дайын» деп белгілемей тұрып, ол тек жоба (draft). Редакторда «AI жасаған мазмұнды тексеріңіз» деген ескерту тұрады.
- Мұғалімнің жоспарлары тек өзіне көрінеді (RLS). «Әріптеспен бөлісу» — кейінгі кезең.

## 7. Тесттер (Vitest)

- `parseInline`: `**a** *b* __c__` → дұрыс run-дар; `***x***` → қалың+курсив.
- `imageSize`: PNG және JPEG өлшемі.
- `validateKmzh(examples/sample-7-lab2.json)` → ok, тек «Уақыт көрсетілмеген» ескертуі.
- Минуттары 44 болған нұсқа → қате «Уақыттың қосындысы 44 мин».
- `buildKmzhDocx(example)` → zip ішіндегі `word/document.xml`-да: `w:orient="landscape"`, `w:w="16838"`, gridCol 3573/12304 және 1277/7087/3402/2693/1985, `Times New Roman`, `w:sz w:val="24"`; 3 сурет `word/media`-да.
- API: кіріс zod-тан өтпесе 400; авторизациясыз 401; басқа мұғалімнің жоспары 404.

## 8. Қабылдау критерийлері

1. `examples/sample-7-lab2.json`-нан жасалған DOCX Word-та ашылғанда `reference/teacher-sample.pdf`-пен бірдей көрінеді: альбомдық бет, екі кесте, баған ендері, қаріп, қалың жерлер, ЕБҚ жолының көк түсі, суреттер.
2. Жаңа ҚМЖ 60 секундтан аз уақытта жасалады, валидатордан қатесіз өтеді, уақыт қосындысы = 45.
3. Барлық міндетті бөліктер бар: Сабақтың басы, Жаңа сабақ, Сабақтың ортасы (жеке/жұптық/топтық, зертхана сабағында — зертхана жолы), Функционалдық сауаттылық, ЕБҚ, Сабақтың соңы; дескрипторлар мен «Жалпы балл».
4. Айдың құндылығы күніне сай автоматты қойылады (қазан → «ҚАЗАН – ТӘУЕЛСІЗДІК ЖӘНЕ ОТАНШЫЛДЫҚ АЙЫ»).
5. Редакторда кез келген ұяшықты өзгертіп, сақтап, DOCX-ті қайта жүктегенде өзгеріс көрінеді.
6. «Осы жолды қайта жаса» тек бір жолды өзгертеді, қалғаны сақталады.
7. Телефонда (390 px) форма мен редактор қолдануға жарамды; DOCX жүктеу телефоннан да жұмыс істейді.
8. `npm run build`, `npm run lint`, `npm run test` қатесіз.
