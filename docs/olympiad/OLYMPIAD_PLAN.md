**«Дарын» оқушылардың ғылыми қоғамы үйірмесінің күнтізбелік жоспары  
(9-сынып, Химия)  
2026–2027 оқу жылы**

| №   | Тақырып                                                                           |
|-----|-----------------------------------------------------------------------------------|
| 1   | Кіріспе. Ұйымдастырушылық сабақ. Химия кабинетіндегі қауіпсіздік техникасы.       |
| 2   | Атом құрылысы. Квант сандары және электронды конфигурациялар.                     |
| 3   | Периодтық заң және периодтық жүйенің тереңдетілген заңдылықтары.                  |
| 4   | Химиялық байланыс түрлері және кристалдық торлардың ерекшеліктері.                |
| 5   | Тотығу-тотықсыздану реакциялары. Электрондық баланс әдісі.                        |
| 6   | Электролиттік диссоциация теориясы. Ион алмасу реакциялары.                       |
| 7   | Гидролиз құбылысы. Тұздар гидролизінің олимпиадалық есептері.                     |
| 8   | Электролиз негіздері: балқымалар мен ерітінділер электролизі.                     |
| 9   | Химиялық кинетика. Реакция жылдамдығына әсер ететін факторлар.                    |
| 10  | Химиялық тепе-теңдік және Ле Шателье принципі.                                    |
| 11  | Ерітінділер. Массалық үлес пен молярлық концентрацияға арналған есептер.          |
| 12  | Бейметалдардың жалпы сипаттамасы. Галогендер және олардың қосылыстары.            |
| 13  | Халькогендер: Күкірт және оның маңызды қосылыстары (күкіртсутек, күкірт қышқылы). |
| 14  | Азот тобы: Азот және аммиак, оларды алудың өндірістік әдістері.                   |
| 15  | Азот қышқылының ерекше қасиеттері мен металдармен әрекеттесуі.                    |
| 16  | Фосфор және оның қосылыстары. Фосфор қышқылы мен минералды тыңайтқыштар.          |
| 17  | Көміртек және оның аллотропиялық түр өзгерістері. Көміртек оксидтері.             |
| 18  | Кремний және оның қосылыстары. Силикат өнеркәсібі.                                |
| 19  | Металдардың жалпы қасиеттері. Металдардың кернеу қатары.                          |
| 20  | Сілтілік және сілтілік-жер металдар, олардың қосылыстары.                         |
| 21  | Алюминий және оның амфотерлік қасиеттері.                                         |
| 22  | Темір және оның тотығу дәрежелері әртүрлі қосылыстары.                            |
| 23  | Зертханалық практикум: Катиондар мен аниондарға сапалық реакциялар.               |
| 24  | Эксперименттік олимпиадалық есептерді шығару жолдары.                             |
| 25  | Органикалық химияға кіріспе. Органикалық қосылыстардың құрылыс теориясы.          |
| 26  | Қаныққан көмірсутектер (Алкандар): құрылысы, номенклатурасы, изомериясы.          |
| 27  | Қанықпаған көмірсутектер (Алкендер, Алкиндер). Қосылу реакциялары.                |
| 28  | Ароматты көмірсутектер (Бензол және оның гомологтары).                            |
| 29  | Оттекті органикалық қосылыстар: Спирттер мен фенолдар.                            |
| 30  | Альдегидтер мен карбон қышқылдары.                                                |
| 31  | Тұрмыстағы және адам ағзасындағы химия. Маңызды аминқышқылдар мен белоктар.       |
| 32  | Қазақстанның химиялық өнеркәсібі және экологиялық мәселелер.                      |
| 33  | «Жас химик-дарын» олимпиадалық және білімділер сайысы.                            |
| 34  | Қорытынды сабақ. Оқушылардың ғылыми жобаларын қорғауы.                            |
|     | Барлығы: 34 тақырып                                                               |
