**T02-02** · деңгей 2 · `econf`

## 9. Химиялық кинетика. Реакция жылдамдығына әсер ететін факторлар

Жауабы: **27 есе**
Шешуі: v₂/v₁ = γ^(Δt/10) = 3³ = 27.

**T09-03** · деңгей 2 · `numeric`

## 10. Химиялық тепе-теңдік және Ле Шателье принципі

**T10-01** · деңгей 1 · `mcq`  
N₂ + 3H₂ ⇌ 2NH₃ + Q реакциясында аммиак шығымын арттыратын жағдай:
- Температураны көтеру
- ✅ Қысымды арттыру
- Катализатор қосу
- Аммиак концентрациясын арттыру
Шешуі: Тура реакцияда газ мольдері 4-тен 2-ге азаяды → қысымды арттырғанда тепе-теңдік оңға ығысады. → Реакция экзотермиялық — температураны көтеру солға ығыстырады; катализатор ығыстырмайды.

**T10-02** · деңгей 2 · `numeric`  
H₂ + I₂ ⇌ 2HI. Бастапқы [H₂] = [I₂] = 1 моль/л, тепе-теңдік орнағанда сутектің 80 %-ы әрекеттесті. Kc-ны есепте.
Жауабы: **64 **
Шешуі: x = 0,8: [H₂] = [I₂] = 0,2; [HI] = 1,6. → Kc = 1,6² / (0,2 · 0,2) = 64.

**T10-03** · деңгей 3 · `numeric`  
CO + H₂O ⇌ CO₂ + H₂, Kc = 1. Бастапқы [CO] = [H₂O] = 1 моль/л. Тепе-теңдіктегі [CO₂]-ны (моль/л) тап.
Жауабы: **0,5 моль/л**
Шешуі: x² / (1 − x)² = 1 → x / (1 − x) = 1 → x = 0,5.

**T32-02** · деңгей 2 · `numeric`

**T32-03** · деңгей 3 · `open`  
Күкірт диоксидінен түзілетін қышқыл жаңбырлардың химиясын түсіндір (теңдеулермен) және ластануды азайтудың екі химиялық әдісін ұсын.
Рубрика: SO₂ + H₂O ⇌ H₂SO₃; 2SO₂ + O₂ → 2SO₃; SO₃ + H₂O → H₂SO₄ — 3 ұпай; Салдары: топырақ пен су қышқылдануы, ғимараттар мен ормандардың зақымдануы — 1 ұпай; Әк тасымен күкіртсіздендіру (CaCO₃ + SO₂ → CaSO₃ + CO₂, одан әрі гипс) — 2 ұпай; Отынды алдын ала күкірттен тазарту немесе газды аммиак/сілтімен сіңіру — 2 ұпай
Шешуі: Күкірт оксидтері сумен қышқылдар түзеді. → Түтін газдарын негіздік заттармен тазартады.
