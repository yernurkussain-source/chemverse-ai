> Бұл файл — Claude Code үшін. Негіз: «Дарын» оқушылардың ғылыми қоғамы үйірмесінің күнтізбелік жоспары, 9-сынып, химия, 2026–2027 оқу жылы, 34 тақырып (`OLYMPIAD_PLAN.md`).
> Бұл — `docs/BLUEPRINT.md`-тегі «Olympiad Elite» модулінің толық сипаттамасы.
> Дайын мазмұн: `TOPICS.json` (34 тақырып), `PROBLEMS.json` (94 есеп: шешімі, 3 деңгейлі ишарасы бар), `core/olympiad-core.js` (теңестіру, электрондық конфигурация, 15 есеп генераторы, жауап тексергіш) және оның тесттері.
> Тексеру: `node core/olympiad-core.test.js` (9 тест) және `node core/validate-bank.js` (94 есеп, қате 0).

## 1. Мақсат және пайдаланушылар

- **Оқушы (9-сынып, үйірме мүшесі):** тақырыпты оқиды, есеп шығарады, қатесін талдайды, сынақ олимпиада тапсырады, жоба қорғайды.
- **Мұғалім (үйірме жетекшісі):** күнтізбені басқарады, тапсырма береді, оқушылардың прогресін көреді, ашық жауаптарды бағалайды, өз есептерін қосады.
- Басты қағида: **есептің жауабын AI емес, код тексереді.** AI тек түсіндіреді, ишара береді және ашық жауапқа алдын ала баға ұсынады.

## 3. Тақырып бетінің құрылымы

1. **Мақсат** — `TOPICS.json` → `goals`.
2. **Негізгі ұғымдар** — `key` (чиптер түрінде); мұғалім қысқа теория мәтінін жаза алады (Markdown + KaTeX/mhchem).
3. **Олимпиадалық кеңес** — `olympiadTip`.
4. **Шешілген мысал** — сол тақырыптың бірінші есебі, шешімі қадамдап ашылады.
5. **Жаттығу** — банктен есептер және `generators` тізіміндегі генераторлардан жаңа нұсқалар; 1-деңгейден 3-деңгейге.
6. **Зертхана** — `labs` сілтемелері: 3D Virtual Lab тапсырмалары (`kind:'game'`), ChemLab тәжірибелері (`kind:'chemlab'`), сайт бөлімдері (`kind:'site'`: periodic-table, molecules, live).
7. **Өзін-өзі тексеру** — 5 сұрақ (mcq + numeric), нәтижесі меңгеру деңгейіне әсер етеді.
8. **AI көмекші** — Сократтық режим: дайын жауапты бермейді, есептің `hints` массивінен бастайды.

## 4. Есеп түрлері және тексергіштер

| Түрі | Енгізу | Тексеру (`core/olympiad-core.js`) |
|---|---|---|
| `numeric` | сан + бірлік (үтір де, нүкте де қабылданады) | `checkNumeric(user, value, tol)`: салыстырмалы рұқсат (әдепкі 1 %), бірлік қатесін анықтайды (×1000, ×100) |
| `mcq` | бір таңдау | `correct` индексі |
| `balance` | әр затқа коэффициент | `checkCoefficients(eq, k)`: атом мен заряд сақталуы, бүтін оң сандар, ЕҮОБ = 1; қате болса себебін айтады. `balance(eq)` кез келген теңдеудің дұрыс коэффициенттерін табады |
| `econf` | деңгейшелерді толтыру (1s, 2s, 2p, …) + жұпталмаған электрондар | `econf(Z)` — Z = 1–54, Cr, Cu, Nb, Mo, Ru, Rh, Pd, Ag ерекшеліктерімен; `lastElectronQN(Z, mlOrder)` — соңғы электронның квант сандары |
| `open` | мәтін (+ сурет жүктеу) | `rubric` бойынша: AI алдын ала ұпай ұсынады, **соңғы бағаны мұғалім қояды** |
| `chain` (кейін) | A → B → C тізбегінің заттары | әр сатыны `balance` арқылы тексеру |
| `structure` (кейін) | органикалық атау ↔ формула | атаулар сөздігі + изомерлер кестесі |

**Конвенциялар (баптауда мұғалім өзгерте алады):**
- атомдық массалар олимпиадалық дөңгелектеумен (`AR`: Cl = 35,5, Cu = 64, т.б.), Vm = 22,4 л/моль, F = 96500 Кл/моль;
- mₗ реттілігі оқулыққа байланысты: `minusFirst` (−l…+l, әдепкі) немесе `plusFirst`.

## 5. Есептердің көздері

1. **Банк** — `PROBLEMS.json`: 94 есеп, 1–32 тақырыптар (33 — сайыс, 34 — жоба). Әр есепте: `id`, `topic`, `level` (1–3), `type`, `kk` (шарты), `solution` (қадамдар), `hints` (3 деңгей), жауап өрістері.
2. **Генераторлар** — 15 параметрлі генератор (`GEN`): w_basic, w_mix, w_to_C, C_prep, gas_H2, excess, faraday, vant_hoff, Kc_HI, empirical, alkane_M, combustion, mix_MgAl, pH_strong, plate. `generate(id, seed)` — бір seed әрқашан бірдей есеп береді (оқушыға тапсырма ретінде беруге болады).
3. **Мұғалім редакторы** — жаңа есеп қосу; `balance`/`econf`/`numeric` түрлерінде жауапты сақтамас бұрын тексергіш іске қосылады.
4. **AI ұсынған есептер** — AI тек шарт пен шешім жолын ұсынады; сандық жауапты генератор не тексергіш есептейді; мұғалім бекітпейінше оқушыға көрінбейді.

## 6. Бейімделу және мотивация

- **Меңгеру деңгейі (0–100)** әр тақырып бойынша: бірінші әрекетте дұрыс +, ишарамен дұрыс аз +, қате −; 3-деңгейлі есептер көбірек салмақ береді.
- **Аралықты қайталау:** меңгерілген тақырыптан 3, 7, 21 күннен кейін 2–3 есеп қайта шығады.
- **Қателер дәптері:** қате есеп автоматты түрде түседі; дұрыс шыққанша сонда тұрады.
- **Бейджиктер:** «Теңестіру шебері» (20 теңдеу), «Фарадей» (10 электролиз есебі), «Таза зертхана» (Virtual Lab-та қауіпсіздік 100) т.б.
- Ойын мен зертханаға сілтемелер: тақырыпқа байланысты Virtual Lab тапсырмасы орындалса, меңгеру деңгейіне бонус.

## 7. Сынақ олимпиада және сайыс

- **Сынақ олимпиада:** мұғалім құрастырады (тақырыптар, есеп саны, уақыт) немесе автоматты түрде (әр блоктан 1–2 есеп, 2–3-деңгей). Нәтиже: жалпы ұпай, тақырыптар бойынша талдау, ұсынылатын қайталау тізімі. Тапсырманы PDF ретінде жүктеп алуға болады (қағазбен өткізу үшін).
- **«Жас химик-дарын» сайысы (33-сабақ):** Live Class механизмі (Supabase Realtime): раундтар (жылдам сұрақтар, есептер, эксперимент сұрағы), командалық режим, проекторға арналған рейтинг экраны.
- **Рейтинг:** тек үйірме ішінде, оқушы өз орнын көреді; мұғалім жалпы кестені көреді.

## 8. Ғылыми жобалар (34-сабақ)

Жоба беті: тақырып, зерттеу сұрағы, гипотеза, әдістеме, деректер (кесте/сурет/файл, Virtual Lab журналынан экспорт), нәтиже, қорытынды, дереккөздер. Бағалау рубрикасы (мұғалім өзгерте алады): өзектілік, әдістеме, деректер сапасы, қорытындының негізділігі, қорғау. Қорғау күні күнтізбеде.

## 9. Мұғалім құралдары

- **Күнтізбе:** 34 сабақ; мұғалім апта күнін, уақытын және демалыс күндерін енгізеді, жүйе сабақ күндерін 2026–2027 оқу жылына автоматты түрде таратады; күнді қолмен жылжытуға болады.
- **Журнал:** қатысу, үй тапсырмасы, меңгеру картасы (жылу картасы: оқушы × тақырып).
- **Тапсырмалар:** тақырып немесе нақты есептер жиынын (генератор seed-тері бар) мерзімімен беру.
- **Ашық жауаптар:** рубрика бойынша AI ұсынған ұпай + мұғалім түзетуі + пікір.
- **Мазмұн:** тақырып теориясын өңдеу, есеп қосу/жасыру, банкті JSON түрінде экспорттау/импорттау.

## 10. Деректер базасы (Supabase)

```sql
create table olympiad_topics   (n int primary key, title text, block text, data jsonb);              -- TOPICS.json
create table olympiad_problems (id text primary key, topic int references olympiad_topics(n), level int, type text,
                                body jsonb, author_id uuid, status text default 'published', created_at timestamptz default now());
create table olympiad_attempts (id uuid primary key default gen_random_uuid(), user_id uuid, problem_id text, seed int,
                                answer jsonb, correct boolean, hints_used int, score numeric, created_at timestamptz default now());
create table olympiad_mastery  (user_id uuid, topic int, level numeric, next_review date, primary key(user_id,topic));
create table olympiad_sessions (id uuid primary key default gen_random_uuid(), class_id uuid, topic int, date date, note text);
create table olympiad_mocks    (id uuid primary key default gen_random_uuid(), class_id uuid, title text, config jsonb, starts_at timestamptz, duration_min int);
create table olympiad_mock_results (mock_id uuid, user_id uuid, score numeric, details jsonb, primary key(mock_id,user_id));
create table olympiad_projects (id uuid primary key default gen_random_uuid(), user_id uuid, class_id uuid, title text, body jsonb, files text[], score jsonb, status text);
```
RLS: оқушы өз әрекеттерін, мастерисін және жобасын көреді; мұғалім өз үйірмесінің (class_id) деректерін көреді; есептің дұрыс жауабы клиентке тапсыру алдында жіберілмейді (тексеру серверде — `/api/olympiad/check`).

## 12. Қабылдау критерийлері

1. `npm run test` — `core` тесттері (кемінде 9) және банк валидациясы (94 есеп, қате 0) өтеді.
2. `/olympiad` картасында 34 тақырып, әрқайсысының беті ашылады; 1–32 тақырыптарда жаттығу жұмыс істейді.
3. Барлық 6 есеп түрі (numeric, mcq, balance, econf, open, generator) енгізіледі және серверде тексеріледі; қате жауапқа себебі айтылады.
4. Ишаралар 3 деңгеймен ашылады; AI дайын жауапты бермейді.
5. Сынақ олимпиада уақытпен өтеді, нәтижесі сақталады.
6. Мұғалім күнтізбені құрып, тапсырма бере алады және меңгеру картасын көреді.
7. Барлық мәтін `messages/kk.json` / `ru.json`-да; химиялық формулалар дұрыс көрсетіледі (төменгі/жоғарғы индекстер).
8. Телефонда (390 px) есеп шығару ыңғайлы: коэффициенттер мен деңгейшелерді енгізу батырмалары үлкен.

## 13. Ғылыми дәлдік

- Банктегі барлық теңдеу `balance()` арқылы, барлық конфигурация `econf()` арқылы тексерілген; сандық жауаптар есептеп шығарылған. Соған қарамастан мұғалім банкті оқушыларға ашпас бұрын бір рет қарап шығуы керек.
- Жаңа есеп қосылғанда — алдымен тексергіш, содан кейін жариялау.
