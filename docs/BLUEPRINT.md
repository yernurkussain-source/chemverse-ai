0.1. Конкурс туралы маңызды ескертпелер

- **Ережені оқыңыз:** конкурс ережесіндегі бағалау критерийлерін
  (инновация, практикалық маңызы, масштабталуы, презентация т.б.) жазып
  алып, әр критерийге платформаның қай бөлігі жауап беретінін
  презентацияда нақты көрсетіңіз.

- **Мерзім:** 12-бөлімдегі 11 күндік кесте 1-күн, 2-күн... түрінде
  берілген. Конкурс күнінен кері санап, нақты күндерді өзіңіз қойыңыз.
  Мерзім ұзағырақ болса, P1/P2 модульдерді қосыңыз.

- **Формат:** педагогтер конкурстарында көбіне қысқа презентация + жоба
  демонстрациясы болады. Демек жобаны 5–7 минутта әсерлі көрсету және
  қазыларға телефонмен «ұстатып» көрсету маңызды.

- **Позициялау:** «Оқушыларға арналған тағы бір тест сайты» емес,
  «мұғалім мен оқушыны біріктіретін, AI мен 3D-ны сыныпқа әкелетін химия
  экожүйесі» ретінде таныстырыңыз. Сіз — оны өз сабағында қолданатын
  мұғалімсіз, бұл ең күшті дәлел.

1\. Архитектуралық шешім **ЖАҢАРТЫЛДЫ**

Бастапқы нұсқа: modular monolith. Бір Next.js репозиторийі ішінде
экрандар, API және тәуелсіз feature модульдері болады. Supabase
авторизация, PostgreSQL, Realtime, файл сақтау және RLS шектеулерін
қамтамасыз етеді. Бір код базасы үш «бетті» береді: веб-сайт, телефонға
орнатылатын PWA және Capacitor арқылы оралған Android APK.

**Жүйе ағыны:** Student / Teacher / Guest → Next.js Web + PWA (+ Android
APK) → Server API (Exam, AI, QR, Live) + Client (3D, Gesture, AR,
Scanner) → Supabase Auth / PostgreSQL + pgvector / Realtime / Storage →
AI провайдер (LLM + Vision) → Vercel deployment.

| **Қабат**                               | **Қайда орындалады**                       | **Неге**                                                      |
|-----------------------------------------|--------------------------------------------|---------------------------------------------------------------|
| **3D, қол қимылы, AR, QR сканер**       | Браузерде (клиент)                         | Кадрлар серверге жіберілмейді — жылдам әрі құпиялық сақталады |
| **Тест бағалау, AI сұраулар, QR токен** | Серверде (Route Handlers / Server Actions) | Жауаптар мен API кілттері клиентке ашылмайды                  |
| **Live Class (нақты уақыт)**            | Supabase Realtime арналары                 | Бөлек WebSocket сервер жазудың қажеті жоқ                     |
| **RAG білім қоры**                      | PostgreSQL + pgvector                      | Бөлек векторлық база керек емес                               |
| **Күрделі химиялық есептеу (кейін)**    | Python FastAPI + RDKit                     | V2-де ғана, қазір JS жеткілікті                               |

5\. Мобильді қосымша стратегиясы **ЖАҢА**

11 күнде бөлек нативті қосымша (React Native / Flutter) жазу нақты емес
— ол екінші код базасын білдіреді. Дұрыс жол: бір Next.js кодынан үш
нұсқа шығару.

| **Нұсқа**                   | **Не береді**                                                                     | **Уақыт**                   | **Шешім**                                  |
|-----------------------------|-----------------------------------------------------------------------------------|-----------------------------|--------------------------------------------|
| **PWA**                     | Телефон экранына орнату, толық экран, иконка, offline кэш, камера, push (Android) | Әзірлеу барысында, ~0.5 күн | Міндетті (P0)                              |
| **Android APK (Capacitor)** | Нағыз .apk файл, Play Store-ға жүктеуге дайын, нативті камера/QR плагиндері       | ~1 күн                      | P1 — қазыға «қосымша бар» деп көрсету үшін |
| **PWABuilder (TWA)**        | PWA-дан бірнеше минутта Android пакет                                             | ~2 сағат                    | Capacitor үлгермесе — резерв               |
| **iOS App Store**           | Apple әзірлеуші аккаунты және тексеру кезеңі керек                                | 11 күнге сыймайды           | iPhone-да PWA «Add to Home Screen»         |

**Мобильді UX ережелері:** төменгі навигация панелі (5 таб: Басты, Оқу,
3D Lab, Сканер, Профиль); ортада үлкен «Сканер» батырмасы; батырмалар ≥
44px; 3D беттерде бір саусақпен айналдыру, екі саусақпен zoom; қараңғы
режим әдепкі.

6\. QR жүйесі — толық сценарийлер **ЖАҢА**

**Қауіпсіздік:** QR ішінде тек қысқа кездейсоқ токен болады (мысалы

статистикаға жазылады (неше оқушы ашты).

**Креатив идея:** стендке басып шығарылған QR-периодтық кесте мен 5–6
«молекула карточкасын» апарыңыз. Қазылар физикалық карточканы сканерлеп,
AR-да молекуланы көреді — бұл есте қалады.

10\. Негізгі модульдердің жұмыс тәртібі **ЖАҢАРТЫЛДЫ**

10.1. 3D Molecule Engine

Алғашқы 10 молекула: H₂O, CO₂, CH₄, NH₃, C₂H₅OH, бензол, NaCl (кристалл
тор), H₂SO₄, глюкоза, кофеин (соңғысы — оқушыларға қызықты «өмірлік»
мысал). Құрылым файлдарын PubChem-нен SDF форматында жүктеп, тексеріңіз.
3Dmol.js айналдыру, масштабтау, ball-and-stick / space-filling /
сызықтық көріністерді береді. Атомды басқанда — элемент атауы, массасы,
электртерістігі шығады.

10.2. Gesture Controller 2.0

Webcam → MediaPipe Hand Landmarker (21 нүкте) → тегістеу (smoothing,
мысалы 5 кадрлық орташа) → қимыл классификаторы → 3D әрекет.

| **Қимыл**                           | **Әрекет**                | **Анықтау тәсілі**                             |
|-------------------------------------|---------------------------|------------------------------------------------|
| **Сұқ саусақ қозғалысы**            | Айналдыру                 | Сұқ саусақ ұшының (8-нүкте) жылжуы             |
| **Шымшу (бас бармақ + сұқ саусақ)** | Zoom                      | 4 және 8 нүктелер арақашықтығы / алақан өлшемі |
| **Ашық алақан**                     | Тоқтату / қалпына келтіру | Барлық саусақ созылған                         |
| **Жұдырық**                         | Келесі молекула           | Барлық саусақ бүгілген, 0.5 с ұстау            |
| **Екі саусақ (V)**                  | Көрініс стилін ауыстыру   | Сұқ + ортаңғы созылған                         |

Экран бұрышында камераның кішкентай терезесі мен қол «қаңқасы»
көрсетіледі — қазыларға технологияның жұмысы көрінеді. Камераға келісім
міндетті; тышқан және сенсорлық баламасы әрқашан бар.

10.3. AR Molecule **ЖАҢА**

Құрастыру кезінде scripts/sdf-to-glb.ts скрипті SDF файлдан Three.js
арқылы сфера + цилиндр модель жасап, GLTFExporter-мен .glb файлға
сақтайды (CPK түстері: C — сұр, O — қызыл, H — ақ, N — көк). /ar/\[id\]
беті model-viewer компонентін ar атрибутымен көрсетеді: Android-та Scene
Viewer, iPhone-да Quick Look ашылады (iOS үшін .usdz нұсқасы қажет болуы
мүмкін — ерте тексеріңіз).

10.4. AI Tutor

Сұрақ → қауіпсіздік және тақырып тексеруі → RAG: pgvector-тен 4–6
сенімді материал үзіндісі → LLM (жүйелік нұсқау: «тек химия, қазақша,
қадамдық, дереккөз көрсет») → сандық жауап болса, JS-пен қайта есептеп
тексеру → стриминг жауап + дереккөз. Сократтық режим: оқушы «жауабын
айтпа» дегенде AI тек бағыттаушы сұрақ қояды. Оқушының аты-жөні AI
провайдеріне жіберілмейді.

10.5. Exam Engine

Сервер тест сессиясын ашады, уақыт шегін белгілейді, тапсырмалар
нұсқасын бекітеді, жауаптарды сақтайды және сервер жақта бағалайды. ҰБТ,
ББЖМ, олимпиада бір қозғалтқышта бөлек бағалау ережелерімен жұмыс
істейді. Нәтиже бетінде: тақырып бойынша «әлсіз жерлер» картасы және
«AI-дан осы қатені түсіндіріп бер» батырмасы.

10.6. Virtual Lab

Бірінші зертхана — қышқыл-сілті титрлеуі (HCl + NaOH): бюреткадан
тамшылату слайдері, нақты уақыттағы pH қисығы, индикатор (фенолфталеин)
түсінің өзгеруі, эквивалент нүктесін табу, нәтижені талдау және сақтау.
Формулалар күшті қышқыл/күшті негіз үшін дәл; әлсіз қышқылдар V2-де.

10.7. Live Class **ЖАҢА**

Мұғалім /teacher-де тест таңдап «Live бастау» басады → экранда 6 санды
код + QR. Оқушылар телефонмен QR сканерлеп, лақап атпен қосылады
(тіркеусіз). Мұғалім сұрақты ауыстырады → Supabase Realtime арқылы
барлық телефонға жетеді → жауаптар бірден диаграммаға түседі → соңында
рейтинг. Демода қазылар мен залдағы мұғалімдер қатыса алады — бұл ең
күшті интерактив сәт.

10.8. AI Lesson Studio **ЖАҢА**

Мұғалім енгізеді: сынып, тақырып, оқу мақсаты (оқу бағдарламасынан),
сабақ ұзақтығы. AI құрылымдық JSON қайтарады: сабақ кезеңдері, уақыт,
мұғалім/оқушы әрекеті, саралау, бағалау критерийлері мен дескрипторлар,
рефлексия, платформадағы 3D/зертхана/QR ресурстарына сілтемелер. Нәтиже
— редакцияланатын бет + PDF/DOCX экспорт. Маңызды: AI жоспарын мұғалім
тексеріп бекітеді — бұл туралы интерфейсте жазылады.

10.9. ChemScan **ЖАҢА**

Телефон камерасы → есеп суреті (клиентте сығылады, ≤1 МБ) → multimodal
LLM есепті мәтінге айналдырады → оқушыға «дұрыс таныдым ба?» деп
көрсетеді → растағаннан кейін AI Tutor қадамдық шешеді. Суреттер
оқушының келісімімен ғана сақталады.

15\. Мини-пилот және тиімділік дәлелі **ЖАҢА**

Қазылардың ең күшті сұрағы: «Бұл шынымен оқытуға көмектесе ме?» Оған
нақты дерекпен жауап беріңіз. 8-күні (немесе 6–8-күндер аралығында) өз
сыныбыңызда (немесе әріптесіңіздің сыныбында) шағын тексеру өткізіңіз:

1.  Алғашқы мини-тест (5 сұрақ, мысалы «молекула құрылысы» тақырыбы) —
    платформасыз.

2.  15–20 минут платформамен жұмыс: 3D, AR, AI Tutor, Live Class.

3.  Қорытынды мини-тест (ұқсас 5 сұрақ) + 4 сұрақтық сауалнама (Google
    Forms): қызықты болды ма, түсінікті болды ма, қайта қолданасыз ба,
    не жетпейді.

4.  Нәтижені бір слайдқа: «N оқушы, орташа балл X → Y, Z% қайта
    қолданғысы келеді» + 2 оқушы пікірі (ата-ана/әкімшілік келісімімен).

**Ескерту:** мұндай шағын тексеру ғылыми дәлел емес — презентацияда
«алғашқы пилот нәтижелері» деп адал атаңыз. Сандарды ойдан шығармаңыз.

17\. Сапа, қауіпсіздік, тәуекелдер **ЖАҢАРТЫЛДЫ**

- **Химиялық дәлдік:** формулалар мен есептер тексерілген контентке
  сүйенеді; AI жауабындағы сандар кодпен қайта есептеледі.

- **Дербес деректер:** ҚР «Дербес деректер және оларды қорғау туралы»
  Заңын ескеріп, кәмелетке толмағандардан ең аз дерек жинаңыз; демо және
  пилот үшін ата-ана/мектеп келісімі; аты-жөні AI провайдеріне
  жіберілмейді.

- **Камера:** келісіммен ғана; кадрлар құрылғыда өңделеді, серверге
  жіберілмейді; камерасыз балама интерфейс.

- **AI:** rate limiting, токен шығынын бақылау, тақырыптан тыс
  сұрақтарды сүзу, «AI қателесуі мүмкін» белгісі.

- **Қолжетімділік:** keyboard/mouse/touch баламалары, контраст, қазақ
  әріптерін (ә, ғ, қ, ң, ө, ұ, ү, һ, і) толық қолдайтын қаріп — таңдаған
  қаріпті тексеріңіз.

- **Өнімділік:** әлсіз телефондарда 3D сапасын автоматты төмендету, GLB
  ≤ 500 КБ, суреттер WebP, Lighthouse mobile ≥ 85.
