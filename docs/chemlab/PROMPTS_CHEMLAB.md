# ChemLab-ты Claude Code-қа жіберу: 3 сессия

Әр сессияны жаңа чатта бастаңыз (Claude панеліндегі «New session»). Режимді **Plan** етіп қойыңыз: Claude алдымен жоспар көрсетеді, оқып шығып, қабылдаңыз.
Әр сессиядан кейін `npm run dev` арқылы тексеріп, ұнаса келесісіне өтіңіз.

---

## 1-сессия · Каталог, ортақ қабықша (LabShell), деректер базасы
```
@CLAUDE.md @docs/chemlab/CHEMLAB_SPEC.md @docs/chemlab/CHEMLAB_IDEA.md оқып шық.
Виртуалды зертхана бөліміне ChemLab қосамыз. Алдымен қазіргі /virtual-lab және титрлеу кодын қарап, не бар екенін маған қысқаша айт.
Бұл сессияда тек мынаны жаса:
1) CHEMLAB_SPEC 8-бөліміндегі миграция және seed (3-бөлімдегі каталог, ready/soon статусымен);
2) /virtual-lab басты беті (ұран, 7–10-сынып карталары) және /virtual-lab/grade/[grade] беті;
3) ортақ LabShell компоненті (4-бөлімдегі 8 қадам), SafetyCard, ObservationTable, AnalysisQuestions, ConclusionEditor, ModelBadge;
4) бар титрлеу зертханасын LabShell-ге көшір (5.5-бөлім) — ол толық жұмыс істеп тұрсын;
5) /api/labs/submit — серверлік бағалау (6-бөлім), титрлеу үшін.
Мәтіндер kk.json/ru.json-да. Соңында npm run build және git commit.
```

## 2-сессия · 7 және 8-сынып тәжірибелері
```
@CLAUDE.md @docs/chemlab/CHEMLAB_SPEC.md оқы. LabShell дайын. Енді екі тәжірибе:
1) mixture-separation (5.1-бөлім) — күй машинасы, қате ретке кері байланыс, шығым есептеулері;
2) atom-builder (5.2-бөлім) — 20 элемент кестесі, ион және изотоп ережелері, 2D атом моделі, 3 мақсат.
Әрқайсысына model.ts (таза функциялар) және model.test.ts (Vitest, құжаттағы сандармен) жаз, тесттерді іске қосып көрсет.
Бағалауды /api/labs/submit-ке қос. Телефон өлшемінде тексер. Соңында build + commit.
```

## 3-сессия · 9–10-сынып тәжірибелері, AI ишара, мұғалім беті
```
@CLAUDE.md @docs/chemlab/CHEMLAB_SPEC.md оқы. Енді:
1) indicator-lab (5.3-бөлім) — 6 белгісіз ерітінді, 4 индикатордың түс функциялары, тамшы анимациясы;
2) reaction-rate (5.4-бөлім) — Mg + HCl моделі, газ шприці анимациясы, 4 жүгіртілімді салыстыратын график, «бір параметр» ережесі;
3) HintButton — 7-бөлімдегі 3 деңгейлі ишара, бар /api/ai/chat арқылы; қорытындыны AI алдын ала бағалауы (мұғалім түзете алады);
4) /teacher/labs — тәжірибені сыныпқа тапсырма ету және нәтижелер кестесі.
model.test.ts тесттері құжаттағы кестемен сәйкес болсын. 12-бөлімдегі қабылдау критерийлерін бір-бірлеп тексеріп, нәтижесін маған тізім етіп көрсет. Соңында build + commit.
```

## Уақыт туралы
ChemLab шамамен 2–3 жұмыс күнін алады. Жалпы кестеге сыймаса, Claude-қа айтыңыз: «BLUEPRINT 12-бөліміндегі кесу ережесі бойынша нені кейінге қалдыруды ұсын» — мысалы ChemScan немесе ББЖМ/олимпиада режимін.
