## 4. Әр тәжірибенің 8 қадамдық құрылымы (ортақ `LabShell` компоненті)

Барлық тәжірибе бір ортақ «қабықшада» жұмыс істейді. Жоғарыда қадам көрсеткіш (stepper), телефонда — бір қадам бір экранда.

1. **Мақсат** — 1–2 сөйлем + қысқа теория (≤ 120 сөз) + «Қауіпсіздік» карточкасы (міндетті).
2. **Болжам** — оқушы нәтижені болжайды (таңдау немесе қысқа мәтін). Бағаланбайды, соңында «Болжамың расталды ма?» деп салыстырылады.
3. **Құралдар мен модель** — қажетті құралдарды/реагенттерді таңдау (артық құралдар да бар — алаңдатқыштар).
4. **Тәжірибе** — интерактивті модель (5-бөлім).
5. **Бақылау** — бақылау кестесі: кейбір ұяшықтар модельден автоматты толады, кейбірін оқушы өзі толтырады.
6. **Талдау** — 2–4 сұрақ: таңдау, сандық есеп, сәйкестендіру.
7. **Қорытынды** — оқушы ғылыми тілмен 2–5 сөйлем жазады. AI көмекші құрылым ұсынады («Мақсат — Нәтиже — Түсіндіру»), бірақ дайын мәтін бермейді.
8. **Бағалау** — 100 ұпай (6-бөлім), кері байланыс, «Қайта орындау» батырмасы.

Барлық модельдік деректердің қасында белгі: **«Модель нәтижесі — нақты өлшенген дерек емес»**.

## 5. MVP тәжірибелердің нақты логикасы

Әр тәжірибенің есептеу логикасы **таза функциялар** түрінде `model.ts` файлында болсын және **Vitest тесттерімен** тексерілсін (төмендегі сандар — тест мәндері).

### 5.1. `mixture-separation` — Құм, тұз және су қоспасын бөлу (7-сынып)

**Бастапқы деректер (модель):** қоспа 20 г: құм 12 г + ас тұзы (NaCl) 8 г; су 100 мл.

**Құралдар (таңдау):** химиялық стакан ✓, шыны таяқша ✓, воронка + сүзгі қағаз ✓, фарфор табақша ✓, қыздырғыш (электр плитка) ✓, магнит ✗ (алаңдатқыш), тамызғыш ✗.

**Әрекеттер (оқушы ретін таңдайды, drag-and-drop немесе батырмалар):**
`еріту` (суға салып араластыру) → `сүзу` → `буландыру` (сүзіндіні) → `кептіру` (сүзгідегі құмды).

**Күй машинасы:** әр заттың орны көрсетіледі: `стакан`, `сүзгі қағаз`, `сүзінді`, `фарфор табақша`.

| Оқушы әрекеті | Модель нәтижесі | Кері байланыс |
|---|---|---|
| еріту → сүзу → буландыру | Құм сүзгіде, тұз табақшада кристал түрінде | Дұрыс |
| сүзу ерітуден бұрын | Құрғақ қоспа сүзгіде қалады, тұз да бөлінбейді | «Тұз әлі ерімеген — алдымен не істеу керек?» |
| буландыру бірінші | Су кетеді, құм мен тұз аралас қалады | «Буландыру ерімеген затты бөле ме?» |
| магнит қолдану | Ештеңе тартылмайды | «Құм мен тұз магнитке тартыла ма?» |

**Шығым (модель):** құм 11,8 г, тұз 7,7 г (аз шығын — сүзгіде, табақшада қалады).

**Бақылау кестесі:** зат · қайда қалды · массасы (г).

**Талдау сұрақтары (сандық, сервер тексереді, рұқсат ±1%):**
- Қоспадағы тұздың массалық үлесі: 8 / 20 = **40%**.
- Тұздың шығымы: 7,7 / 8 × 100 = **96,25%** (≈ 96%).
- Неге құм сүзгіде қалады? (таңдау: «суда ерімейді» ✓)

**Қауіпсіздік:** ыстық табақшаны қысқышпен ұстау; буландыру кезінде ерітіндіні шыны таяқшамен араластырып, шашыраудан сақтану; көзілдірік.

### 5.2. `atom-builder` — Атом құрылысы (8-сынып)

Оқушы `+/−` батырмаларымен протон (p), нейтрон (n), электрон (e) қосады. Модель атомды 2D-да салады: ядро (p қызыл, n сұр) және электрон қабаттары (сақиналар).

**Ережелер (Z = 1…20):**
- Элемент = протон санымен анықталады (Z = p). p = 0 болса — «Элемент жоқ».
- Массалық сан A = p + n.
- Заряд = p − e. Заряд 0 болса — «бейтарап атом», әйтпесе «ион» (мысалы Na⁺, Cl⁻).
- Электрондарды қабаттарға орналастыру (Z ≤ 20 үшін): 1-қабат ≤ 2, 2-қабат ≤ 8, 3-қабат ≤ 8, 4-қабат — қалғаны. Мысалы K: 2, 8, 8, 1; Ca: 2, 8, 8, 2.
- Нейтрон саны ең көп таралған изотопқа сәйкес келсе — «Тұрақты изотоп ✓», әйтпесе — «Бұл изотоп сирек немесе тұрақсыз».

|---|---|---|---|---|
| 1 | H | Сутек | 0 | 1 |
| 2 | He | Гелий | 2 | 4 |
| 3 | Li | Литий | 4 | 7 |
| 4 | Be | Бериллий | 5 | 9 |
| 5 | B | Бор | 6 | 11 |
| 6 | C | Көміртек | 6 | 12 |
| 7 | N | Азот | 7 | 14 |
| 8 | O | Оттек | 8 | 16 |
| 9 | F | Фтор | 10 | 19 |
| 10 | Ne | Неон | 10 | 20 |
| 11 | Na | Натрий | 12 | 23 |
| 12 | Mg | Магний | 12 | 24 |
| 13 | Al | Алюминий | 14 | 27 |
| 14 | Si | Кремний | 14 | 28 |

**Талдау:** «Атомның түрін не анықтайды?» (протон саны ✓); «Mg (Z=12) электрондары қабаттарға қалай таралады?» (2, 8, 2 ✓); «O²⁻ ионында неше электрон бар?» (10 ✓).

### 5.3. `indicator-lab` — Индикатор зертханасы (9-сынып)

**Белгісіз ерітінділер (A–F, әр жолы ретін араластыр).** pH-ты қозғалтқыш құрамы бойынша есептейді;

| Ерітінді (оқушыдан жасырын) | pH (модель) | Орта |
|---|---|---|
| Тұз қышқылы, 0,01 М | 2,0 | қышқыл |
| Лимон шырыны | 2,4 (өлшенген мән) | қышқыл |
| Дистилденген су | 7,0 | бейтарап |
| Ас тұзы (NaCl) ерітіндісі, 0,1 М | 7,0 | бейтарап |

**Индикаторлардың түсі (pH бойынша функция):**

| Индикатор | Түс ауысуы |
|---|---|
| Лакмус | pH < 4,5 — қызыл; 4,5–8,3 — күлгін; > 8,3 — көк |
| Фенолфталеин | pH < 8,2 — түссіз; 8,2–10 — ақшыл қызғылттан таңқурайға (біртіндеп); > 10 — таңқурай |

**Тәжірибе:** оқушы пробиркаға индикатор тамызады (тамшы анимациясы, түс біртіндеп өзгереді). Бір пробиркаға бірнеше индикатор сынауға болады (жаңа пробирка алады).

**Бақылау кестесі:** пробирка · индикатор · түс · орта (оқушы таңдайды: қышқыл / бейтарап / сілтілі).

**Талдау:** «Фенолфталеин қышқыл мен бейтарап ортаны неге ажырата алмайды?»; «Ас содасы мен NaOH-тың қайсысының pH-ы жоғары? Қай индикатор мұны көрсетеді?» (әмбебап ✓).

**Қауіпсіздік:** қышқыл мен сілтімен тек мұғалім бақылауымен, көзілдірік пен қолғаппен жұмыс; ерітіндіні дәмін татып немесе иіскеп тексермеу.

### 5.4. `reaction-rate` — Реакция жылдамдығы (9–10-сынып)

**Реакция:** Mg + 2HCl → MgCl₂ + H₂↑. Магний таспасы m = 0,05 г (шектеуші), қышқыл артық. Сутек көлемі газ шприцімен «өлшенеді» (модель).

**Модель (таза функция):**
- V_max = m / M(Mg) × V_m = 0,05 / 24,31 × 24,0 л/моль = **49,4 мл** (20 °C, 1 атм).
- k = k₀ · c · γ^((T − 20)/10), мұнда k₀ = 0,02 с⁻¹·М⁻¹, γ = 2 (Вант-Гофф ережесі, модельде 2 деп алынған).
  k₀, Mg массасы мен Вант-Гофф ережесі ортақ қозғалтқыштан алынады (3D зертханадағы Mg + HCl да осы заңмен жүреді);
  ChemLab-та колба термостатта (T тұрақты), қышқыл артық — сондықтан қозғалтқыштың теңдеуі осы формулаға келеді.
- V(t) = V_max · (1 − e^(−k·t)); бастапқы жылдамдық v₀ = V_max · k (мл/с); жартылай уақыт t½ = ln 2 / k.
- Параметр шектері: T = 10…50 °C (қадам 5), c(HCl) = 0,5…2,0 М (қадам 0,25); уақыт 0…300 с.

**Тест мәндері (Vitest):**

| T, °C | c, М | k, с⁻¹ | t½, с | V(30 с), мл | v₀, мл/с |
|---|---|---|---|---|---|
| 20 | 1,0 | 0,020 | 34,7 | 22,3 | 0,99 |
| 30 | 1,0 | 0,040 | 17,3 | 34,5 | 1,97 |
| 20 | 2,0 | 0,040 | 17,3 | 34,5 | 1,97 |
| 40 | 1,0 | 0,080 | 8,7 | 44,9 | 3,95 |

**Тәжірибе:** оқушы бір параметрді өзгертеді, «Бастау» басады → газ шприцінің поршені жылжиды, көпіршіктер анимациясы, график нақты уақытта сызылады. Әр жүгіртілім графикте жеке түспен қалады (ең көбі 4), салыстыруға болады. «Бір уақытта тек бір параметрді өзгерт» ережесі: екеуі де өзгерсе, ескерту шығады.

**Бақылау кестесі:** № · T · c · V(30 с) · t½ — модельден автоматты толады, оқушы V(30 с)-ты графиктен өзі оқып енгізеді (рұқсат ±1 мл).

**Талдау:** «Температураны 10 °C-қа көтергенде жылдамдық неше есе өсті?» (2 ✓); «Концентрацияны 2 есе арттырғанда t½ қалай өзгерді?» (2 есе азайды ✓); «Неге соңғы көлем барлық жағдайда бірдей?» (магний шектеуші ✓).

**Ескерту:** «Модельде γ = 2 деп алынған. Нақты реакцияларда γ әдетте 2–4 аралығында».

**Қауіпсіздік:** сутек жанғыш газ — от көзінен алыс; қышқылмен көзілдірік пен қолғаппен жұмыс.

### 5.5. `titration` — бұрынғы титрлеу зертханасы

Бұрын жасалған титрлеуді `LabShell`-ге көшір: мақсат, болжам («эквивалент нүктесінде pH қанша болады?»), тәжірибе (бар модель), бақылау кестесі (V(NaOH) → pH, 5 нүкте), талдау («эквивалент нүктесі неше мл?» → 25 ✓), қорытынды, бағалау.

## 6. Бағалау (100 ұпай)

| Критерий | Ұпай | Қалай есептеледі |
|---|---|---|
| Тәжірибені дұрыс орындау | 30 | Құралдар дұрыс таңдалды (10) + әрекеттер реті / мақсаттар орындалды (20). Әр қате әрекет −3, бірақ ≥ 0 |
| Бақылау нәтижелерін тіркеу | 25 | Кестедегі оқушы толтырған ұяшықтар модель мәнімен салыстырылады (рұқсат шегімен) |
| Есептеулер | 20 | Сандық жауаптарды **сервер** тексереді (рұқсат ±1–2%), бірлік те тексеріледі |
| Қорытынды және түсіндіру | 25 | AI рубрика бойынша алдын ала бағалайды (0–25) + қысқа кері байланыс; **мұғалім түзете алады**. AI баллы «алдын ала» деп белгіленеді |

- Бағалау тек серверде (`/api/labs/submit`). Дұрыс жауаптар клиентке жіберілмейді.
- Нәтиже бетінде: критерийлер бойынша жолақтар, «Болжамың расталды ма?», ұсыныс «Келесі қай тәжірибені жаса».

## 7. AI көмекші (тәжірибе ішіндегі «Ишара» батырмасы)

- Әр қадамда «Ишара алу» батырмасы. Ишара 3 деңгейлі: 1) бағыттаушы сұрақ, 2) нақтырақ кеңес, 3) шешімнің бірінші қадамы. Дайын жауапты бермейді.
- Қате жауапты «дұрыс» деп қабылдамайды: сандық тексеруді AI емес, **код** жасайды; AI тек түсіндіреді.
- Қорытынды қадамында: құрылым ұсынады (Мақсат → Нәтиже → Түсіндіру), оқушының мәтініне 2–3 нақты ескерту береді.
- Контекст ретінде AI-ға: сынып, тәжірибе slug, қадам, оқушының бақылау деректері беріледі (аты-жөні берілмейді).
- Бар AI Tutor инфрақұрылымын (`/api/ai/chat`, rate limit) қайта қолдан.

## 8. Деректер базасы (Supabase миграция)

```sql
-- lab_experiments: бар кестені кеңейту
alter table lab_experiments
  add column if not exists slug text unique,
  add column if not exists grade int[],          -- мысалы {9,10}
  add column if not exists topic text,
  add column if not exists status text default 'soon', -- 'ready' | 'soon'
  add column if not exists rubric jsonb;         -- {"procedure":30,"observation":25,"calc":20,"conclusion":25}

-- lab_attempts: бар кестені кеңейту
alter table lab_attempts
  add column if not exists prediction text,
  add column if not exists actions jsonb,        -- оқушы әрекеттерінің тізбегі
  add column if not exists observations jsonb,   -- бақылау кестесі
  add column if not exists answers jsonb,        -- талдау жауаптары
  add column if not exists conclusion text,
  add column if not exists score_total int,
  add column if not exists score_breakdown jsonb,
  add column if not exists ai_feedback text,
  add column if not exists teacher_override jsonb,
  add column if not exists completed_at timestamptz;
```
RLS: оқушы тек өз `lab_attempts`-ын көреді; мұғалім — өз сыныбындағы оқушылардың әрекеттерін. Каталогты `supabase/seed.sql`-ге қос.

## 10. Дизайн

- `design/prototype.html` стилі: ашық әдепкі, қараңғы режим, Unbounded / Manrope / JetBrains Mono.
- Сынып карталарының әрқайсысына өз акцент түсі: 7 — көгілдір, 8 — көк, 9 — таңқурай (индикатор), 10 — сары.

## 11. Қауіпсіздік және ғылыми дәлдік (міндетті)

- Әр тәжірибеде «Бұл — нақты зертханадағы жұмыстың оқу моделі» деген белгі.
- Қауіпті реактивтермен, улы газдармен, ашық отпен жұмыс істеудің нақты нұсқаулығы берілмейді; қажет жерде тек қауіпсіз визуалды модель.
- Модельденген деректер «өлшенген дерек» ретінде көрсетілмейді.
- Барлық реакция теңдеулері, сандар және оқу мақсаттары мұғалім тексеруінен өтеді: `model.test.ts` тесттері осы құжаттағы мәндермен сәйкес болуы керек.

## 12. Қабылдау критерийлері

1. `/virtual-lab` ішінде 7–10-сынып карталары, әр сыныпта каталог (ready + soon карточкалар).
2. 5 тәжірибе (`mixture-separation`, `atom-builder`, `indicator-lab`, `reaction-rate`, `titration`) 8 қадамның бәрімен басынан аяғына дейін өтеді.
3. Бағалау серверде, 100 ұпай критерийлер бойынша бөлініп көрсетіледі.
4. `npm run test` — барлық `model.test.ts` өтеді; `npm run build` қатесіз.
5. Телефонда (390px) барлық қадам ыңғайлы.
6. Мұғалім `/teacher/labs`-та тәжірибені сыныпқа бере алады және нәтижелерді көреді.
