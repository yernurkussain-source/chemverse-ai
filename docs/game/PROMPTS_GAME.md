# Virtual Lab ойынын Claude Code-қа жіберу: 4 сессия

Әр сессияны жаңа чатта бастаңыз («New session»), режимді **Plan** етіп қойыңыз: Claude алдымен жоспар көрсетеді, оқып шығып қабылдайсыз.
Әр сессиядан кейін `npm run dev` арқылы `/game` бетін ашып тексеріңіз.

Алдымен `CLAUDE.md` файлының соңына мына жолды қосыңыз:
```
- 3D ойын (Virtual Lab): docs/game/GAME_SPEC.md, жұмыс істейтін прототип: docs/game/prototype/virtual-lab.html
```

---

## 1-сессия · Химия қозғалтқышын TypeScript-ке көшіру
```
@CLAUDE.md @docs/game/GAME_SPEC.md @docs/game/prototype/engine.js @docs/game/prototype/engine.test.js оқы.
Бұл сессияда тек химия қозғалтқышы: engine.js-ті src/features/chem-engine/ ішіне TypeScript модульдеріне көшір (GAME_SPEC 3-бөлім).
Формулалар мен константаларды өзгертпе. engine.test.js-тегі 13 тексерісті Vitest-ке дәл сол сандармен көшір, npm run test арқылы барлығы өтетінін көрсет.
UI-ге тиме. Соңында build + commit.
```

## 2-сессия · /game беті: бөлме, жүру, алу және құю
```
@CLAUDE.md @docs/game/GAME_SPEC.md оқы, @docs/game/prototype/virtual-lab.html прототипін зертте.
src/features/virtual-lab-3d/ құрылымын жаса (GAME_SPEC 3-бөлім) және /game бетін аш (dynamic import, ssr:false).
Бұл сессияда: бөлме, шкафтар (есіктері ашылады), үстел, плитка, штативтер, барлық бөтелкелер мен ыдыстар; бірінші жақтан жүру (WASD + тышқан, pointer lock + сүйреп қарау), коллизия;
оң қолмен алу/қою/басып тұрып құю; қарап тұрған ыдыстың HUD карточкасы. Химияны тек src/features/chem-engine арқылы есепте.
three-тің жаңа нұсқасындағы түс пен жарық өзгерістерін ескеріп, көріністі прототипке ұқсат. Скриншотпен салыстыруға қалай ашатынымды айт. Соңында build + commit.
```

## 3-сессия · Барлық құралдар, екі қол, дыбыс, тапсырмалар
```
@CLAUDE.md @docs/game/GAME_SPEC.md оқы, прототипті негізге ал.
Қос: сол қол (F / оң батырма, Z), сол қолдағы ыдысқа құю; тамызғыш пен қатты заттар; воронка және сүзу; газ өткізгіш түтік; шырпы (жағу, бықсу, поп, сөну, қайта жану);
бюретка (кран 3 күй, көрсеткіш, эквивалент нүктесі); спиртовка мен нихром сым (жалын түсі, Na⁺ жасыруы, HCl-мен тазалау);
қорғаныс құралдары және айыптар; синтезделген дыбыстар (audio/snd.ts); журнал; 22 тапсырма мен XP (zustand дүкені).
Прототиптегі decide() кестесін interaction/decide.ts-ке ауыстыр. Әр құралды тексеріп, нәтижесін тізіммен көрсет. Соңында build + commit.
```

## 4-сессия · Телефон, өнімділік, тілдер, прогресс
```
@CLAUDE.md @docs/game/GAME_SPEC.md оқы.
1) Телефон басқаруы: джойстик, сүйреп қарау, ОҢ ҚОЛ / СОЛ ҚОЛ / Орнына батырмалары; HUD телефонда ыңғайлы болсын.
2) Өнімділік: «Сапа» баптауы (көлеңке қосу/өшіру), pixelRatio шегі; 4-бөлімдегі мақсаттарды тексеру жолын айт.
3) Барлық мәтінді messages/kk.json және ru.json файлдарына шығар.
4) Прогресті Supabase-ке сақта (lab_game_progress + RLS), кірмеген пайдаланушыға localStorage.
5) /virtual-lab бетіне «3D зертхана» карточкасын қос, /game-ге апарсын.
GAME_SPEC 5-бөліміндегі қабылдау критерийлерін бір-бірлеп тексеріп, тізім етіп көрсет. Соңында build + commit.
```

## Кеңестер
- Прототипті браузерде ашып салыстыру: `docs/game/prototype/virtual-lab.html` файлын екі рет басыңыз (интернет керек — three.js CDN-нен жүктеледі).
- Химияға қатысты бір нәрсе дұрыс емес болса, Claude-қа айтыңыз: «алдымен осы жағдайға тест жаз, сосын түзет».
- Сессия ұзарып кетсе, жаңасын ашып: «@CLAUDE.md @docs/game/GAME_SPEC.md оқы, кеше X бітті, енді Y» деп жалғастырыңыз.
