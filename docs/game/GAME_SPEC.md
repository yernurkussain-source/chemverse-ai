## 2. Химия қозғалтқышы — ең маңызды бөлік

`engine.js` — DOM-сыз таза функциялар. Ол **ChemLab (2D) пен 3D ойынға ортақ** болуы керек: бір ғылыми модель, екі интерфейс.

- Иондар мен тұнбалар моль бойынша есептеледі; әр қосудан кейін `equilibrate()` лездік реакцияларды (бейтараптану, карбонат → гидрокарбонат → CO₂, 13 тұнба, тұнбалардың қышқылда еруі, амфотерлік) тепе-теңдікке дейін жүргізеді.
- `pH()` — күшті қышқыл/негіз артығы, әлсіз қышқыл катиондар (Fe³⁺, Cu²⁺, Zn²⁺, Fe²⁺), карбонат буфері (10,33 + lg), гидрокарбонат 8,34.
- Жылу: бейтараптану −57,1 кДж/моль; Mg −466,9; Zn −153,9; Fe −89,1; H₂O₂ ыдырауы −98 кДж/моль; судың жылу сыйымдылығы 4,18 Дж/(г·К) + шыны 40 Дж/К.
- Жылдамдық: металл + H⁺ бірінші ретті, Вант-Гофф γ = 2; ығыстыру реакциялары (Fe/Zn/Mg + Cu²⁺, металдар + Ag⁺); MnO₂ катализі (k = 0,035 с⁻¹).
- Газ: `gasOut` → ыдыстың аузында жиналады (пробирка τ = 30 с, стакан τ = 8 с) немесе түтік арқылы B ыдысына өтеді; `absorbCO2()` — әк суы (OH⁻ арқылы тез, артық CO₂ баяу, 12 %).
- `transfer(src, dst, mL, sink)` — құю/сүзу; `sink` берілсе тұнба сүзгі қағазына жиналады; ыдыс босағанда шөккен тұнба да ауысады.
- Буландыру → `residueOf()` катион мен анионды жұптап, тұз формуласы мен массасын береді.

**Ережелер:** қозғалтқышты TypeScript-ке көшіргенде формулалар мен константаларды өзгертпе; `engine.test.js`-тегі 13 тексерісті Vitest-ке дәл сол сандармен көшір. Жаңа реакция қосылса — алдымен тест, сосын код.

**ChemLab-пен ортақ (орындалды):** ChemLab-тың титрлеуі, индикатор зертханасы және реакция жылдамдығы осы қозғалтқышты
қолданады (`tests/chemlab-engine.test.ts`). Бір модель болу үшін Mg + HCl жылдамдық тұрақтысы ChemLab-тағыдай
k = 0,02 деп алынды (прототипте 0,03 еді; 3D-дегі t½ 18,5 → 27,7 с). «Қоспаларды бөлу» мен «Атом құрастыру»
ерітінді химиясын қолданбайды.

**Белгілі жеңілдетулер (интерфейсте «оқу моделі» деп жазылады):** CO₂ толық ұшқаннан кейін pH 7 (шындығында ≈ 5); H₂SO₄ екінші сатысы толық; сұйықтық физикасы есептелмейді.

- **Three.js-ті императивті түрде қалдыр** (прототиптегідей), React тек HUD үшін. Ойын циклі React рендерінен тыс; HUD дүкеннен (zustand) секундына ~6 рет жаңарады. React Three Fiber-ге көшіру міндетті емес — тәуекелі көп.
- `three` npm пакетінің қазіргі нұсқасын қолдан. Прототип r128 глобал нұсқасында жазылған, сондықтан көшіргенде мыналарды тексер (нақты өзгерістерді three.js ресми migration нұсқаулығынан қара):
  - `renderer.outputEncoding = sRGBEncoding` → `renderer.outputColorSpace = SRGBColorSpace`; `texture.encoding` → `texture.colorSpace`;
  - жаңа нұсқаларда түстерді басқару әдепкі қосулы — прототиптегі `convertSRGBToLinear()` көмекшісі артық болуы мүмкін;
  - жарық қарқындылығының бірліктері өзгерген (physically correct lighting) — жарықтарды прототиптегі көрініске сай қайта баптау керек;
  - мысал модульдері `three/addons/...` арқылы импортталады.
- Барлық интерфейс мәтіні `messages/kk.json` және `messages/ru.json` файлдарына (қазір прототипте қазақша кодқа жазылған). Химиялық теңдеулер аударылмайды.
- Прогресті сақтау: Supabase `lab_game_progress` (user_id, xp, safety, quests_done jsonb, updated_at) + RLS; кірмеген пайдаланушыға localStorage (try/catch).
- Мұғалім режимі (кейін): мұғалім тапсырма жинағын береді, нәтижесі `/teacher`-де көрінеді.

## 4. Өнімділік және құрылғылар

- Компьютерде 60 кадр/с, орташа телефонда ≥ 30 кадр/с мақсат.
- Телефонда: pixelRatio ≤ 1,5; көлеңке картасы 1024; әлсіз құрылғыда көлеңкені өшіретін «Сапа» баптауы.
- Мөлдір материалдардың `renderOrder`-ін сақта (сұйықтық 1–3, шыны 4–6) — әйтпесе шыны артындағы сұйықтық жоғалады.
- Ойын беті ашылғанда ғана жүктелсін (dynamic import), басты бетті ауырлатпасын.

## 5. Қабылдау критерийлері

1. `npm run test` — химия қозғалтқышының барлық тесті өтеді (13+).
2. `/game` беті ашылады, қате жоқ (консоль таза), `npm run build` өтеді.
3. 22 тапсырманың әрқайсысын ойнап орындауға болады (тізімі прототиптегі `QUESTS`).
4. Компьютерде де, телефонда да басқару жұмыс істейді (pointer lock болмаса — сүйреп қарау).
5. Дыбысты өшіруге болады; `prefers-reduced-motion` ескеріледі.
6. Прогресс кірген пайдаланушы үшін сақталады.
7. ChemLab (`docs/chemlab/CHEMLAB_SPEC.md`) осы ортақ қозғалтқышты қолданады — екі жерде бөлек химия коды жоқ.

## 6. Келешек идеялар (міндетті емес)

- WebXR: VR шлемде қолмен (hand tracking) жұмыс.
- Электролиз, айдау (дистилляция), хроматография.
- Сыныппен бірге ойнау (Supabase Realtime): бір зертхана, бірнеше оқушы.
- ChemLab бағалауымен (100 ұпай) байланыстыру: ойындағы тәжірибе мұғалімге есеп болып барады.
