# Химия 9-сынып · VIII тарау (2-бөлігі). 15(VA) және 14(IVA) топ элементтері: азот, фосфор, кремний

> Оқулық: Оспанова М.Қ., Аухадиева Қ.С., Белоусова Т.Г. Химия: 9-сынып, 2-бөлім. — Алматы: Мектеп, 2019. Мәтін — оқулық тақырыптары бойынша өз сөзімізбен жазылған конспект. Жақшадағы бет — параграфтың басталатын беті.

## §36. 15(VA) топ элементтері. Азот (9-сынып 2-бөлім, 30-б.)

15(VA) топ: азот N, фосфор P, мышьяк As, сурьма Sb, висмут Bi. Сыртқы деңгейде 5 электрон (ns²np³). Тотығу дәрежелері −3-тен +5-ке дейін. Топ бойымен төмен қарай бейметалдық қасиеттер әлсіреп, металдық қасиеттер күшейеді (висмут — металл). Сутекті қосылыстары RH₃ (NH₃, PH₃), жоғары оксидтері R₂O₅.

Азот: Z = 7, 1s²2s²2p³ — үш жұптаспаған p-электрон. Тотығу дәрежелері: −3 (NH₃), 0 (N₂), +1 (N₂O), +2 (NO), +3 (N₂O₃, HNO₂), +4 (NO₂), +5 (N₂O₅, HNO₃). Валенттілігі ең көбі IV.

Табиғатта: ауаның көлемі бойынша 78%-ы азот. Қосылыстар түрінде — селитралар (NaNO₃, KNO₃), барлық белоктар мен нуклеин қышқылдарының құрамында.

N₂ молекуласы: үш еселі байланыс N≡N — өте берік, сондықтан азот қалыпты жағдайда инертті.

Физикалық қасиеттері: түссіз, иіссіз, дәмсіз газ, ауадан сәл жеңіл, суда нашар ериді, −196 °C-та сұйылады.

Алу: өнеркәсіпте — сұйық ауаны айдау; зертханада — аммоний нитритін қыздыру: NH₄NO₂ → N₂ + 2H₂O.

Химиялық қасиеттері (тек қатаң жағдайда):
литиймен бөлме температурасында, басқа белсенді металдармен қыздырғанда нитридтер түзеді: 6Li + N₂ → 2Li₃N; 3Mg + N₂ → Mg₃N₂ (тотықтырғыш);
сутекпен: N₂ + 3H₂ ⇄ 2NH₃ (қысым, катализатор, қыздыру);
оттекпен электр разрядында немесе ≈ 3000 °C-та: N₂ + O₂ ⇄ 2NO (тотықсыздандырғыш); найзағай кезінде табиғи түрде жүреді.

Азот оксидтері: N₂O — «күлдіргіш газ» (наркоз); NO — түссіз, ауада бірден қоңыр NO₂-ге айналады: 2NO + O₂ → 2NO₂; NO₂ — қоңыр, улы газ, сумен: 4NO₂ + O₂ + 2H₂O → 4HNO₃.

Табиғаттағы азот айналымы: түйнек бактериялары (бұршақ тұқымдас өсімдіктер тамырында) және найзағай атмосфералық азотты байланыстырады; өсімдіктер нитраттарды сіңіріп, белок түзеді; жануарлар өсімдікпен қоректенеді; шірік бактериялары қалдықтарды аммиакқа, нитрификациялаушы бактериялар нитраттарға, денитрификациялаушылар қайта N₂-ге айналдырады.

Қолданылуы: аммиак синтезі, азот тыңайтқыштары; инертті орта (тағам орау, шамдар, мұражай экспонаттарын сақтау); сұйық азот — медицинада (криотерапия), биоматериалдарды сақтау.

## §37. Аммиак. Аммоний тұздары (9-сынып 2-бөлім, 33-б.)

Аммиак NH₃ — пирамида пішінді молекула, N–H байланыстары коваленттік полюсті, азотта бір бөлінбеген электрон жұбы бар. Түссіз, өткір иісті газ, ауадан екі есе жеңіл, суда өте жақсы ериді (1 көлем суда ≈ 700 көлем). Оңай сұйылады; сұйық аммиак буланғанда көп жылу жұтады — тоңазытқыш қондырғыларда қолданылады.

Алу: зертханада — аммоний тұзын сілтімен (әкпен) қыздыру: 2NH₄Cl + Ca(OH)₂ → CaCl₂ + 2NH₃↑ + 2H₂O. Ауадан жеңіл болғандықтан, ыдыстың аузын төмен қаратып жинайды. Анықтау: дымқыл қызыл лакмус қағазы көгереді; тұз қышқылы тамызылған таяқшаны жақындатқанда ақ «түтін» (NH₄Cl) пайда болады.
Өнеркәсіпте (Габер–Бош әдісі): N₂ + 3H₂ ⇄ 2NH₃ + Q; жоғары қысым, ≈ 450–500 °C, кеуекті темір катализаторы, әрекеттеспеген газдар циркуляцияға қайтарылады.

Химиялық қасиеттері:
сумен: NH₃ + H₂O ⇄ NH₃·H₂O ⇄ NH₄⁺ + OH⁻ — әлсіз негіздік орта (нашатыр спирті — 10%-дық ерітінді);
қышқылдармен аммоний тұздарын түзеді: NH₃ + HCl → NH₄Cl; 2NH₃ + H₂SO₄ → (NH₄)₂SO₄; NH₃ + HNO₃ → NH₄NO₃ (донор-акцепторлық механизм: азоттың бос жұбы H⁺-ға беріледі);
тотықсыздандырғыш (N⁻³): оттекте жанады — 4NH₃ + 3O₂ → 2N₂ + 6H₂O; платина катализаторымен тотығады — 4NH₃ + 5O₂ → 4NO + 6H₂O (азот қышқылы өндірісінің бірінші сатысы); металл оксидтерін тотықсыздандырады: 3CuO + 2NH₃ → 3Cu + N₂ + 3H₂O.

Аммоний тұздары — иондық кристалды заттар, суда жақсы ериді. Қыздырғанда айырылады: NH₄Cl → NH₃ + HCl; NH₄NO₃ → N₂O + 2H₂O. Аммоний ионына сапалық реакция: сілтімен қыздырғанда аммиак иісі: NH₄⁺ + OH⁻ → NH₃↑ + H₂O.

Қолданылуы: азот тыңайтқыштары (аммиак селитрасы, мочевина, аммоний сульфаты), азот қышқылы, сода өндірісі, тоңазытқыштар, медицина (нашатыр спирті), NH₄Cl — дәнекерлеуде металды тазарту.

## §38. Азот қышқылы (9-сынып 2-бөлім, 37-б.)

Азот қышқылы HNO₃ — түссіз, ауада «түтіндейтін» ұшқыш сұйықтық, өткір иісті. Жарықта және қыздырғанда ішінара айырылады, сондықтан ерітінді сарғыш тартады: 4HNO₃ → 4NO₂ + O₂ + 2H₂O. Қара шыны ыдыста, салқын жерде сақталады.

Алу:
өнеркәсіпте (аммиактан) үш сатыда: 1) 4NH₃ + 5O₂ → 4NO + 6H₂O (Pt–Rh катализатор); 2) 2NO + O₂ → 2NO₂; 3) 4NO₂ + O₂ + 2H₂O → 4HNO₃;
зертханада — натрий селитрасына концентрлі күкірт қышқылымен әсер етіп, әлсіз қыздыру: NaNO₃ + H₂SO₄(конц) → NaHSO₄ + HNO₃↑.

Күшті бір негізді қышқыл ретінде жалпы қасиеттері: индикатор түсін өзгертеді; негіздік оксидтермен (CuO + 2HNO₃ → Cu(NO₃)₂ + H₂O), негіздермен (NaOH + HNO₃ → NaNO₃ + H₂O), әлсіз қышқылдардың тұздарымен (CaCO₃ + 2HNO₃ → Ca(NO₃)₂ + H₂O + CO₂↑) әрекеттеседі. Тұздары — нитраттар.

## §39. Азот қышқылы мен нитраттардың өзіне тән қасиеттері (9-сынып 2-бөлім, 40-б.)

Азот қышқылы — күшті тотықтырғыш (N⁺⁵ есебінен). Металдармен әрекеттескенде сутек бөлінбейді — азоттың тотықсыздану өнімдері түзіледі. Өнім қышқыл концентрациясы мен металл белсенділігіне байланысты:
концентрлі HNO₃ + белсенділігі төмен металл → NO₂: Cu + 4HNO₃(конц) → Cu(NO₃)₂ + 2NO₂↑ + 2H₂O (қоңыр газ);
сұйылтылған HNO₃ + белсенділігі төмен металл → NO: 3Cu + 8HNO₃(сұйыл) → 3Cu(NO₃)₂ + 2NO↑ + 4H₂O;
белсенді металдармен (Mg, Zn) өте сұйылтылған қышқыл N₂O, N₂ немесе NH₄NO₃ түзе алады: 4Zn + 10HNO₃ → 4Zn(NO₃)₂ + NH₄NO₃ + 3H₂O.
Суық концентрлі HNO₃ темір, алюминий, хромды пассивтейді. Алтын мен платина азот қышқылында ерімейді, бірақ «патша сұйығында» (1 көлем конц. HNO₃ + 3 көлем конц. HCl) ериді.

Бейметалдарды тотықтырады: C + 4HNO₃ → CO₂ + 4NO₂ + 2H₂O; S + 6HNO₃ → H₂SO₄ + 6NO₂ + 2H₂O. Органикалық заттарды бұзады (теріге тисе, белоктар сары түске боялады — ксантопротеин реакциясы).

Нитраттар — суда жақсы еритін тұздар. Қыздырғанда айырылуы металдың белсенділігіне байланысты:
белсенді металдар (Mg-ге дейін): нитрит + O₂ — 2KNO₃ → 2KNO₂ + O₂↑;
Mg-ден Cu-ға дейін: оксид + NO₂ + O₂ — 2Cu(NO₃)₂ → 2CuO + 4NO₂↑ + O₂↑;
Cu-дан кейін: металл + NO₂ + O₂ — 2AgNO₃ → 2Ag + 2NO₂↑ + O₂↑.
Нитраттар оттек бөлетіндіктен, жанғыш заттармен қоспасы жарылғыш: қара оқ-дәрі — KNO₃ + S + C.

Нитрат ионын анықтау: мыс жаңқасы мен концентрлі күкірт қышқылымен қыздыру — көк ерітінді және қоңыр газ NO₂.

Селитралар — азот тыңайтқыштары: NaNO₃, KNO₃, Ca(NO₃)₂, NH₄NO₃. Нитраттарды тыңайтқыш ретінде шамадан тыс қолдану көкөністер мен ауыз суда олардың жиналуына әкеледі (денсаулыққа зиянды).

## §40. Фосфор (9-сынып 2-бөлім, 44-б.)

Фосфор: 3-период, 15(VA) топ, Z = 15, 1s²2s²2p⁶3s²3p³. Тотығу дәрежелері −3 (PH₃, Ca₃P₂), +3 (P₂O₃), +5 (P₂O₅, H₃PO₄). Азотқа қарағанда бейметалдық қасиеті әлсіз, бірақ химиялық белсенді (P≡P сияқты берік байланыс түзбейді).

Табиғатта тек қосылыстар түрінде: фосфориттер және апатиттер (негізгі құрамы Ca₃(PO₄)₂). Қазақстанда Қаратау фосфорит алабы — әлемдегі ірі кен орындарының бірі; Тараз және Шымкент өңірлерінде фосфор өнеркәсібі дамыған. Фосфор сүйек пен тіс (кальций фосфаты), ДНҚ, АТФ (энергия тасымалдаушы) құрамында болады.

Алу: фосфоритті құм мен кокспен электр пешінде ≈ 1500 °C-та қыздыру: Ca₃(PO₄)₂ + 3SiO₂ + 5C → 3CaSiO₃ + 2P + 5CO.

Аллотропиясы:
ақ фосфор — P₄ молекулалары, балауыз тәрізді, жұмсақ, сарымсақ иісті, өте улы, ауада өздігінен тұтанады (су астында сақталады), қараңғыда жасылдау жарқырайды (хемилюминесценция);
қызыл фосфор — полимерлі құрылымды қызыл-қоңыр ұнтақ, улы емес, ауада тұрақты, 260 °C-тан жоғары тұтанады; сіріңке қорабының бүйіріндегі жаққыш қабатта;
қара фосфор — қатты қысымда алынады, металға ұқсас жылтыры бар, ток өткізеді.

Химиялық қасиеттері:
оттекпен: 4P + 5O₂ → 2P₂O₅ (артық оттекте; ақ түтін); 4P + 3O₂ → 2P₂O₃ (оттек жетіспесе);
галогендермен: 2P + 3Cl₂ → 2PCl₃; 2P + 5Cl₂ → 2PCl₅;
металдармен (тотықтырғыш): 3Ca + 2P → Ca₃P₂ (фосфид); фосфидтер сумен фосфин түзеді: Ca₃P₂ + 6H₂O → 3Ca(OH)₂ + 2PH₃↑ (улы газ);
күшті тотықтырғыштармен: 6P + 5KClO₃ → 3P₂O₅ + 5KCl (сіріңке тұтануы).

Қолданылуы: сіріңке, фосфор қышқылы мен тыңайтқыштар, түтін шымылдығы, жартылай өткізгіштер, металл құймалары.

## §41. Ортофосфор қышқылы және оның тұздары (9-сынып 2-бөлім, 51-б.)

Фосфор(V) оксиді P₂O₅ — ақ гигроскопиялық ұнтақ, ең жақсы кептіргіштердің бірі. Қышқылдық оксид: P₂O₅ + 3H₂O → 2H₃PO₄ (ыстық суда); суықта метафосфор қышқылы HPO₃ түзіледі.

Ортофосфор қышқылы H₃PO₄ — түссіз қатты кристалды зат (42 °C-та балқиды), суда кез келген қатынаста ериді. Ұшқыш емес, тотықтырғыштық қасиеті жоқ. Орта күшті үш негізді қышқыл, сатылап диссоциацияланады: H₃PO₄ ⇄ H⁺ + H₂PO₄⁻ ⇄ 2H⁺ + HPO₄²⁻ ⇄ 3H⁺ + PO₄³⁻.

Алу: экстракциялық әдіс — Ca₃(PO₄)₂ + 3H₂SO₄ → 3CaSO₄↓ + 2H₃PO₄; термиялық әдіс — фосфорды жағып, P₂O₅-ті суда еріту.

Қасиеттері: қышқылдардың жалпы қасиеттері — белсенді металдармен, негіздік оксидтермен, негіздермен, тұздармен әрекеттеседі. Сілтінің мөлшеріне қарай үш түрлі тұз түзеді:
H₃PO₄ + NaOH → NaH₂PO₄ + H₂O (дигидрофосфат);
H₃PO₄ + 2NaOH → Na₂HPO₄ + 2H₂O (гидрофосфат);
H₃PO₄ + 3NaOH → Na₃PO₄ + 3H₂O (фосфат).

Тұздарының ерігіштігі: барлық дигидрофосфаттар суда ериді; гидрофосфаттар мен фосфаттардың тек натрий, калий, аммоний тұздары ериді. Фосфат ионына сапалық реакция: 3Ag⁺ + PO₄³⁻ → Ag₃PO₄↓ — сары тұнба, азот қышқылында ериді.

Қолданылуы: тыңайтқыштар, тағам өнеркәсібі (сусындарға қышқылдылық беретін қоспа Е338), металдарды жемірілуден қорғайтын фосфаттау, жуғыш заттар, дәрілер.

## §42. Минералды тыңайтқыштар (9-сынып 2-бөлім, 54-б.)

Тыңайтқыштар — өсімдікке қажетті қоректік элементтері бар заттар. Өсімдік әсіресе азотты (N), фосфорды (P) және калийді (K) көп қажет етеді — бұлар макроқоректік элементтер. Микротыңайтқыштар: бор, мыс, марганец, мырыш, молибден қосылыстары.

Азот тыңайтқыштары (өсуді, жапырақ пен сабақтың дамуын қамтамасыз етеді): аммиак селитрасы NH₄NO₃ (ω(N) = 35%), мочевина (карбамид) CO(NH₂)₂ (ω(N) ≈ 46,7% — ең жоғары), аммоний сульфаты (NH₄)₂SO₄ (21%), натрий және кальций селитралары, сұйық аммиак, аммиак суы.

Фосфор тыңайтқыштары (тамыр жүйесінің дамуына, гүлдеу мен жеміс салуға қажет): фосфорит ұны Ca₃(PO₄)₂ (тек қышқыл топыраққа), жай суперфосфат Ca(H₂PO₄)₂ + 2CaSO₄, қос суперфосфат Ca(H₂PO₄)₂, преципитат CaHPO₄·2H₂O, сүйек ұны.
Жай суперфосфат алу: Ca₃(PO₄)₂ + 2H₂SO₄ → Ca(H₂PO₄)₂ + 2CaSO₄.
Фосфор тыңайтқыштарының құндылығын әдетте P₂O₅-ке шаққандағы массалық үлеспен бағалайды.

Калий тыңайтқыштары (өсімдіктің ауруға, суыққа, құрғақшылыққа төзімділігін, крахмал мен қант жиналуын арттырады): калий хлориді KCl, сильвинит KCl·NaCl, калий сульфаты K₂SO₄, ағаш күлі (K₂CO₃).

Кешенді тыңайтқыштар (бірнеше қоректік элемент): аммофос NH₄H₂PO₄ + (NH₄)₂HPO₄, нитрофоска, калий селитрасы KNO₃.

Органикалық тыңайтқыштар: көң, компост, шымтезек, құс саңғырығы.

Тыңайтқыштарды дұрыс пайдалану: топырақ талдауына сай нормада, дұрыс мерзімде енгізу. Шамадан тыс енгізу нитраттардың өнімде жиналуына, су қоймаларының ластануына және «гүлденуіне», топырақ құрылымының бұзылуына әкеледі.

Есептеу мысалы: мочевинадағы азоттың массалық үлесі. M(CO(NH₂)₂) = 12 + 16 + 2·(14 + 2) = 60 г/моль; ω(N) = 28/60 ≈ 46,7%.

## §43. 14(IVA) топ элементтері. Кремний (9-сынып 2-бөлім, 56-б.)

14(IVA) топ: көміртек C, кремний Si, германий Ge, қалайы Sn, қорғасын Pb. Сыртқы деңгейінде 4 электрон (ns²np²). Тотығу дәрежелері −4, +2, +4. Топ бойымен төмен қарай бейметалдық қасиеттер әлсіреп, металдық қасиеттер күшейеді: C, Si — бейметалдар; Ge — жартылай өткізгіш; Sn, Pb — металдар. Жоғары оксидтері RO₂, сутекті қосылыстары RH₄ (CH₄, SiH₄).

Кремний: 3-период, Z = 14, 1s²2s²2p⁶3s²3p². Қосылыстарда көбіне +4 (SiO₂), металдармен −4 (Mg₂Si).

Табиғатта: Жер қыртысындағы таралуы бойынша оттектен кейінгі екінші элемент (≈ 27%). Бос күйінде кездеспейді. Негізгі қосылыстары: кремнезем SiO₂ (кварц, құм, тау хрусталі, аметист, агат, яшма, опал) және силикаттар мен алюмосиликаттар (дала шпаттары, слюда, саз, каолин) — көптеген тау жыныстарының негізі.

Алу: өнеркәсіпте — кремнеземді кокспен электр пешінде тотықсыздандыру: SiO₂ + 2C → Si + 2CO; зертханада — магниймен: SiO₂ + 2Mg → Si + 2MgO.

Физикалық қасиеттері: кристалды кремний — сұр түсті, металдық жылтыры бар, қатты әрі морт, алмаз тәрізді атомдық торы бар; жартылай өткізгіш (электр өткізгіштігі қыздырғанда және жарықтандырғанда артады).

Химиялық қасиеттері (қалыпты жағдайда инертті, қыздырғанда белсенді):
оттекпен: Si + O₂ → SiO₂;
галогендермен: Si + 2F₂ → SiF₄ (бөлме температурасында); Si + 2Cl₂ → SiCl₄ (қыздырғанда);
көміртекпен: Si + C → SiC (карборунд — алмазға жақын қатты абразив);
металдармен (тотықтырғыш): Si + 2Mg → Mg₂Si; силицидтер қышқылдармен силан бөледі: Mg₂Si + 4HCl → 2MgCl₂ + SiH₄↑ (ауада өздігінен тұтанады);
сілтілермен: Si + 2NaOH + H₂O → Na₂SiO₃ + 2H₂↑.
Қышқылдармен (HF және HNO₃ қоспасынан басқа) әрекеттеспейді.

Қолданылуы: жартылай өткізгіш құралдар (микросхемалар, транзисторлар, процессорлар), күн батареялары, кремнийлі болаттар мен құймалар (ферросилиций), силикондар.

## §44. Кремний қосылыстары: кремний(IV) оксиді (9-сынып 2-бөлім, 60-б.)

Кремний(IV) оксиді SiO₂ (кремнезем) — атомдық кристалдық торы бар қатты, өте қиын балқитын (≈ 1700 °C) зат; суда ерімейді. Әр кремний атомы төрт оттек атомымен тетраэдр түзеді, әр оттек екі кремний атомын байланыстырады. Сондықтан SiO₂ — молекула емес, полимер; оның қасиеттері CO₂-ден мүлде өзгеше (CO₂ — молекулалық торлы газ).

Түрлері: кварц, құм (қоспалары бар SiO₂), тау хрусталі (таза мөлдір кварц), түсті түрлері — аметист (күлгін), раухтопаз (қоңыр); агат, яшма, опал — аморфты және ұсақ кристалды түрлері. Диатомит (трепел) — микроорганизмдер қалдығынан түзілген.

Химиялық қасиеттері — қышқылдық оксид (бірақ сумен әрекеттеспейді):
сілтілермен балқытқанда: SiO₂ + 2NaOH → Na₂SiO₃ + H₂O;
негіздік оксидтермен балқытқанда: SiO₂ + CaO → CaSiO₃;
карбонаттармен балқытқанда (CO₂-ні ығыстырады, өйткені SiO₂ ұшқыш емес): SiO₂ + Na₂CO₃ → Na₂SiO₃ + CO₂↑;
балқытқыш қышқылмен (шыны ою): SiO₂ + 4HF → SiF₄↑ + 2H₂O;
кокспен, магниймен тотықсызданады.

Қолданылуы: шыны, цемент, керамика өндірісі; кварц шыны — ыстыққа және ультракүлгінге төзімді (кварц шамдары, зертханалық ыдыстар); оптика (призмалар, линзалар); пьезокристалдар (кварц сағаттары); зергерлік тастар; құрылыста құм; оптикалық талшықтар.

## §45. Кремний қышқылы және оның тұздары. Силикат өнеркәсібі (9-сынып 2-бөлім, 63-б.)

Кремний қышқылы H₂SiO₃ (шартты формула; құрамы nSiO₂·mH₂O) — өте әлсіз, суда ерімейтін қышқыл. Оксидтің сумен әрекеттесуі арқылы алынбайды; оны еритін силикатқа күштірек қышқылмен әсер етіп алады: Na₂SiO₃ + 2HCl → 2NaCl + H₂SiO₃↓ (іркілдек тұнба); тіпті көмір қышқылы да ығыстырады: Na₂SiO₃ + CO₂ + H₂O → Na₂CO₃ + H₂SiO₃↓. Қыздырғанда айырылады: H₂SiO₃ → SiO₂ + H₂O. Кептірілген гелі — силикагель — адсорбент және кептіргіш.

Силикаттар — кремний қышқылының тұздары. Суда тек натрий мен калий силикаттары ериді; олардың концентрлі ерітіндісі — «сұйық шыны» (кеңсе желімі, ағаш пен матаны отқа төзімді ететін сіңіргіш, қышқылға төзімді бетон). Силикаттар сулы ерітінділерде гидролизденеді — орта сілтілік.

Силикат өнеркәсібі — табиғи силикаттарды өңдеп, шыны, цемент, керамика өндіру.

Шыны: шикізаты — құм, сода, әктас. Балқыту: Na₂CO₃ + CaCO₃ + 6SiO₂ → Na₂O·CaO·6SiO₂ + 2CO₂↑ (кәдімгі терезе шынысы). Сода орнына поташ алса — тұғыр шыны (химиялық ыдыстар), қорғасын оксидін қосса — хрусталь; металл оксидтері шыныны бояйды (CoO — көк, Cr₂O₃ — жасыл, Cu₂O — қызыл).

Цемент: әктас пен сазды айналмалы пеште ≈ 1500 °C-та күйдіріп, клинкер алады, содан кейін гипспен ұнтақтайды. Сумен араластырғанда қатаяды. Бетон — цемент, құм, қиыршық тас және су қоспасы; темірбетон — болат арматурамен күшейтілген бетон.

Керамика: саз (каолин) негізінде күйдірілген бұйымдар — кірпіш, черепица, қыш ыдыстар, фаянс, фарфор (таза каолин, кварц, дала шпаты). Қазақстанда цемент зауыттары (Шымкент, Семей, Қарағанды өңірлері), шыны өндірісі бар.

## №11 және №12 зертханалық жұмыстар. Азот және аммиак молекулаларының модельдері (9-сынып 2-бөлім, 66-б.)

Алдымен азоттың (N≡N) және аммиактың құрылымдық формулалары жазылады. Молекулалардың шар-өзек модельдерін құрастыру жиынтығынан азот үшін бір түсті екі шар, аммиак үшін екі түсті шарлар (бір азот, үш сутек) алынады.

Азот моделінде атомдар арасындағы үш байланысқа назар аударылады: үш еселі байланыс молекуланы өте берік етеді, сондықтан азот химиялық белсенділігі төмен. Аммиак моделі пирамида пішінді: азот атомы төбеде, үш сутек табанда; азоттағы бөлінбеген электрон жұбы аммиактың қышқылдармен аммоний ионын түзу қабілетін түсіндіреді.

## №13 зертханалық жұмыс. Азот қышқылының қасиеттері (9-сынып 2-бөлім, 66–67-б.)

1-тәжірибе: азот қышқылына лакмус қосылып (қызарады), натрий гидроксиді тамызылады — бейтараптану: HNO₃ + NaOH → NaNO₃ + H₂O.
2-тәжірибе: бор ұнтағына сұйылтылған азот қышқылы қосылады — CO₂ бөлінеді: CaCO₃ + 2HNO₃ → Ca(NO₃)₂ + H₂O + CO₂↑.
3-тәжірибе: мыс(II) оксидіне сұйылтылған азот қышқылы құйылады, аздап қыздырғанда оксид еріп, ерітінді көк түске боялады: CuO + 2HNO₃ → Cu(NO₃)₂ + H₂O — түс Cu²⁺ иондарының түзілгенін көрсетеді.

## №6 практикалық жұмыс. Аммиактың алынуы және оның қасиеттерін зерттеу (9-сынып 2-бөлім, 68-б.)

1-тәжірибе: аммиак алу және оны суда еріту. Аммоний хлориді мен кальций гидроксидінің ұнтақтары келіде араластырылып, сынауыққа салынып, қыздырылады. Аммиак ауадан жеңіл болғандықтан, аузы төмен қаратылған құрғақ сынауыққа жиналады. Газ толған сынауықты төңкеріп, суға батырып ашқанда су сынауықты тез толтырады — аммиак суда өте жақсы ериді. Ерітіндіге қызыл лакмус қағазы салынса — көгереді, фенолфталеин тамызылса — таңқурай түс пайда болады (NH₃ + H₂O ⇄ NH₄⁺ + OH⁻).
Теңдеу: 2NH₄Cl + Ca(OH)₂ → CaCl₂ + 2NH₃↑ + 2H₂O.

2-тәжірибе: аммиактың оттекте жануы — 4NH₃ + 3O₂ → 2N₂ + 6H₂O.

Қосымша: аммиак ерітіндісінің қышқылдармен әрекеттесіп, аммоний тұздарын түзуі (NH₃ + HCl → NH₄Cl — ақ «түтін»).

Қауіпсіздік: аммиакты абайлап, қолмен желпіп иіскеу; қыздыру құралдарымен, қышқылдармен және сілтілермен жұмыс ережелерін сақтау.
