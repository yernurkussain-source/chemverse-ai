# Химия 8-сынып · IV тарау. Зат мөлшері

> Оқулық: Оспанова М.Қ., Аухадиева Қ.С., Белоусова Т.Г. Химия: 8-сынып. — Алматы: Мектеп, 2018. Мәтін — оқулық тақырыптары бойынша өз сөзімізбен жазылған конспект. Жақшадағы бет — параграфтың басталатын беті.

## §15. Зат мөлшері. Моль. Авогадро саны (8-сынып, 55-б.)

Атомдар мен молекулалар өте кішкентай, оларды санап алу мүмкін емес. Сондықтан химияда бөлшектер санын көрсететін арнайы физикалық шама — зат мөлшері қолданылады. Белгіленуі: n (кейде ν), өлшем бірлігі — моль.

Моль — құрамында 6,02·10²³ құрылымдық бөлшек (атом, молекула, ион, электрон) бар зат мөлшері. Бұл сан 12 г көміртек-12 изотопындағы атомдар санына тең.

Авогадро тұрақтысы: N_A = 6,02·10²³ моль⁻¹. Бөлшектер саны мен зат мөлшерінің байланысы: N = n · N_A, n = N / N_A.

Мысал: 2 моль судағы молекулалар саны N = 2 · 6,02·10²³ = 12,04·10²³ = 1,204·10²⁴.

Мысал: 3,01·10²³ темір атомы қанша моль? n = 3,01·10²³ / 6,02·10²³ = 0,5 моль.

Бір молекуладағы атомдарды да есептеуге болады: 1 моль H₂O-да 2 моль H атомы және 1 моль O атомы бар, яғни барлығы 3 · 6,02·10²³ атом.

Моль ұғымын «дюжина» (12 дана) сияқты санау бірлігі деп елестетуге болады, тек ол өте үлкен сан.

## §16. Молярлық масса (8-сынып, 58-б.)

Молярлық масса (M) — 1 моль заттың массасы. Өлшем бірлігі — г/моль. Сан мәні бойынша ол заттың салыстырмалы молекулалық массасына (Mr) немесе атомдық массасына (Ar) тең.

Мысалдар: M(H₂O) = 18 г/моль; M(CO₂) = 12 + 2·16 = 44 г/моль; M(NaCl) = 23 + 35,5 = 58,5 г/моль; M(Fe) = 56 г/моль; M(H₂SO₄) = 2 + 32 + 64 = 98 г/моль.

Негізгі формулалар: n = m / M; m = n · M; M = m / n.

Мысал: 88 г CO₂ қанша моль? n = 88 / 44 = 2 моль. Ондағы молекулалар саны N = 2 · 6,02·10²³ = 1,204·10²⁴.

Мысал: 0,25 моль CaCO₃-тің массасы: M = 100 г/моль, m = 0,25 · 100 = 25 г.

Масса, зат мөлшері және бөлшектер санын бір тізбекпен байланыстыруға болады: m ⇄ n ⇄ N, мұндағы m = n·M, N = n·N_A.

Мысал: 1 молекула судың массасы: m = M / N_A = 18 / 6,02·10²³ ≈ 3·10⁻²³ г.

Мысал: қай затта молекула көп — 9 г суда ма, әлде 22 г CO₂-де ме? n(H₂O) = 9/18 = 0,5 моль; n(CO₂) = 22/44 = 0,5 моль. Зат мөлшері тең, демек молекулалар саны да бірдей.
