# Химия 8-сынып · II тарау. Заттардың формулалары және реакция теңдеулері

> Оқулық: Оспанова М.Қ., Аухадиева Қ.С., Белоусова Т.Г. Химия: 8-сынып. — Алматы: Мектеп, 2018. Мәтін — оқулық тақырыптары бойынша өз сөзімізбен жазылған конспект. Жақшадағы бет — параграфтың басталатын беті.

## §6. Химиялық қосылыстағы элементтердің массалық үлесі (8-сынып, 23-б.)

Элементтің массалық үлесі (ω) — қосылыстағы сол элемент массасының бүкіл қосылыс массасына қатынасы. Формуласы: ω(Э) = n · Ar(Э) / Mr(зат), мұндағы n — формуладағы атом саны. Нәтиже бөлшекпен немесе пайызбен (×100%) беріледі. Барлық элементтердің массалық үлестерінің қосындысы 1-ге (100%) тең.

Мысал: судағы сутектің массалық үлесі. Mr(H₂O) = 2·1 + 16 = 18. ω(H) = 2/18 = 0,111 (11,1%), ω(O) = 16/18 = 0,889 (88,9%).

Мысал: CaCO₃ құрамындағы кальций. Mr = 40 + 12 + 3·16 = 100. ω(Ca) = 40/100 = 40%, ω(C) = 12%, ω(O) = 48%.

Кері есеп — массалық үлестер бойынша формуланы табу. Әр элементтің массалық үлесін оның Ar-іне бөліп, атомдар сандарының қатынасын табамыз, содан кейін ең кіші санға бөліп, бүтін сандарға келтіреміз.

Мысал: құрамында 40% S және 60% O бар оксид. S: 40/32 = 1,25; O: 60/16 = 3,75. Қатынас 1,25 : 3,75 = 1 : 3 → SO₃.

Массалық үлесті білу практикада маңызды: тыңайтқыштағы азоттың, кендегі металдың үлесін салыстырып, қайсысы тиімді екенін анықтауға болады. Мысалы, NH₄NO₃-те ω(N) = 28/80 = 35%, ал (NH₄)₂SO₄-те ω(N) = 28/132 ≈ 21%.

## §7. Зат массасының сақталу заңы (8-сынып, 26-б.)

Заң: реакцияға түскен заттардың массасы реакция нәтижесінде түзілген заттардың массасына тең. Бұл заңды М.В. Ломоносов (1748–1756) ашып, тәжірибе жүзінде дәлелдеген, кейін А. Лавуазье де тәуелсіз түрде тұжырымдаған.

Ломоносов металдарды дәнекерленген (тығыз жабылған) ыдыста қыздырып, ыдысты ашпай өлшеген — масса өзгермеген. Ашық ыдыста металл қыздырғанда масса артатын себебі — металл ауадағы оттекпен қосылады.

Заңның мәні: химиялық реакцияда атомдар жоғалмайды да, жоқтан пайда болмайды, тек қайта топтасады. Әр элемент атомдарының саны реакцияға дейін және кейін бірдей болғандықтан, жалпы масса да сақталады.

Есептеу мысалы: 5,6 г темір 3,2 г күкіртпен толық әрекеттессе, түзілген темір(II) сульфидінің массасы 5,6 + 3,2 = 8,8 г болады.

Заңның маңызы: осы заң негізінде химиялық теңдеулер құрастырылады (коэффициенттер қойылады) және реакция теңдеулері бойынша есептеулер жүргізіледі.

## §8. Химиялық реакция теңдеулерін құрастыру (8-сынып, 29-б.)

Химиялық теңдеу — реакцияны химиялық формулалар мен коэффициенттер арқылы шартты түрде жазу. Сол жақта бастапқы заттар (реагенттер), оң жақта реакция өнімдері жазылады.

Коэффициент — формуланың алдына қойылатын сан, ол молекулалар (формулалық бірліктер) санын көрсетеді. Индекс — формуланың ішіндегі кіші сан, ол заттың құрамын көрсетеді. Теңестіргенде тек коэффициенттерді өзгертеміз, индекстерді ешқашан өзгертпейміз.

Теңестіру реті: 1) реагенттер мен өнімдердің дұрыс формулаларын жазамыз; 2) әр элементтің атом санын екі жақта салыстырамыз; 3) алдымен күрделі заттардағы металдарды, содан кейін бейметалдарды, соңында сутек пен оттекті теңестіреміз; 4) коэффициенттер ең кіші бүтін сандар болуы керек.

Мысалдар:
2H₂ + O₂ → 2H₂O
4Al + 3O₂ → 2Al₂O₃
2Fe(OH)₃ → Fe₂O₃ + 3H₂O
CH₄ + 2O₂ → CO₂ + 2H₂O

Тақ санды оттек әдісі: егер бір жақта оттек атомдары тақ, екінші жақта жұп болса, тақ санды екіге көбейтіп, қалғанын соған сәйкестендіреміз (4P + 5O₂ → 2P₂O₅).

## §9. Химиялық реакциялардың типтері (8-сынып, 32-б.)

Бастапқы және түзілетін заттардың саны мен құрамына қарай реакциялар төрт негізгі типке бөлінеді.

Қосылу реакциясы — екі немесе бірнеше заттан бір күрделі зат түзіледі: A + B → AB. Мысалдар: 2Mg + O₂ → 2MgO; CaO + H₂O → Ca(OH)₂; SO₃ + H₂O → H₂SO₄.

Айырылу реакциясы — бір күрделі заттан екі немесе бірнеше зат түзіледі: AB → A + B. Мысалдар: CaCO₃ → CaO + CO₂ (қыздырғанда); 2H₂O → 2H₂ + O₂ (электр тогымен); 2KMnO₄ → K₂MnO₄ + MnO₂ + O₂.

Орынбасу реакциясы — жай зат пен күрделі зат әрекеттесіп, жай заттың атомдары күрделі заттағы бір элементтің атомдарын ығыстырады: A + BC → AC + B. Мысалдар: Zn + 2HCl → ZnCl₂ + H₂↑; Fe + CuSO₄ → FeSO₄ + Cu.

Алмасу реакциясы — екі күрделі зат құрамдас бөліктерімен алмасады: AB + CD → AD + CB. Мысалдар: NaOH + HCl → NaCl + H₂O; BaCl₂ + Na₂SO₄ → BaSO₄↓ + 2NaCl. Алмасу реакциясы соңына дейін жүреді, егер тұнба (↓), газ (↑) немесе су түзілсе.

Реакция белгілері: түстің өзгеруі, газ бөлінуі, тұнба түзілуі, иіс шығуы, жылу немесе жарық бөлінуі не жұтылуы.

## §10. Табиғатта және тірі организмдерде жүретін реакциялар (8-сынып, 36-б.)

Фотосинтез — жасыл өсімдіктерде жарық энергиясы мен хлорофилдің қатысуымен көмірқышқыл газы мен судан глюкоза мен оттек түзілуі: 6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂. Бұл реакция энергияны жұтады және атмосферадағы оттектің негізгі көзі.

Тыныс алу — ағза жасушаларында глюкозаның оттекпен тотығуы: C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O + энергия. Бөлінген энергия тіршілікке жұмсалады. Фотосинтез бен тыныс алу — бір-біріне қарама-қарсы процестер.

Ашу (ферменттеу) — микроорганизмдердің көмегімен органикалық заттардың ыдырауы. Спирттік ашу: C₆H₁₂O₆ → 2C₂H₅OH + 2CO₂ (нан ашытқысы, шарап). Сүт қышқылды ашу айран, қымыз, қатық жасағанда жүреді.

Шіру — органикалық заттардың бактериялар әсерінен ыдырауы, нәтижесінде CO₂, H₂O, NH₃, H₂S сияқты қарапайым заттар түзіледі және табиғаттағы зат айналымы жүреді.

Жансыз табиғаттағы реакциялар: найзағай кезінде азот пен оттек қосылады (N₂ + O₂ → 2NO), бұдан әрі азот қышқылы мен нитраттар түзіліп, топырақты азотпен байытады. Үңгірлерде сталактит пен сталагмит түзілуі: CaCO₃ + H₂O + CO₂ ⇄ Ca(HCO₃)₂ — әктас құрамында CO₂ бар суда еріп, кейін су буланғанда қайта тұнбаға түседі. Темірдің тотығуы (тот басу) — ылғал мен оттектің әсері.

Тұрмыстағы реакциялар: тамақ пісіру, отын жағу, ас содасын сірке суымен сөндіру (NaHCO₃ + CH₃COOH → CH₃COONa + H₂O + CO₂↑).

## 2-зертханалық тәжірибе. Әрекеттесуші заттар массаларының қатынасы (8-сынып, 41-б.)

Мақсаты — заттар бір-бірімен белгілі бір тұрақты қатынаста әрекеттесетінін көзбен көру. Сегіз сынауыққа бірдей көлемде калий гидроксидінің ерітіндісі құйылады, оларға мыс(II) сульфатының 0,5 М ерітіндісі біртіндеп көбейтілген көлемдерде қосылады.

Реакция теңдеуі (алмасу реакциясы): CuSO₄ + 2KOH → Cu(OH)₂↓ + K₂SO₄. Көгілдір тұнба түзіледі.

Реакция аяқталған соң әр сынауықтағы тұнбаның биіктігі сызғышпен өлшенеді. Мыс сульфатының мөлшері артқан сайын тұнба биіктігі өседі, бірақ сілті толық жұмсалған сәттен бастап биіктік тұрақты болып қалады. Бұл нүкте заттардың теңдеудегі 1 : 2 мольдік қатынасына сәйкес келеді: артық қосылған CuSO₄ тұнба бермейді.

Қорытынды: реагенттердің бірі артық алынса, өнімнің мөлшерін жетіспейтін (толық жұмсалатын) зат анықтайды. Қауіпсіздік: қорғаныш көзілдірігін кию, жұмыстан кейін қолды жақсылап жуу.
