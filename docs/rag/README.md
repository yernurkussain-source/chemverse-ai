# AI мұғалімнің білім қоры (RAG)

Бұл папкаға AI мұғалім сүйенетін **тексерілген** материалдарды салыңыз: тақырып конспектілері, анықтамалар, есеп шығару үлгілері.
AI жауап бергенде осы материалдардан үзінді тауып, дереккөзін `[1]`, `[2]` деп көрсетеді.

## Файл ережелері
- Пішімі: `.md` немесе `.txt`, кодтауы UTF-8.
- Файл атауы латынша, қысқа: `atom-structure.md`, `acids-bases.md`. Атауы дереккөз ретінде көрсетіледі.
- Тілі атауынан анықталады: `acids.ru.md` — орысша, `acids.en.md` — ағылшынша, қалғаны — қазақша.
- Тақырыптарды `# ...` немесе `## ...` деп бөліңіз, абзацтардың арасына бос жол қойыңыз.
- Бір тақырып — бір файл (30–50 үзінді жалпы жеткілікті, бір үзінді ≈ 1000 таңба).
- Осы `README.md` және `_` таңбасынан басталатын файлдар жүктелмейді.

## Жүктеу
```powershell
npm run rag
```
Материалды өзгерткен сайын қайта іске қосыңыз — кесте толық жаңартылады.
