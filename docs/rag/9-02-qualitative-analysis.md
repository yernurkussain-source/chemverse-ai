# Химия 9-сынып · II тарау. Бейорганикалық қосылыстардың сапалық талдауы

> Оқулық: Оспанова М.Қ., Аухадиева Қ.С., Белоусова Т.Г. Химия: 9-сынып, 1-бөлім. — Алматы: Мектеп, 2019. Мәтін — оқулық тақырыптары бойынша өз сөзімізбен жазылған конспект. Жақшадағы бет — параграфтың басталатын беті.

## §11. Катиондарға сапалық реакциялар (9-сынып 1-бөлім, 43-б.)

Аналитикалық химия — заттар мен қоспалардың құрамын анықтау әдістері туралы ғылым. Ол сапалық талдауға (үлгіде қандай элементтер мен иондар бар) және сандық талдауға (олардың мөлшері қанша) бөлінеді. Химиялық талдау өндірісте, медицинада, ауыл шаруашылығында, экологияда, криминалистикада қолданылады.

Сапалық реакция — белгілі бір ионды анықтауға мүмкіндік беретін, көзге көрінетін белгісі бар реакция. Реагент — құрамы белгілі, анықталатын ионмен ерекше белгі беретін зат. Белгілері: жалын түсінің өзгеруі, тұнба түзілуі, түстің өзгеруі, газ бөлінуі.

1. Жалын түсі бойынша анықтау. Сілтілік және сілтілік-жер металдардың катиондары тұнба түзбейтіндіктен, оларды жалын түсі арқылы анықтайды: таза болат (нихром) сымды тұз үлгісіне батырып, жанарғы жалынына ұстайды.
Li⁺ — карминді-қызыл; Na⁺ — сары; K⁺ — күлгін (көк шыны арқылы қарайды); Ca²⁺ — кірпіш-қызыл; Sr²⁺ — қанық қызыл; Ba²⁺ — сарғыш-жасыл; Cu²⁺ — жасыл (көкшіл-жасыл). Мерекелік отшашулардың түсі осы құбылысқа негізделген.

2. Тұнба түзілуі бойынша. Сілтімен (OH⁻ — топтық реагент) d-металдардың катиондары түрлі түсті гидроксидтер береді:
Cu²⁺ + 2OH⁻ → Cu(OH)₂↓ — көк (көгілдір) тұнба;
Fe²⁺ + 2OH⁻ → Fe(OH)₂↓ — жасылдау тұнба (ауада біртіндеп қоңырланады);
Fe³⁺ + 3OH⁻ → Fe(OH)₃↓ — қоңыр тұнба;
Al³⁺ + 3OH⁻ → Al(OH)₃↓ және Zn²⁺ + 2OH⁻ → Zn(OH)₂↓ — ақ тұнбалар, сілтінің артық мөлшерінде ериді (амфотерлік).
Ba²⁺ иондары сульфат иондарымен ақ тұнба береді: Ba²⁺ + SO₄²⁻ → BaSO₄↓; Ca²⁺ карбонатпен: Ca²⁺ + CO₃²⁻ → CaCO₃↓; Ag⁺ хлоридпен: Ag⁺ + Cl⁻ → AgCl↓; Pb²⁺ иодидпен ашық сары тұнба: Pb²⁺ + 2I⁻ → PbI₂↓ («алтын жаңбыр» тәжірибесі).

3. Түстің өзгеруі бойынша. Fe³⁺ ионы калий роданидімен (тиоцианатымен, KSCN) қан-қызыл түс береді: Fe³⁺ + 3SCN⁻ → Fe(SCN)₃. Бұл реакция кино түсірілімінде «жасанды қан» ретінде қолданылады.

4. Газ бөлінуі бойынша. Аммоний ионы сілтімен қыздырғанда аммиак бөледі: NH₄⁺ + OH⁻ → NH₃↑ + H₂O; аммиак өткір иісімен және дымқыл қызыл лакмус қағазын көгертуімен анықталады.

H⁺ катиондары индикаторлармен анықталады (лакмус қызарады, метилоранж қызғылт).

## §12. Аниондарға сапалық реакциялар (9-сынып 1-бөлім, 47-б.)

Аниондар топтық реагенттердің көмегімен анықталады — бір реагент бірнеше анионмен әртүрлі белгі береді.

1. Күміс катионы Ag⁺ (AgNO₃) — галогенид иондарына топтық реагент:
Ag⁺ + Cl⁻ → AgCl↓ — ақ ірімшік тәрізді тұнба;
Ag⁺ + Br⁻ → AgBr↓ — ақшыл-сары тұнба;
Ag⁺ + I⁻ → AgI↓ — сары тұнба;
3Ag⁺ + PO₄³⁻ → Ag₃PO₄↓ — сары тұнба (азот қышқылында ериді, ал AgCl ерімейді).

2. Барий катионы Ba²⁺ (BaCl₂) — сульфат иондарына: Ba²⁺ + SO₄²⁻ → BaSO₄↓ — ақ, қышқылдарда ерімейтін тұнба. Мысалы: Na₂SO₄ + BaCl₂ → BaSO₄↓ + 2NaCl.

3. Сутек катионы H⁺ (қышқылдар) — әлсіз қышқылдардың аниондарына топтық реагент:
CO₃²⁻ + 2H⁺ → H₂O + CO₂↑ — иіссіз газ, әк суын лайлайды (соданы сірке суымен сөндіру);
SO₃²⁻ + 2H⁺ → H₂O + SO₂↑ — тұтанған сіріңкенің иісіндей өткір иісті газ;
S²⁻ + 2H⁺ → H₂S↑ — шіріген жұмыртқа иісті газ;
SiO₃²⁻ + 2H⁺ → H₂SiO₃↓ — ақ іркілдек (гель тәрізді) тұнба.

4. Нитрат ионы NO₃⁻ үшін топтық реагент жоқ. Оны анықтау үшін зерттелетін тұзға мыс жаңқасы мен концентрлі күкірт қышқылын қосып қыздырады: көк түсті ерітінді (Cu²⁺) түзіліп, қоңыр түсті газ (NO₂) бөлінеді.

5. Гидроксид ионы OH⁻ индикаторлармен анықталады: фенолфталеин таңқурай түске енеді.

Белгісіз қоспаларды талдаудың ретін (талдау сызбасын) құрастыру: алдымен жалпы белгілерді (түс, иіс, ерігіштік) қарап, содан кейін бір реактивпен бір уақытта бірнеше ионды бөліп анықтайтын реакцияларды таңдау керек.

## §13. Әрекеттесуші заттардың біреуі артық болған жағдайда есептер шығару (9-сынып 1-бөлім, 50-б.)

Егер есепте екі реагенттің де массасы (мөлшері) берілсе, алдымен қайсысы артық, қайсысы жетіспейтінін анықтау керек. Өнімнің мөлшері жетіспейтін (толық әрекеттесетін) зат бойынша есептеледі.

Шешу реті: 1) реакция теңдеуін жазамыз; 2) әр реагенттің зат мөлшерін табамыз; 3) әр реагенттің зат мөлшерін теңдеудегі коэффициентіне бөлеміз — мәні кіші болған зат жетіспейді; 4) өнімді жетіспейтін зат бойынша есептейміз.

Мысал: 20 г натрий гидроксиді бар ерітіндіге 32 г мыс(II) сульфаты бар ерітінді қосылды. Тұнбаның массасы қанша?
2NaOH + CuSO₄ → Cu(OH)₂↓ + Na₂SO₄
n(NaOH) = 20/40 = 0,5 моль; n(CuSO₄) = 32/160 = 0,2 моль.
Коэффициентке бөлеміз: NaOH 0,5/2 = 0,25; CuSO₄ 0,2/1 = 0,2. CuSO₄ жетіспейді, NaOH артық.
n(Cu(OH)₂) = n(CuSO₄) = 0,2 моль; m = 0,2 · 98 = 19,6 г.
Артық қалған NaOH: 0,5 − 2·0,2 = 0,1 моль (4 г).

Мысал: 5,6 л (қ.ж.) хлор мен 4 г сутек әрекеттесті. Қанша литр HCl түзіледі? H₂ + Cl₂ → 2HCl. n(Cl₂) = 0,25 моль; n(H₂) = 2 моль — сутек артық. n(HCl) = 2 · 0,25 = 0,5 моль; V = 11,2 л.

Пропорция әдісі де қолданылады: берілген массаларды теңдеу бойынша массаларға бөліп, кіші қатынасты табамыз. Екі әдістің нәтижесі бірдей.

## №3 зертханалық жұмыс. Катиондарды жалын түсі бойынша анықтау (9-сынып 1-бөлім, 53-б.)

LiCl, NaCl, KCl, CaCl₂, SrCl₂, BaCl₂, CuCl₂ кристалдары қолданылады. Болат немесе нихром сым алдымен тұз қышқылына батырылып, жалында түссіз жанғанша күйдіріледі (тазартылады). Содан кейін сым ұшымен тұз кристалдары алынып, жанарғының түссіз жалынына енгізіледі.

Бақылау нәтижелері кестеге жазылады: Li⁺ — карминді-қызыл, Na⁺ — сары, K⁺ — күлгін, Ca²⁺ — кірпіш-қызыл, Sr²⁺ — қызыл, Ba²⁺ — сарғыш-жасыл, Cu²⁺ — жасыл. Әр тұздан кейін сым қайта тазартылады, әйтпесе натрий қоспасының сары түсі басқа түстерді жасырып қояды.

## №4 зертханалық жұмыс. Fe²⁺, Fe³⁺, Cu²⁺ катиондарына сапалық реакциялар (9-сынып 1-бөлім, 53-б.)

Темір(II), темір(III) және мыс(II) хлоридтерінің немесе сульфаттарының ерітінділеріне NaOH немесе KOH ерітіндісі қосылады.

Нәтиже: Cu²⁺ — көк тұнба Cu(OH)₂; Fe²⁺ — жасылдау тұнба Fe(OH)₂, ол ауада тотығып қоңырлана бастайды; Fe³⁺ — қоңыр тұнба Fe(OH)₃. Әр реакция үшін молекулалық және қысқартылған иондық теңдеулер жазылады.

## №5 зертханалық жұмыс. Сулы ерітіндідегі аниондарды анықтау (9-сынып 1-бөлім, 54-б.)

Анықталатын аниондар: Cl⁻, Br⁻, I⁻, PO₄³⁻, SO₄²⁻, CO₃²⁻, NO₃⁻, SiO₃²⁻.

Галогенидтер мен фосфат — күміс нитратымен (AgCl — ақ, AgBr — ақшыл-сары, AgI — сары, Ag₃PO₄ — сары тұнба). Сульфат — барий хлоридімен (ақ BaSO₄). Карбонат — қышқылмен (CO₂ көпіршіктері, әк суы лайланады). Силикат — қышқылмен (іркілдек H₂SiO₃ тұнбасы). Нитрат — мыс пен концентрлі күкірт қышқылымен қыздырғанда қоңыр газ және көк ерітінді.

Қауіпсіздік: концентрлі күкірт қышқылымен және NO₂ газымен тек тартпа шкафта, мұғалімнің қадағалауымен жұмыс істеу.

## №2 практикалық жұмыс. Бейорганикалық қосылыстар құрамының сапалық талдауы (9-сынып 1-бөлім, 55-б.)

Оқушыларға нөмірленген ыдыстарда темір(III) сульфаты, кальций хлориді, натрий карбонаты, натрий сульфаты, натрий хлориді секілді заттар беріледі. Міндет — әр заттың құрамындағы катион мен анионды сапалық реакциялар арқылы анықтау.

Жұмыс жоспары: 1) заттың сыртқы түрін сипаттап, суда еріту; 2) катионды анықтау (жалын түсі, сілтімен тұнба: Fe³⁺ — қоңыр тұнба); 3) анионды анықтау (BaCl₂ — сульфат, AgNO₃ — хлорид, HCl — карбонат); 4) бақылауларды кестеге жазып, молекулалық және иондық теңдеулер құрастыру; 5) заттың формуласын тұжырымдау.
