# Химия 9-сынып · VII тарау. 1(IA), 2(IIA) және 13(IIIA) топ элементтері және олардың қосылыстары

> Оқулық: Оспанова М.Қ., Аухадиева Қ.С., Белоусова Т.Г. Химия: 9-сынып, 1-бөлім. — Алматы: Мектеп, 2019. Мәтін — оқулық тақырыптары бойынша өз сөзімізбен жазылған конспект. Жақшадағы бет — параграфтың басталатын беті.

## §25. 1(IA) топ элементтері: жалпы сипаттамасы (9-сынып 1-бөлім, 97-б.)

1(IA) топқа сілтілік металдар жатады: литий Li, натрий Na, калий K, рубидий Rb, цезий Cs, франций Fr. Олардың гидроксидтері сілтілер, сондықтан топ осылай аталады. Әр период (1-периодтан басқа) сілтілік металмен басталады.

Атом құрылысы: сыртқы деңгейде бір s-электрон — ns¹ (n — период нөмірі). Na: 1s²2s²2p⁶3s¹; K: …3s²3p⁶4s¹. Қосылыстарда тотығу дәрежесі тұрақты +1, күшті тотықсыздандырғыштар. Li-ден Cs-ке қарай атом радиусы артып, металдық және тотықсыздандырғыштық қасиеттер күшейеді.

Физикалық қасиеттері: күміс түсті, жұмсақ (пышақпен кесіледі), жеңіл (Li, Na, K судан жеңіл), оңай балқиды, ток пен жылуды жақсы өткізеді. Ауада тез тотығатындықтан керосин астында сақталады (литий вазелин қабатында).

Табиғатта тек қосылыстар түрінде: ас тұзы NaCl, сильвинит NaCl·KCl, глаубер тұзы Na₂SO₄·10H₂O, чили селитрасы NaNO₃. Алу: тұз балқымаларын электролиздеу: 2NaCl → 2Na + Cl₂.

## §25. Сілтілік металдардың химиялық қасиеттері мен қосылыстары (9-сынып 1-бөлім, 97–103-б.)

Химиялық қасиеттері:
оттекпен: 4Li + O₂ → 2Li₂O (оксид); 2Na + O₂ → Na₂O₂ (натрий пероксиді); калий супероксид KO₂ түзеді;
галогендермен, күкіртпен, сутекпен: 2Na + Cl₂ → 2NaCl; 2Na + S → Na₂S; 2Na + H₂ → 2NaH;
литий азотпен қалыпты жағдайда әрекеттеседі: 6Li + N₂ → 2Li₃N;
сумен: 2Na + 2H₂O → 2NaOH + H₂↑ — натрий су бетінде балқып, ысқырып жүгіреді; калий сумен одан да қатты әрекеттесіп, сутек күлгін жалынмен тұтанады;
қышқылдармен жарылыспен әрекеттеседі.

Оксидтері (Na₂O, K₂O) — негіздік, сумен сілті түзеді: Na₂O + H₂O → 2NaOH.
Гидроксидтері (NaOH — күйдіргіш натр, KOH — күйдіргіш кали) — күшті сілтілер, ауадағы ылғал мен CO₂-ні сіңіреді.

Маңызды тұздар: NaCl — ас тұзы, хлор, натрий, сода, NaOH өндірісінің шикізаты; Na₂CO₃ — кальцийленген сода (шыны, сабын, қағаз өндірісі); NaHCO₃ — ас содасы (нан пісіру, медицина); Na₂SO₄·10H₂O — глаубер тұзы; KNO₃ — калий селитрасы (тыңайтқыш, қара оқ-дәрі); KCl — калий тыңайтқышы; K₂CO₃ — поташ.

Сапалық анықтау — жалын түсі: Li⁺ — қызыл, Na⁺ — сары, K⁺ — күлгін.

Биологиялық маңызы: Na⁺ және K⁺ иондары жасушадағы су-тұз алмасуын, жүйке импульсінің берілуін реттейді. Ересек адамға тәулігіне 3–6 г шамасында ас тұзы жеткілікті; артық натрий ісінуге, қан қысымының көтерілуіне әкеледі.

Қолданылуы: литий — литий-иондық аккумуляторлар, жеңіл құймалар; натрий — ядролық реакторларда жылу тасығыш, натрий шамдары (сары жарық); цезий — фотоэлементтер, атомдық сағаттар.

## §26. 2(IIA) топ элементтері. Кальций (9-сынып 1-бөлім, 104-б.)

2(IIA) топ: бериллий Be, магний Mg, кальций Ca, стронций Sr, барий Ba, радий Ra. Сыртқы деңгейінде екі s-электрон (ns²), тотығу дәрежесі тұрақты +2. Оксидтерінің жалпы формуласы RO, гидроксидтері R(OH)₂. Be-ден Ra-ға қарай металдық және тотықсыздандырғыштық қасиеттер күшейеді, оксидтер мен гидроксидтердің негіздік қасиеттері артады: Be(OH)₂ — амфотерлі, Mg(OH)₂ — әлсіз негіз, Ca(OH)₂, Sr(OH)₂, Ba(OH)₂ — сілтілер. Ca, Sr, Ba — сілтілік-жер металдар.

Кальций: Z = 20, 1s²2s²2p⁶3s²3p⁶4s². Табиғатта көп таралған (Жер қыртысында 5-орын): әктас, бор, мәрмәр CaCO₃; гипс CaSO₄·2H₂O; доломит CaCO₃·MgCO₃; фосфорит пен апатит; флюорит CaF₂. Алу: балқыған CaCl₂-ні электролиздеу: CaCl₂ → Ca + Cl₂.

Физикалық қасиеттері: күміс-ақ түсті, салыстырмалы жеңіл, натрийден қатты металл.

Химиялық қасиеттері:
оттекпен: 2Ca + O₂ → 2CaO; галогендермен: Ca + Cl₂ → CaCl₂; сутекпен: Ca + H₂ → CaH₂; азотпен: 3Ca + N₂ → Ca₃N₂; көміртекпен: Ca + 2C → CaC₂ (кальций карбиді);
сумен: Ca + 2H₂O → Ca(OH)₂ + H₂↑ (натрийге қарағанда баяу);
қышқылдармен: Ca + 2HCl → CaCl₂ + H₂↑.

Қосылыстары:
CaO — сөндірілмеген әк, әктасты күйдіріп алады: CaCO₃ → CaO + CO₂; сумен көп жылу бөле әрекеттеседі: CaO + H₂O → Ca(OH)₂ (әкті сөндіру).
Ca(OH)₂ — сөндірілген әк; әк суы (мөлдір ерітінді) CO₂-ні анықтауға қолданылады; әк ерітіндісі ауада қатаяды: Ca(OH)₂ + CO₂ → CaCO₃ + H₂O.
CaCO₃ — құрылыс материалы, цемент пен шыны өндірісінің шикізаты, бор.
CaSO₄·2H₂O — гипс; 150 °C-та қыздырғанда алебастр (CaSO₄·0,5H₂O) түзіледі, ол сумен араласып тез қатаяды (медицинада гипс таңғыштар, мүсіндер).
Кальций иондары судың кермектігін тудырады (XIII тарау, 8-сынып).

Биологиялық маңызы: сүйек пен тістің құрамында (кальций фосфаты, гидроксиапатит), қанның ұюына, бұлшықеттің жиырылуына қатысады; жетіспеушілігі қаңқаның дамуын баяулатады.

Магний: хлорофилл құрамына кіреді; жарқырап жанады (фотосуреттегі «жарқыл», отшашу); жеңіл құймаларда қолданылады; MgSO₄ — ащы тұз (медицинада).

## §27. 13(IIIA) топ. Алюминий және оның қосылыстары (9-сынып 1-бөлім, 110-б.)

Алюминий: 3-период, 13(IIIA) топ, Z = 13, 1s²2s²2p⁶3s²3p¹. Қосылыстарда +3 тотығу дәрежесін көрсетеді.

Табиғатта: Жер қыртысында таралуы бойынша үшінші элемент (O мен Si-ден кейін) және металдар арасында бірінші. Маңызды қосылыстары: боксит (Al₂O₃·nH₂O), корунд Al₂O₃ (асыл түрлері — рубин, сапфир), каолинит (саз), дала шпаттары, криолит Na₃AlF₆. Қазақстан боксит қоры бойынша ТМД-да алдыңғы қатарда; кен орындары солтүстік-шығыста және Торғай өңірінде; Павлодар алюминий зауыты боксит өңдейді.

Алу: криолиттегі Al₂O₃ балқымасын электролиздеу (≈ 950 °C): 2Al₂O₃ → 4Al + 3O₂.

Физикалық қасиеттері: жеңіл (ρ = 2,7 г/см³), күміс-ақ түсті, ток пен жылуды жақсы өткізеді, созылғыш (сым, фольга), 660 °C-та балқиды.

Химиялық қасиеттері: белсенді металл, бірақ беті жұқа әрі берік Al₂O₃ қабықшасымен қапталғандықтан ауада және суда тұрақты. Қабықшаны қырып алса, сумен әрекеттеседі: 2Al + 6H₂O → 2Al(OH)₃ + 3H₂↑.
Оттекпен: 4Al + 3O₂ → 2Al₂O₃ (ұнтақ жарқырап жанады — бенгал оттары, отшашулар).
Бейметалдармен қыздырғанда: 2Al + 3Cl₂ → 2AlCl₃; 2Al + 3S → Al₂S₃; 2Al + N₂ → 2AlN; 4Al + 3C → Al₄C₃.
Қышқылдармен: 2Al + 6HCl → 2AlCl₃ + 3H₂↑. Суық концентрлі HNO₃ және H₂SO₄ алюминийді пассивтейді (сондықтан бұл қышқылдарды алюминий ыдыстарда тасымалдайды).
Сілтілермен (амфотерлігі): 2Al + 2NaOH + 6H₂O → 2Na[Al(OH)₄] + 3H₂↑.
Металл оксидтерімен (алюминотермия): Fe₂O₃ + 2Al → 2Fe + Al₂O₃.

Қосылыстары амфотерлі:
Al₂O₃ + 6HCl → 2AlCl₃ + 3H₂O; Al₂O₃ + 2NaOH + 3H₂O → 2Na[Al(OH)₄].
Al(OH)₃ — ақ іркілдек тұнба: AlCl₃ + 3NaOH → Al(OH)₃↓ + 3NaCl; қышқылда да (Al(OH)₃ + 3HCl → AlCl₃ + 3H₂O), сілтінің артығында да (Al(OH)₃ + NaOH → Na[Al(OH)₄]) ериді.

Қолданылуы: ұшақ, автомобиль, кеме жасау (дюралюминий), электр сымдары, тағам фольгасы мен ыдыстары, құрылыс конструкциялары, алюминотермия. Ағзаға артық түскен алюминий жүйке жүйесіне зиян келтіреді.

## №8 зертханалық жұмыс. Кальцийдің сумен және қышқыл ерітіндісімен әрекеттесуі (9-сынып 1-бөлім, 116-б.)

1-тәжірибе: фарфор табақшадағы фенолфталеин тамызылған суға сүзгі қағазымен құрғатылған кішкентай кальций түйірі пинцетпен салынады. Газ көпіршіктері бөлінеді, ерітінді таңқурай түске боялады, ерітінді лайланады (Ca(OH)₂ аз ериді): Ca + 2H₂O → Ca(OH)₂ + H₂↑.

2-тәжірибе: тұз қышқылына кальций түйірі салынады — газ қарқынды бөлінеді: Ca + 2HCl → CaCl₂ + H₂↑.

Қорытынды: кальций — белсенді металл, сумен сілті мен сутек түзеді, қышқылдармен одан да жылдам әрекеттеседі.

## №9 зертханалық жұмыс. Алюминийдің қышқыл және сілті ерітінділерімен әрекеттесуі (9-сынып 1-бөлім, 116-б.)

1-тәжірибе: алюминий түйірі тұз немесе күкірт қышқылына салынады — бастапқыда реакция баяу (оксид қабықшасы ериді), содан кейін сутек қарқынды бөлінеді: 2Al + 6HCl → 2AlCl₃ + 3H₂↑.

2-тәжірибе: алюминий натрий немесе калий гидроксиді ерітіндісіне салынады — сутек бөлінеді: 2Al + 2NaOH + 6H₂O → 2Na[Al(OH)₄] + 3H₂↑.

Қорытынды: алюминий қышқылмен де, сілтімен де әрекеттеседі — амфотерлі металл.

## №4 практикалық жұмыс. «Металдар» тақырыбына эксперименттік есептер (9-сынып 1-бөлім, 117-б.)

1-тәжірибе: натрий сульфаты мен барий хлоридінің сапалық құрамын анықтау (Na⁺ — жалын түсі сары; SO₄²⁻ — BaCl₂-мен ақ тұнба; Ba²⁺ — жалын сарғыш-жасыл, сульфатпен ақ тұнба; Cl⁻ — AgNO₃-пен ақ тұнба).

2-тәжірибе: кальций гидроксиді, күкірт қышқылы және натрий карбонатын пайдаланып алмасу реакцияларымен кальций карбонатын және кальций сульфатын алу: Ca(OH)₂ + Na₂CO₃ → CaCO₃↓ + 2NaOH; Ca(OH)₂ + H₂SO₄ → CaSO₄ + 2H₂O.

3-тәжірибе: магнийден оның хлоридін, гидроксидін және сульфатын алу: Mg + 2HCl → MgCl₂ + H₂↑; MgCl₂ + 2NaOH → Mg(OH)₂↓ + 2NaCl; Mg(OH)₂ + H₂SO₄ → MgSO₄ + 2H₂O.

4-тәжірибе: алюминийден оның хлоридін, гидроксидін және сульфатын алу: 2Al + 6HCl → 2AlCl₃ + 3H₂↑; AlCl₃ + 3NaOH → Al(OH)₃↓ + 3NaCl (сілтіні артық қоспау керек); 2Al(OH)₃ + 3H₂SO₄ → Al₂(SO₄)₃ + 6H₂O.

Әр тәжірибе үшін молекулалық және иондық теңдеулер жазылады.
