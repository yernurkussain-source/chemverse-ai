# Химия 8-сынып · XI тарау. Бейорганикалық қосылыстардың негізгі кластары. Генетикалық байланыс

> Оқулық: Оспанова М.Қ., Аухадиева Қ.С., Белоусова Т.Г. Химия: 8-сынып. — Алматы: Мектеп, 2018. Мәтін — оқулық тақырыптары бойынша өз сөзімізбен жазылған конспект. Жақшадағы бет — параграфтың басталатын беті.

## §42. Оксидтер: құрамы, жіктелуі, атаулары (8-сынып, 148-б.)

Оксидтер — екі элементтен тұратын, біреуі −2 тотығу дәрежесіндегі оттек болатын күрделі заттар: Na₂O, CaO, CO₂, SO₃, Fe₂O₃, Al₂O₃.

Атауы: элемент атауы + (айнымалы валентті болса, жақшада рим цифрымен валенттілігі) + «оксиді». Мысалы, FeO — темір(II) оксиді, Fe₂O₃ — темір(III) оксиді, CO — көміртек(II) оксиді, SO₂ — күкірт(IV) оксиді.

Жіктелуі:
Негіздік оксидтер — металдардың (тотығу дәрежесі +1, +2) оксидтері, оларға негіздер сәйкес келеді: Na₂O → NaOH, CaO → Ca(OH)₂, CuO → Cu(OH)₂.
Қышқылдық оксидтер — бейметалдардың және жоғары тотығу дәрежесіндегі металдардың оксидтері, оларға қышқылдар сәйкес келеді: CO₂ → H₂CO₃, SO₃ → H₂SO₄, P₂O₅ → H₃PO₄, N₂O₅ → HNO₃, CrO₃ → H₂CrO₄.
Амфотерлі оксидтер — қышқылмен де, сілтімен де әрекеттесетін оксидтер: ZnO, Al₂O₃, BeO, Cr₂O₃.
Тұз түзбейтін оксидтер — қышқыл да, негіз де түзбейтін: CO, NO, N₂O.

Оксидтерді алу: жай заттарды жағу (4P + 5O₂ → 2P₂O₅), күрделі заттарды жағу (2ZnS + 3O₂ → 2ZnO + 2SO₂), ерімейтін негіздерді, кейбір тұздар мен қышқылдарды айыру (Cu(OH)₂ → CuO + H₂O; CaCO₃ → CaO + CO₂).

## §43. Оксидтердің қасиеттері мен қолданылуы (8-сынып, 150-б.)

Негіздік оксидтердің қасиеттері:
1) сілтілік және сілтілік-жер металдардың оксидтері сумен сілті түзеді: CaO + H₂O → Ca(OH)₂ (әкті сөндіру), Na₂O + H₂O → 2NaOH; CuO, FeO сумен әрекеттеспейді;
2) қышқылдармен тұз бен су түзеді: CuO + H₂SO₄ → CuSO₄ + H₂O (қара ұнтақ еріп, көк ерітінді түзіледі);
3) қышқылдық оксидтермен тұз түзеді: CaO + CO₂ → CaCO₃.

Қышқылдық оксидтердің қасиеттері:
1) көпшілігі сумен қышқыл түзеді: SO₃ + H₂O → H₂SO₄; P₂O₅ + 3H₂O → 2H₃PO₄ (SiO₂ сумен әрекеттеспейді);
2) сілтілермен тұз бен су түзеді: CO₂ + 2NaOH → Na₂CO₃ + H₂O; CO₂ + Ca(OH)₂ → CaCO₃↓ + H₂O (әк суының лайлануы — CO₂-ге сапалық реакция);
3) негіздік оксидтермен тұз түзеді: SiO₂ + CaO → CaSiO₃ (қыздырғанда).

Амфотерлі оксидтер екі жақты қасиет көрсетеді: ZnO + 2HCl → ZnCl₂ + H₂O; ZnO + 2NaOH → Na₂ZnO₂ + H₂O (балқытқанда).

Қолданылуы: CaO — құрылыста (әк), SiO₂ — шыны мен цемент өндірісі, Fe₂O₃ және Fe₃O₄ — темір кендері, Al₂O₃ — алюминий алу, корунд (абразив), TiO₂ мен ZnO — ақ бояулар, CO₂ — газдалған сусындар, өрт сөндіру, құрғақ мұз.

## §44. Қышқылдар: құрамы, жіктелуі, атаулары (8-сынып, 154-б.)

Қышқылдар — құрамында металл атомдарымен орын алмаса алатын сутек атомдары және қышқыл қалдығы бар күрделі заттар. Суда ерігенде сутек катиондарын (H⁺) түзеді.

Жіктелуі:
Оттегінің болуына қарай: оттексіз (HCl — тұз қышқылы, HBr, HI, HF — балқытқыш қышқыл, H₂S — күкіртсутек қышқылы) және оттекті (H₂SO₄ — күкірт, H₂SO₃ — күкіртті, HNO₃ — азот, HNO₂ — азотты, H₃PO₄ — фосфор, H₂CO₃ — көмір, H₂SiO₃ — кремний қышқылы).
Негізділігіне (сутек атомдарының санына) қарай: бір негізді (HCl, HNO₃), екі негізді (H₂SO₄, H₂CO₃), үш негізді (H₃PO₄).
Күшіне қарай: күшті (HCl, HNO₃, H₂SO₄) және әлсіз (H₂CO₃, H₂S, H₂SiO₃); H₃PO₄ — орта күшті.
Тұрақтылығына қарай: тұрақсыз қышқылдар оңай айырылады: H₂CO₃ → H₂O + CO₂; H₂SO₃ → H₂O + SO₂.

Қышқыл қалдықтары және олардың тұздарының атауы: Cl⁻ — хлорид, SO₄²⁻ — сульфат, SO₃²⁻ — сульфит, S²⁻ — сульфид, NO₃⁻ — нитрат, PO₄³⁻ — фосфат, CO₃²⁻ — карбонат, SiO₃²⁻ — силикат.

Алу: қышқылдық оксид + су (SO₃ + H₂O → H₂SO₄); сутек + бейметалл, газды суда еріту (H₂ + Cl₂ → 2HCl); тұз бен күштірек қышқыл (2NaCl(қ) + H₂SO₄(конц) → Na₂SO₄ + 2HCl↑).

Қауіпсіздік: концентрлі күкірт қышқылын сұйылтқанда қышқылды суға жіңішке ағынмен құю керек, керісінше емес («алдымен су, кейін қышқыл»).

## §45. Қышқылдардың қасиеттері (8-сынып, 158-б.)

Индикаторлармен: лакмус қызарады, метилоранж қызғылт-қызыл түске өзгереді, фенолфталеин түссіз қалады. Әмбебап индикатор қағазы қызыл немесе қызғылт түс береді (pH < 7).

Металдармен (кернеу қатарында сутекке дейінгілері): Zn + H₂SO₄(сұйыл) → ZnSO₄ + H₂↑; Fe + 2HCl → FeCl₂ + H₂↑. Мыс, күміс сұйылтылған HCl және H₂SO₄-пен әрекеттеспейді.

Негіздік және амфотерлі оксидтермен: CuO + 2HCl → CuCl₂ + H₂O; Al₂O₃ + 6HCl → 2AlCl₃ + 3H₂O.

Негіздермен (бейтараптану реакциясы): NaOH + HCl → NaCl + H₂O; Cu(OH)₂ + H₂SO₄ → CuSO₄ + 2H₂O. Бейтараптану — қышқыл мен негіздің әрекеттесіп, тұз бен су түзуі.

Тұздармен (егер тұнба, газ немесе әлсіз қышқыл түзілсе): HCl + AgNO₃ → AgCl↓ + HNO₃ (ақ ірімшік тәрізді тұнба — хлорид ионына сапалық реакция); Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑ (көпіршіктер); H₂SO₄ + BaCl₂ → BaSO₄↓ + 2HCl (ақ тұнба).

Қолданылуы: H₂SO₄ — тыңайтқыштар, аккумуляторлар, бояғыштар өндірісі; HCl — металдарды тазарту, асқазан сөлінің құрамында; HNO₃ — тыңайтқыштар, жарылғыш заттар; H₃PO₄ — тыңайтқыштар, тағам қоспасы; органикалық қышқылдар (сірке, лимон) — тағам өнеркәсібінде.

## §46. Негіздер: құрамы, жіктелуі, атаулары (8-сынып, 164-б.)

Негіздер — металл атомы мен бір немесе бірнеше гидроксид топтарынан (OH⁻) тұратын күрделі заттар: NaOH, Ca(OH)₂, Fe(OH)₃. Атауы: металл атауы + (валенттілігі) + «гидроксиді»: Fe(OH)₂ — темір(II) гидроксиді.

Жіктелуі: суда еритін негіздер — сілтілер (LiOH, NaOH, KOH, Ca(OH)₂ — аз ериді, Ba(OH)₂) және суда ерімейтін негіздер (Cu(OH)₂ — көгілдір, Fe(OH)₂ — ақшыл-жасыл, Fe(OH)₃ — қоңыр, Mg(OH)₂ — ақ). Қышқылдылығына (OH топтарының санына) қарай бір қышқылды (NaOH), екі қышқылды (Ca(OH)₂), үш қышқылды (Fe(OH)₃). Амфотерлі гидроксидтер: Zn(OH)₂, Al(OH)₃.

Тұрмыстық атаулары: NaOH — күйдіргіш натр, KOH — күйдіргіш кали, Ca(OH)₂ — сөндірілген әк (оның мөлдір ерітіндісі — әк суы, суспензиясы — әк сүті).

Алу: белсенді металл + су (2Na + 2H₂O → 2NaOH + H₂↑); негіздік оксид + су (CaO + H₂O → Ca(OH)₂); ерімейтін негіздер — тұз ерітіндісі мен сілтінің әрекеттесуі: CuSO₄ + 2NaOH → Cu(OH)₂↓ + Na₂SO₄; FeCl₃ + 3NaOH → Fe(OH)₃↓ + 3NaCl. Өнеркәсіпте NaOH ас тұзы ерітіндісін электролиздеп алынады.

Қауіпсіздік: сілтілер теріні, көзді күйдіреді — қорғаныш көзілдірігі мен қолғап қажет.

## §47. Негіздердің қасиеттері (8-сынып, 167-б.)

Сілтілердің қасиеттері:
1) индикаторлардың түсін өзгертеді: фенолфталеин таңқурай (малина) түсті, лакмус көк, метилоранж сары болады (pH > 7);
2) қышқылдармен бейтараптану реакциясы: 2KOH + H₂SO₄ → K₂SO₄ + 2H₂O;
3) қышқылдық оксидтермен: 2NaOH + SO₂ → Na₂SO₃ + H₂O; Ca(OH)₂ + CO₂ → CaCO₃↓ + H₂O;
4) тұз ерітінділерімен (тұнба немесе газ түзілсе): 2NaOH + CuCl₂ → Cu(OH)₂↓ + 2NaCl; NaOH + NH₄Cl → NaCl + NH₃↑ + H₂O;
5) амфотерлі гидроксидтерді ерітеді: Al(OH)₃ + NaOH → Na[Al(OH)₄].

Ерімейтін негіздердің қасиеттері:
1) индикатор түсін өзгертпейді;
2) қышқылдармен әрекеттеседі: Cu(OH)₂ + 2HCl → CuCl₂ + 2H₂O;
3) қыздырғанда оксид пен суға айырылады: Cu(OH)₂ → CuO + H₂O (көгілдір тұнба қараяды); 2Fe(OH)₃ → Fe₂O₃ + 3H₂O.

Сілтілердің ерекшелігі: олар қыздырғанда айырылмайды (LiOH-тан басқасы), ауадағы CO₂-ні сіңіріп, карбонатқа айналады, сондықтан ыдыс тығыз жабылады.

Қолданылуы: NaOH — сабын, қағаз, жасанды талшық өндірісі, мұнайды тазарту; Ca(OH)₂ — құрылыс ерітінділері, ағаштарды ағарту, топырақтың қышқылдығын азайту, қант өндірісі; Mg(OH)₂, Al(OH)₃ — асқазан қышқылдығын азайтатын дәрілер құрамында.

## §48. Тұздар: құрамы, жіктелуі, атаулары (8-сынып, 170-б.)

Тұздар — металл катиондары (немесе аммоний NH₄⁺) мен қышқыл қалдығы аниондарынан тұратын күрделі заттар. Оларды қышқылдағы сутектің металмен толық немесе ішінара орын басуының өнімі деп қарастыруға болады.

Жіктелуі:
Орта (қалыпты) тұздар — сутек толық алмасқан: NaCl, K₂SO₄, Ca₃(PO₄)₂.
Қышқыл тұздар — сутек толық алмаспаған (көп негізді қышқылдардан): NaHCO₃ — натрий гидрокарбонаты (ас содасы), KHSO₄, Ca(H₂PO₄)₂ — кальций дигидрофосфаты.
Негіздік тұздар — гидроксотоптары бар: (CuOH)₂CO₃ — малахит, Mg(OH)Cl.
Сондай-ақ қос тұздар (KAl(SO₄)₂·12H₂O — ашудас) және кешенді тұздар (K₃[Fe(CN)₆]) бар.

Атауы: металл + (валенттілігі) + қышқыл қалдығының атауы: FeSO₄ — темір(II) сульфаты, Fe₂(SO₄)₃ — темір(III) сульфаты, AgNO₃ — күміс нитраты, Na₂SiO₃ — натрий силикаты.

Тұрмыстық атаулары: NaCl — ас тұзы, Na₂CO₃ — кальцийленген сода, NaHCO₃ — ас содасы, CaCO₃ — бор, әктас, мәрмәр, CuSO₄·5H₂O — мыс купоросы, KMnO₄ — «марганцовка», NaNO₃ — чили селитрасы.

## §49. Тұздардың алынуы және қасиеттері (8-сынып, 173-б.)

Тұздарды алу тәсілдері (10-нан аса әдіс бар), негізгілері:
металл + бейметалл: 2Na + Cl₂ → 2NaCl;
металл + қышқыл: Mg + 2HCl → MgCl₂ + H₂↑;
металл + тұз: Fe + CuSO₄ → FeSO₄ + Cu;
негіздік оксид + қышқыл: CuO + H₂SO₄ → CuSO₄ + H₂O;
қышқылдық оксид + сілті: CO₂ + 2NaOH → Na₂CO₃ + H₂O;
негіздік оксид + қышқылдық оксид: CaO + SiO₂ → CaSiO₃;
негіз + қышқыл (бейтараптану): NaOH + HCl → NaCl + H₂O;
тұз + тұз: AgNO₃ + NaCl → AgCl↓ + NaNO₃.

Химиялық қасиеттері:
1) металдармен (белсендірегі ығыстырады): Zn + CuCl₂ → ZnCl₂ + Cu;
2) қышқылдармен (тұнба, газ немесе әлсіз қышқыл түзілсе): CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑;
3) сілтілермен (ерімейтін негіз түзілсе): FeCl₃ + 3NaOH → Fe(OH)₃↓ + 3NaCl;
4) басқа тұздармен (ерімейтін тұз түзілсе): BaCl₂ + Na₂SO₄ → BaSO₄↓ + 2NaCl;
5) кейбір тұздар қыздырғанда айырылады: CaCO₃ → CaO + CO₂; 2NaHCO₃ → Na₂CO₃ + H₂O + CO₂; 2KNO₃ → 2KNO₂ + O₂.

Ерігіштік кестесін пайдаланып, алмасу реакциясының жүру-жүрмеуін болжаймыз. Тұздар мен негіздердің реакциялары үшін екі реагент те суда еритін болуы керек.

## §50. Бейорганикалық қосылыстардың кластары арасындағы генетикалық байланыс (8-сынып, 176-б.)

Генетикалық байланыс — бір класс заттарынан екінші класс заттарын алу мүмкіндігі; бір элементтің жай затынан бастап, оның түрлі қосылыстары арқылы тұзға дейін жететін тізбек — генетикалық қатар.

Металдың генетикалық қатары: металл → негіздік оксид → негіз → тұз.
Мысал: Ca → CaO → Ca(OH)₂ → CaCO₃ (немесе CaCl₂).
2Ca + O₂ → 2CaO; CaO + H₂O → Ca(OH)₂; Ca(OH)₂ + CO₂ → CaCO₃↓ + H₂O.
Ерімейтін негізі бар металл үшін тізбек тұз арқылы жүреді: Cu → CuO → CuCl₂ → Cu(OH)₂ → CuO.

Бейметалдың генетикалық қатары: бейметалл → қышқылдық оксид → қышқыл → тұз.
Мысал: P → P₂O₅ → H₃PO₄ → Na₃PO₄. 4P + 5O₂ → 2P₂O₅; P₂O₅ + 3H₂O → 2H₃PO₄; H₃PO₄ + 3NaOH → Na₃PO₄ + 3H₂O.
Мысал: S → SO₂ → SO₃ → H₂SO₄ → BaSO₄.

Екі қатар тұз арқылы тоғысады: металл қатарының заттары бейметалл қатарының заттарымен әрекеттесіп, тұз береді (негіздік оксид + қышқылдық оксид, негіз + қышқыл, т.б.). Бұл заңдылық бейорганикалық заттардың біртұтас жүйе екенін көрсетеді.

Тізбекті есептерді шешу кеңесі: әр көрсеткі үшін қандай реагент қосу керектігін анықтап, теңдеуді теңестіру; тізбектің соңында тұзды алу үшін ерігіштік кестесін тексеру.

## 6–9-зертханалық тәжірибелер. Оксидтердің, қышқылдардың, негіздердің және тұздардың қасиеттерін зерттеу (8-сынып, 179–182-б.)

6-тәжірибе. Оксидтердің қасиеттері: күкіртті зертханалық қасықта жағып, түзілген SO₂-ні бірінде лакмусы бар су, екіншісінде фенолфталеинді NaOH ерітіндісі бар екі құтыға енгізеді. Судағы лакмус қызарады (күкіртті қышқыл түзіледі), ал сілтінің таңқурай түсі жоғалады (тұз түзіліп, ерітінді бейтараптанады) — қышқылдық оксидтің қасиеттері.

7-тәжірибе. Қышқылдардың қасиеттері: индикатормен ортаны анықтау, мырыш пен мыстың қышқылға қатынасы, мыс(II) оксидін қыздырып еріту (көк ерітінді), фенолфталеинді сілтіні бейтараптау, күміс нитратымен хлорид-ионын анықтау (ақ тұнба), натрий карбонатымен CO₂ бөлу.

8-тәжірибе. Негіздердің қасиеттері: фенолфталеин тамызылған NaOH ерітіндісіне түссізденгенше қышқыл қосу (бейтараптану); әк суына шыны түтік арқылы абайлап үрлеу — дем құрамындағы CO₂ әсерінен лайлану (Ca(OH)₂ + CO₂ → CaCO₃↓ + H₂O); сілтіні мыс(II) сульфатымен және темір(III) хлоридімен әрекеттестіріп, Cu(OH)₂ (көгілдір) және Fe(OH)₃ (қоңыр) тұнбаларын алу, содан кейін тұнбаны қыздырып айыру.

9-тәжірибе. Тұздарды алу және олардың қасиеттері: темір(II) хлориді және мыс(II) хлориді ерітінділеріне натрий гидроксидін қосу (Fe(OH)₂ — ақшыл-жасыл, Cu(OH)₂ — көгілдір тұнба); тұз ерітінділеріне алюминий және болат сым батыру (белсенді металл мысты ығыстырады: 2Al + 3CuCl₂ → 2AlCl₃ + 3Cu); тұз ерітінділеріне күміс нитратын тамызу (AgCl ақ тұнбасы).
