# Химия 9-сынып · V тарау. Тотығу-тотықсыздану реакциялары

> Оқулық: Оспанова М.Қ., Аухадиева Қ.С., Белоусова Т.Г. Химия: 9-сынып, 1-бөлім. — Алматы: Мектеп, 2019. Мәтін — оқулық тақырыптары бойынша өз сөзімізбен жазылған конспект. Жақшадағы бет — параграфтың басталатын беті.

## §19. Тотығу дәрежесі (9-сынып 1-бөлім, 69-б.)

Тотығу дәрежесі — қосылыстағы барлық байланыстар иондық деп болжағандағы атомның шартты заряды. Ол оң, теріс, нөл немесе бөлшек сан болуы мүмкін; таңбасы санның алдында жазылады (+2, −3), ал ион зарядында кейін (2+, 3−).

Анықтау ережелері:
1) жай заттардағы атомдардың тотығу дәрежесі нөлге тең: Na⁰, O₂⁰, Cl₂⁰, S⁰;
2) қосылыстардағы барлық атомдардың тотығу дәрежелерінің қосындысы нөлге, ал күрделі иондарда ион зарядына тең;
3) фтор әрдайым −1; оттек әдетте −2 (пероксидтерде −1: H₂O₂, Na₂O₂; OF₂-де +2);
4) сутек металдармен қосылыстарда (гидридтерде) −1, бейметалдармен +1;
5) сілтілік металдар +1, 2-топ металдары +2, алюминий +3;
6) электртерістігі үлкен элемент теріс, кіші элемент оң тотығу дәрежесін көрсетеді.

Мысал: H₂SO₄ құрамындағы күкірт. 2·(+1) + x + 4·(−2) = 0 → x = +6.
Мысал: K₂Cr₂O₇ құрамындағы хром. 2·(+1) + 2x + 7·(−2) = 0 → x = +6.
Мысал: NH₄⁺ ионындағы азот. x + 4·(+1) = +1 → x = −3.
Мысал: KMnO₄ құрамындағы марганец: +7; MnO₂-де +4.

Жоғары тотығу дәрежесі негізгі топша элементтері үшін топ нөміріне (13–18 топтарда топ нөмірі минус 10) тең (S +6, N +5, Cl +7); бейметалдардың төменгі тотығу дәрежесі = (топ нөмірі − 18): S −2, N −3, Cl −1.

Тотығу дәрежесі мен валенттілік әрдайым тең бола бермейді: мысалы, N₂ молекуласында азоттың валенттілігі III, ал тотығу дәрежесі 0.

## §20. Тотығу-тотықсыздану реакциялары (9-сынып 1-бөлім, 72-б.)

Тотығу-тотықсыздану реакциялары (ТТР) — әрекеттесуші заттар құрамындағы элементтердің тотығу дәрежелері өзгеретін реакциялар. Олардың мәні — электрондардың бір атомнан екіншісіне ауысуы.

Тотығу — атомның (ионның) электрон беру процесі; тотығу дәрежесі артады: Fe⁰ − 2e⁻ → Fe⁺².
Тотықсыздану — электрон қосып алу процесі; тотығу дәрежесі кемиді: Cl₂⁰ + 2e⁻ → 2Cl⁻.
Тотықсыздандырғыш — электрон беретін бөлшек (өзі тотығады): металдар, H₂, C, CO, H₂S, NH₃.
Тотықтырғыш — электрон қосып алатын бөлшек (өзі тотықсызданады): O₂, галогендер, HNO₃, конц. H₂SO₄, KMnO₄, K₂Cr₂O₇.

Барлық орынбасу реакциялары, жай заттар қатысатын қосылу және айырылу реакциялары — ТТР. Алмасу реакциялары ТТР-ға жатпайды.

Электрондық баланс әдісімен теңестіру:
1) әр элементтің тотығу дәрежесін жазып, өзгергендерін табамыз;
2) тотығу және тотықсыздану процестерінің электрондық теңдеулерін құрамыз;
3) берілген және қабылданған электрондар санын теңестіретін көбейткіштерді (ЕКОЕ арқылы) табамыз;
4) көбейткіштерді теңдеуге коэффициент ретінде қойып, қалған атомдарды (соңында сутек пен оттекті) теңестіреміз.

Мысал: Al + O₂ → Al₂O₃
Al⁰ − 3e⁻ → Al⁺³ | 4 (тотығу, Al — тотықсыздандырғыш)
O₂⁰ + 4e⁻ → 2O⁻² | 3 (тотықсыздану, O₂ — тотықтырғыш)
4Al + 3O₂ → 2Al₂O₃.

Мысал: Cu + HNO₃(конц) → Cu(NO₃)₂ + NO₂ + H₂O
Cu⁰ − 2e⁻ → Cu⁺² | 1
N⁺⁵ + 1e⁻ → N⁺⁴ | 2
Cu + 4HNO₃ → Cu(NO₃)₂ + 2NO₂ + 2H₂O (екі HNO₃ тотықтырғыш, екеуі тұз түзуге жұмсалады).

Мысал: MnO₂ + 4HCl → MnCl₂ + Cl₂ + 2H₂O; Mn⁺⁴ + 2e⁻ → Mn⁺² | 1; 2Cl⁻ − 2e⁻ → Cl₂⁰ | 1.

Аралық тотығу дәрежесіндегі элементтер (S⁺⁴, N⁺³, Fe⁺², H₂O₂-дегі O⁻¹) тотықтырғыш та, тотықсыздандырғыш та бола алады.

ТТР-дың маңызы: тыныс алу, фотосинтез, жану, металдарды кендерден алу, жемірілу, электролиз, гальваникалық элементтер мен аккумуляторлар.
