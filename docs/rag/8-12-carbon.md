# Химия 8-сынып · XII тарау. Көміртек

> Оқулық: Оспанова М.Қ., Аухадиева Қ.С., Белоусова Т.Г. Химия: 8-сынып. — Алматы: Мектеп, 2018. Мәтін — оқулық тақырыптары бойынша өз сөзімізбен жазылған конспект. Жақшадағы бет — параграфтың басталатын беті.

## §51. Көміртекке жалпы сипаттама (8-сынып, 183-б.)

Көміртек (C) — 2-период, 14(IVA) топ элементі, Z = 6, Ar = 12. Электрондық құрылысы 2, 4 (1s²2s²2p²). Сыртқы деңгейінде 4 электрон бар, сондықтан оған электрон беру де, қосып алу да тиімсіз — көбіне коваленттік байланыс түзеді.

Тотығу дәрежелері: −4 (CH₄, Al₄C₃), 0 (C), +2 (CO), +4 (CO₂, H₂CO₃, карбонаттар). Қозған күйде 2s-электрондардың бірі 2p-ге ауысып, атомда 4 жұптаспаған электрон болады — сондықтан көміртек органикалық қосылыстарда әрдайым төрт валентті.

Көміртек атомдарының бір-бірімен ұзын тізбектер, тармақтар және циклдер түзе алу қабілеті миллиондаған органикалық қосылыстардың болуының себебі. Көміртек — тіршіліктің негізгі элементі.

Табиғатта: бос күйінде — алмаз, графит; қосылыстар түрінде — көмір, мұнай, табиғи газ, әктас, мәрмәр, бор (CaCO₃), доломит, малахит, ауадағы CO₂, барлық тірі ағзалар. Жер қыртысындағы үлесі шамамен 0,1%.

Табиғаттағы көміртек айналымы: атмосферадағы CO₂ фотосинтез арқылы органикалық заттарға айналады; тыныс алу, шіру, жану нәтижесінде қайтадан CO₂ түзіледі; бір бөлігі ұзақ уақыт әктас пен қазба отын түрінде сақталады.

## §52. Көміртектің аллотропиялық түрөзгерістері (8-сынып, 186-б.)

Алмаз — атомдық кристалдық торы бар, әр көміртек атомы тетраэдр төбелерінде тұрған төрт атоммен байланысқан. Ең қатты табиғи зат, түссіз, мөлдір, жарықты күшті сындырады, ток өткізбейді. Қолданылуы: бұрғылау, шыныны кесу, тегістеу құралдары, зергерлік бұйымдар (бриллиант).

Графит — қабатты құрылымды: әр қабатта атомдар алты бұрышты торлар түзеді, қабаттар арасындағы байланыс әлсіз. Сондықтан графит жұмсақ, майлы, қағазда із қалдырады, қара-сұр түсті, металдық жылтыры бар, электр тогын жақсы өткізеді. Қолданылуы: қарындаш, электродтар, балқытуға арналған тигельдер, майлау материалы, ядролық реакторларда нейтрондарды баяулатқыш.

Карбин — сызықтық тізбекті құрылымды, қара ұнтақ; фуллерендер — көміртек атомдарынан тұратын тұйық сфералық молекулалар (C₆₀ — футбол добына ұқсас); графен — графиттің бір атомдық қабаты, өте берік әрі жоғары өткізгіш; көміртекті нанотүтікшелер.

Аморфты көміртек (кокс, ағаш көмірі, күйе) — ұсақ кристалды графит түрлері. Ағаш көмірі мен белсендірілген көмір кеуекті, беті өте үлкен, сондықтан газдар мен еріген заттарды бетіне сіңіреді — бұл адсорбция құбылысы. Қолданылуы: противогаздар (Н.Д. Зелинский), суды және ауаны тазарту, медицинада уланғанда (белсендірілген көмір таблеткасы), қантты тазарту.

Алмазды жасанды жолмен графиттен өте жоғары қысым мен температурада алады.

## §53. Көміртектің химиялық қасиеттері. Көміртек қосылыстары (8-сынып, 191-б.)

Қалыпты жағдайда көміртек белсенді емес, қыздырғанда белсенділігі артады.

Тотықсыздандырғыш ретінде:
оттекпен: C + O₂ → CO₂ (оттек жеткілікті болса); 2C + O₂ → 2CO (оттек жетіспесе);
металл оксидтерімен: 2CuO + C → 2Cu + CO₂; Fe₂O₃ + 3C → 2Fe + 3CO (металлургия негізі);
CO₂-мен: CO₂ + C → 2CO (қыздырғанда);
су буымен: C + H₂O → CO + H₂ (су газы).
Тотықтырғыш ретінде: металдармен карбидтер (Ca + 2C → CaC₂; 4Al + 3C → Al₄C₃), сутекпен метан (C + 2H₂ → CH₄, катализатор, қыздыру).

Көміртек(II) оксиді CO (иіс газы) — түссіз, иіссіз, өте улы газ: қан гемоглобинімен берік қосылып, оттек тасымалдауды бұзады. Тұз түзбейтін оксид. Көкшіл жалынмен жанады: 2CO + O₂ → 2CO₂. Жақсы тотықсыздандырғыш: Fe₂O₃ + 3CO → 2Fe + 3CO₂ (домна пеші).

Көміртек(IV) оксиді CO₂ (көмірқышқыл газы) — түссіз, иіссіз, ауадан 1,5 есе ауыр, жануды демейді. Қатты күйі — «құрғақ мұз». Қышқылдық оксид: CO₂ + H₂O ⇄ H₂CO₃; CO₂ + Ca(OH)₂ → CaCO₃↓ + H₂O (әк суының лайлануы — анықтау реакциясы); артық CO₂ өткізгенде тұнба ериді: CaCO₃ + CO₂ + H₂O → Ca(HCO₃)₂. Зертханада алу: CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑. Өнеркәсіпте — әктасты күйдіріп. Қолданылуы: газдалған сусындар, өрт сөндіргіштер, тоңазытқыштар (құрғақ мұз), жылыжайларда өсімдікті қоректендіру, сода өндірісі.

Көмір қышқылы H₂CO₃ — әлсіз, тұрақсыз екі негізді қышқыл, тек ерітіндіде болады. Тұздары: карбонаттар (Na₂CO₃ — сода, CaCO₃, K₂CO₃ — поташ) және гидрокарбонаттар (NaHCO₃ — ас содасы, Ca(HCO₃)₂). Карбонат ионына сапалық реакция — күшті қышқыл қосқанда «қайнау» (CO₂ бөлінуі), газ әк суын лайлайды.

## 6-практикалық жұмыс. Көміртектің физикалық және химиялық қасиеттері (8-сынып, 196-б.)

1-тәжірибе: көмір, графит (қарындаш өзегі) және белсендірілген көмірдің сыртқы түрін, түсін, қаттылығын, ұстағандағы сезімін салыстыру; мүмкін болса, белсендірілген көмірді микроскоппен қарау (кеуектері көрінеді).

2-тәжірибе: фуксин немесе сияның әлсіз ерітіндісіне белсендірілген көмір салып шайқағанда ерітінді түссізденеді — бояғыш көмір бетіне адсорбцияланды.

3-тәжірибе: тұтандырылған көмірді оттек толтырылған құтыға енгізгенде ол жарқырап жанады; содан кейін құтыға әк суын құйғанда лайланады — CO₂ түзілгенін дәлелдейді: C + O₂ → CO₂; CO₂ + Ca(OH)₂ → CaCO₃↓ + H₂O.

4-тәжірибе: мыс(II) оксидін көмір ұнтағымен араластырып қыздыру — қара қоспада қызыл мыс түйірлері пайда болады, бөлінген газ әк суын лайлайды: 2CuO + C → 2Cu + CO₂.

## 7-практикалық жұмыс. Көмірқышқыл газын алу және оның қасиеттерін зерттеу (8-сынып, 197-б.)

Сынауыққа бор немесе мәрмәр түйірлері салынып, үстіне тұз қышқылы құйылады: CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑. Газ түтігі арқылы бөлінген CO₂ стақанға жиналады (ауадан ауыр, ыдыс аузы жоғары қаратылады).

Қасиеттерін зерттеу: жанып тұрған шырақты стақанға енгізгенде ол сөнеді — CO₂ жануды демейді; газды лакмусы бар суға өткізгенде лакмус қызғылт түске енеді — көмір қышқылы түзіледі; әк суынан өткізгенде алдымен лайланады, ал газды ұзақ өткізгенде гидрокарбонат түзіліп, лай қайта ериді.

Қорытындыда реакция теңдеулері жазылып, CO₂-нің ауадан ауыр, жануды демейтін қышқылдық оксид екені тұжырымдалады.
