# Химия 9-сынып · VIII тарау (1-бөлігі). 17(VIIA) және 16(VIA) топ элементтері: галогендер, оттек тобы, күкірт

> Оқулық: Оспанова М.Қ., Аухадиева Қ.С., Белоусова Т.Г. Химия: 9-сынып, 2-бөлім. — Алматы: Мектеп, 2019. Мәтін — оқулық тақырыптары бойынша өз сөзімізбен жазылған конспект. Жақшадағы бет — параграфтың басталатын беті.

## §28. Галогендер: жалпы сипаттамасы (9-сынып 2-бөлім, 3-б.)

17(VIIA) топ элементтері — фтор F, хлор Cl, бром Br, иод I, астат At — галогендер («тұз туғызушылар») деп аталады. Сыртқы деңгейінде 7 электрон (ns²np⁵), бір электрон жетіспейді, сондықтан күшті тотықтырғыштар. Қосылыстарда −1 тотығу дәрежесін көрсетеді; фтордан басқалары оттекпен қосылыстарда +1, +3, +5, +7 тотығу дәрежелерін де көрсетеді (фтор — ең электртеріс элемент, тек −1).

Жай заттары — екі атомды молекулалар, коваленттік полюссіз байланыс: F₂ — ақшыл-сары газ, Cl₂ — сарғыш-жасыл газ, Br₂ — қызыл-қоңыр сұйықтық (жалғыз сұйық бейметалл), I₂ — күлгін жылтыры бар қара-сұр кристалдар, қыздырғанда айдалады (сублимацияланады). Барлығы өткір иісті және улы.

F-тан I-ға қарай: атом радиусы артады, электртерістік пен тотықтырғыштық қасиет кемиді, балқу және қайнау температуралары артады, түсі қоюланады.

Белсенді галоген белсенділігі төменін оның тұзынан ығыстырады: Cl₂ + 2KBr → 2KCl + Br₂; Cl₂ + 2KI → 2KCl + I₂; Br₂ + 2KI → 2KBr + I₂. Иод крахмалмен көк түс береді — иодқа сапалық реакция.

Галогенсутектер: HF, HCl, HBr, HI — түссіз газдар, суда жақсы ериді, ерітінділері қышқылдар. HF → HI қатарында қышқыл күші артады (HF — әлсіз, HI — ең күшті).

Табиғатта тек қосылыстар түрінде: флюорит CaF₂, ас тұзы NaCl, сильвин KCl, теңіз суындағы бромидтер мен иодидтер, теңіз балдырлары (иод).

Биологиялық маңызы: фтор тіс кіреукесіне қажет; хлор (Cl⁻) асқазан сөлінде; иод қалқанша без гормондарының құрамында — жетіспегенде зоб ауруы, сондықтан ас тұзын иодтайды.

## §29. Хлор (9-сынып 2-бөлім, 7-б.)

Хлор: Z = 17, 1s²2s²2p⁶3s²3p⁵. Тотығу дәрежелері −1, 0, +1, +3, +5, +7.

Физикалық қасиеттері: сарғыш-жасыл, тұншықтыратын өткір иісті, ауадан 2,5 есе ауыр, улы газ. Қысыммен оңай сұйылады. Суда ериді — хлор суы.

Алу:
зертханада — концентрлі тұз қышқылына тотықтырғышпен әсер ету: MnO₂ + 4HCl → MnCl₂ + Cl₂↑ + 2H₂O; 2KMnO₄ + 16HCl → 2KCl + 2MnCl₂ + 5Cl₂↑ + 8H₂O;
өнеркәсіпте — ас тұзы ерітіндісін электролиздеу: 2NaCl + 2H₂O → 2NaOH + H₂↑ + Cl₂↑ (бір мезгілде NaOH пен H₂ алынады).

Химиялық қасиеттері (күшті тотықтырғыш):
металдармен: 2Na + Cl₂ → 2NaCl; 2Fe + 3Cl₂ → 2FeCl₃ (темір +3 дейін тотығады); Cu + Cl₂ → CuCl₂;
сутекпен: H₂ + Cl₂ → 2HCl (жарықта жарылыспен);
фосформен: 2P + 3Cl₂ → 2PCl₃; 2P + 5Cl₂ → 2PCl₅;
сумен: Cl₂ + H₂O ⇄ HCl + HClO; хлорлылау қышқылы HClO тұрақсыз, атомдық оттек бөліп ыдырайды — хлор суының ағартқыш және зарарсыздандырғыш әсері осыған байланысты;
сілтілермен: суықта Cl₂ + 2NaOH → NaCl + NaClO + H₂O (жавель суы); 2Cl₂ + 2Ca(OH)₂ → CaCl₂ + Ca(ClO)₂ + 2H₂O (хлорлы әк);
бромидтер мен иодидтерден бром мен иодты ығыстырады.

Қолданылуы: ауыз су мен бассейн суын зарарсыздандыру, ағартқыштар, тұз қышқылы, поливинилхлорид (ПВХ), дәрілер мен пестицидтер, еріткіштер өндірісі. Бірінші дүниежүзілік соғыста хлор алғашқы химиялық қару ретінде қолданылған — оның улылығын еске салатын тарихи дерек.

Қауіпсіздік: хлормен жұмыс тек тартпа шкафта; улану кезінде таза ауаға шығару.

## §30. Хлорсутек қышқылы (тұз қышқылы) (9-сынып 2-бөлім, 12-б.)

Хлорсутек HCl — түссіз, өткір иісті газ, ауадан ауыр, суда өте жақсы ериді (1 көлем суда шамамен 500 көлем HCl). Ылғалды ауада «түтіндейді» (ұсақ қышқыл тамшылары түзіледі). Оның судағы ерітіндісі — хлорсутек қышқылы (тұз қышқылы); концентрлі ерітіндісі ≈ 37%.

Алу: зертханада — қатты ас тұзына концентрлі күкірт қышқылымен қыздырып әсер ету: NaCl(қ) + H₂SO₄(конц) → NaHSO₄ + HCl↑; өнеркәсіпте — сутекті хлорда жағу: H₂ + Cl₂ → 2HCl, түзілген газды суға сіңіру.

Химиялық қасиеттері — күшті бір негізді қышқыл, қышқылдардың барлық ортақ қасиеттері бар:
индикаторлар: лакмус қызарады;
металдармен: Zn + 2HCl → ZnCl₂ + H₂↑ (мыс әрекеттеспейді);
негіздік оксидтермен: MgO + 2HCl → MgCl₂ + H₂O;
негіздермен: KOH + HCl → KCl + H₂O;
тұздармен: CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑;
тотықсыздандырғыш ретінде күшті тотықтырғыштармен хлор бөледі (MnO₂, KMnO₄).

Хлорид ионына сапалық реакция: Ag⁺ + Cl⁻ → AgCl↓ — ақ ірімшік тәрізді тұнба, азот қышқылында ерімейді.

Тұздары — хлоридтер: NaCl (ас тұзы), KCl (тыңайтқыш), CaCl₂ (кептіргіш, жолдарды мұздан тазарту), ZnCl₂ (дәнекерлеу кезінде металды тазарту), AgCl (фотографияда), HgCl₂ (сулема, өте улы).

Маңызы: асқазан сөлінде 0,2–0,5% HCl бар — ол асқорытуға қатысады, микробтарды жояды. Өнеркәсіпте металдарды тат пен қақтан тазарту, хлоридтер, дәрілер, бояғыштар өндірісі.

## §31. 16(VIA) топ элементтері: жалпы сипаттамасы (9-сынып 2-бөлім, 15-б.)

16(VIA) топ — оттек O, күкірт S, селен Se, теллур Te, полоний Po (халькогендер, «кен туғызушылар»). Сыртқы деңгейде 6 электрон (ns²np⁴). Тотығу дәрежелері: оттек — негізінен −2; күкірт пен келесілері −2, +4, +6.

O-дан Te-ге қарай атом радиусы артады, бейметалдық қасиеттер мен электртерістік кемиді; полоний — металл, радиоактивті. Сутекті қосылыстары H₂O, H₂S, H₂Se, H₂Te; H₂S-тен H₂Te-ге қарай қышқылдық қасиет пен тотықсыздандырғыштық күшейеді. Жоғары оксидтері RO₃ (SO₃, SeO₃) — қышқылдық, оларға H₂RO₄ қышқылдары сәйкес келеді.

Оттек пен күкірттің айырмашылығы: оттек атомы кіші, электртерістігі үлкен, жай заты — газ (O₂, O₃); күкірт — қатты сары зат, бірнеше аллотропиялық түрөзгерісі бар.

Күкірттің аллотропиясы: ромбылық күкірт (ең тұрақты, S₈ тәж тәрізді молекулалар, сары кристалдар), моноклиндік күкірт (ине тәрізді кристалдар, 96 °C-тан жоғары тұрақты), пластикалық күкірт (балқыған күкіртті суық суға құйғанда түзілетін созылғыш қоңыр масса, біртіндеп ромбылыққа айналады).

## §32. Табиғаттағы күкірт және оны алу. Күкірттің қасиеттері (9-сынып 2-бөлім, 18-б.)

Табиғатта: бос күйінде (саф күкірт — жанартау аймақтарында) және қосылыстар түрінде — сульфидтер (пирит FeS₂, мырыш алдамышы ZnS, қорғасын жылтыры PbS, мыс жылтыры Cu₂S, киноварь HgS) және сульфаттар (гипс CaSO₄·2H₂O, глаубер тұзы Na₂SO₄·10H₂O). Мұнай мен табиғи газда күкіртсутек және күкіртті органикалық қосылыстар бар (Қазақстанда — Теңіз, Қашаған кен орындары; газды тазартқанда көп күкірт алынады). Күкірт белоктардың құрамына кіреді.

Алу: жер астындағы саф күкіртті ыстық су буымен балқытып шығару; табиғи газдағы күкіртсутектен: 2H₂S + O₂ → 2S + 2H₂O немесе 2H₂S + SO₂ → 3S + 2H₂O.

Физикалық қасиеттері: сары, морт, суда ерімейді және суланбайды (флотация әдісі осыған негізделген), 113–119 °C-та балқиды, ток пен жылуды өткізбейді.

Химиялық қасиеттері — тотықтырғыш та, тотықсыздандырғыш та:
металдармен (тотықтырғыш): Fe + S → FeS; Zn + S → ZnS; Hg + S → HgS (төгілген сынапты зарарсыздандыру — демеркуризация);
сутекпен: H₂ + S → H₂S;
оттекпен (тотықсыздандырғыш): S + O₂ → SO₂ (көкшіл жалын);
күшті тотықтырғыштармен: S + 2HNO₃(конц) → H₂SO₄ + 2NO (немесе NO₂ түзіле).

Қолданылуы: күкірт қышқылы өндірісі (негізгі тұтынушы), резеңкені вулкандау, сіріңке, қара оқ-дәрі, ауыл шаруашылығында зиянкестерге қарсы, тері ауруларына қарсы жақпа майлар.

## §33. Күкірттің қосылыстары: күкіртсутек, күкірт оксидтері (9-сынып 2-бөлім, 21-б.)

Күкіртсутек H₂S — түссіз, шіріген жұмыртқа иісті, өте улы газ. Тотығу дәрежесі −2, сондықтан тек тотықсыздандырғыш: 2H₂S + 3O₂ → 2SO₂ + 2H₂O (жеткілікті оттекте); 2H₂S + O₂ → 2S + 2H₂O (оттек жетіспесе). Суда ерігенде әлсіз екі негізді күкіртсутек қышқылын түзеді; тұздары — сульфидтер. Сапалық реакция: Pb²⁺ + S²⁻ → PbS↓ (қара тұнба), Cu²⁺ + S²⁻ → CuS↓ (қара).

Күкірт(IV) оксиді SO₂ (күкіртті газ) — түссіз, жанған сіріңке иісті, улы газ, суда жақсы ериді. Қышқылдық оксид: SO₂ + H₂O ⇄ H₂SO₃ (күкіртті қышқыл — әлсіз, тұрақсыз; тұздары — сульфиттер); SO₂ + 2NaOH → Na₂SO₃ + H₂O. Тотығу дәрежесі +4 аралық, сондықтан екі жақты: тотықсыздандырғыш — 2SO₂ + O₂ ⇄ 2SO₃ (катализатор V₂O₅); тотықтырғыш — SO₂ + 2H₂S → 3S + 2H₂O. Ағартқыш және зарарсыздандырғыш әсері бар (жүнді, жібекті ағарту, жеміс-жидекті консервілеу, қоймаларды дезинфекциялау). Ауадағы SO₂ — қышқыл жаңбырдың басты себептерінің бірі.

Күкірт(VI) оксиді SO₃ — түссіз, ұшқыш сұйықтық (≈ 17 °C-тан төмен кристалданады). Қышқылдық оксид, сумен күшті жылу бөле әрекеттеседі: SO₃ + H₂O → H₂SO₄. Тек тотықтырғыш (күкірт ең жоғары +6 күйде).

## §34. Күкірт қышқылы және оның тұздары (9-сынып 2-бөлім, 24-б.)

Күкірт қышқылы H₂SO₄ — түссіз, майлы, ауыр сұйықтық (96%-дық ерітіндінің тығыздығы ≈ 1,84 г/см³), ұшқыш емес. Сумен кез келген қатынаста араласады, көп жылу бөледі, сондықтан «қышқылды суға құй» ережесі сақталады. Гигроскопиялық — газдарды кептіруге қолданылады, органикалық заттарды көмірлендіреді (қант, қағаз, ағаш қараяды).

Өндіру (жанасу әдісі) үш сатыда:
1) SO₂ алу — пиритті күйдіру немесе күкіртті жағу: 4FeS₂ + 11O₂ → 2Fe₂O₃ + 8SO₂; S + O₂ → SO₂;
2) SO₂-ні тотықтыру: 2SO₂ + O₂ ⇄ 2SO₃ + Q (V₂O₅, ≈ 450 °C, артық ауа);
3) SO₃-ті концентрлі күкірт қышқылына сіңіру — олеум түзіледі (H₂SO₄·nSO₃), содан кейін сұйылтып керекті концентрацияға жеткізеді (SO₃-ті тікелей суға сіңірмейді, себебі қышқыл тұманы түзіледі).

Сұйылтылған H₂SO₄ — күшті екі негізді қышқыл: сутекке дейінгі металдармен H₂ бөледі (Zn + H₂SO₄ → ZnSO₄ + H₂↑), негіздік оксидтермен, негіздермен, тұздармен әрекеттеседі. Екі тұз қатарын түзеді: орта — сульфаттар (Na₂SO₄), қышқыл — гидросульфаттар (NaHSO₄).

Концентрлі H₂SO₄ — күшті тотықтырғыш (S⁺⁶ есебінен): сутектен кейінгі металдармен де әрекеттеседі, сутек бөлінбейді: Cu + 2H₂SO₄(конц) → CuSO₄ + SO₂↑ + 2H₂O. Белсенді металдармен SO₂, S немесе H₂S түзілуі мүмкін. Бейметалдарды тотықтырады: C + 2H₂SO₄ → CO₂ + 2SO₂ + 2H₂O. Суық концентрлі қышқыл темір мен алюминийді пассивтейді — сондықтан болат цистерналарда тасымалданады.

Сульфат ионына сапалық реакция: Ba²⁺ + SO₄²⁻ → BaSO₄↓ — қышқылдарда ерімейтін ақ тұнба.

Маңызды сульфаттар: CuSO₄·5H₂O — мыс купоросы (өсімдіктерді қорғау, бордо сұйығы); FeSO₄·7H₂O — темір купоросы; CaSO₄·2H₂O — гипс; Na₂SO₄·10H₂O — глаубер тұзы; MgSO₄·7H₂O — ащы тұз; BaSO₄ — рентген зерттеуінде «барий ботқасы» (ерімейтіндіктен улы емес); (NH₄)₂SO₄ — тыңайтқыш; KAl(SO₄)₂·12H₂O — ашудас.

Қолданылуы: тыңайтқыштар өндірісі (ең көп), аккумулятор электролиті, мұнай өнімдерін тазарту, бояғыштар, дәрілер, жарылғыш заттар, басқа қышқылдар өндірісі. Күкірт қышқылының өндіріс көлемі елдің химия өнеркәсібі дамуының көрсеткіші саналады.

## §35. Өнім шығымының массалық және көлемдік үлестерін есептеу (9-сынып 2-бөлім, 28-б.)

Іс жүзінде алынған өнімнің мөлшері теңдеу бойынша есептелген (теориялық) мөлшерден әрдайым аз болады: реакциялар толық жүрмейді, өнімнің бір бөлігі бөліп алу кезінде жоғалады, жанама реакциялар жүреді.

Өнім шығымы (η) — практикалық массаның (көлемнің) теориялық массаға (көлемге) қатынасы:
η = m(практ.) / m(теор.) немесе η = V(практ.) / V(теор.); пайызбен ×100%.

Есептің үш түрі:
1) шығымды табу — теориялық массаны теңдеуден есептеп, практикалық массаға бөлеміз;
2) практикалық массаны табу — m(практ.) = m(теор.) · η;
3) бастапқы заттың қажетті массасын табу — m(теор.) = m(практ.) / η, содан кейін теңдеу бойынша кері есептеу.

Мысал: 32 г күкірт жанғанда іс жүзінде 57,6 г SO₂ алынды. Шығым қанша? S + O₂ → SO₂; n(S) = 1 моль; m(теор.)(SO₂) = 64 г; η = 57,6 / 64 = 0,9 (90%).

Мысал: 2,24 л (қ.ж.) аммиак алу үшін шығым 80% болса, қанша грамм аммоний хлориді керек? 2NH₄Cl + Ca(OH)₂ → CaCl₂ + 2NH₃↑ + 2H₂O. V(теор.) = 2,24 / 0,8 = 2,8 л; n(NH₃) = 0,125 моль; n(NH₄Cl) = 0,125 моль; m = 0,125 · 53,5 ≈ 6,69 г.

Мысал: 98 г H₂SO₄ мырышпен әрекеттескенде 20 л (қ.ж.) сутек алынды. Көлемдік шығым: V(теор.) = 22,4 л; η = 20 / 22,4 ≈ 89,3%.

## №10 зертханалық жұмыс. Хлорсутек қышқылы ерітіндісінің қасиеттерін оқып-үйрену (9-сынып 2-бөлім, 66-б.)

Үш сынауыққа 2 мл-ден тұз қышқылы құйылады.
1-сынауық: лакмус тамызылады (қызарады), содан кейін калий гидроксиді қосылады — бейтараптану жүріп, түс күлгінге, сілті артық болса көкке өзгереді: HCl + KOH → KCl + H₂O; H⁺ + OH⁻ → H₂O.
2-сынауық: мырыш түйіршігі салынады — сутек көпіршіктері бөлінеді: Zn + 2HCl → ZnCl₂ + H₂↑; Zn + 2H⁺ → Zn²⁺ + H₂↑.
3-сынауық: магний оксиді салынады — ол ериді: MgO + 2HCl → MgCl₂ + H₂O; MgO + 2H⁺ → Mg²⁺ + H₂O.

Қорытынды: тұз қышқылы қышқылдардың барлық ортақ қасиеттерін көрсетеді; олар ерітіндідегі H⁺ иондарымен байланысты.

## №5 практикалық жұмыс. Сұйылтылған күкірт қышқылының химиялық қасиеттерін оқып-үйрену (9-сынып 2-бөлім, 67-б.)

1-тәжірибе: күкірт қышқылы бар екі сынауықтың біріне мырыш, екіншісіне мыс салынады. Мырышта сутек бөлінеді (Zn + H₂SO₄ → ZnSO₄ + H₂↑ — ТТР: Zn⁰ − 2e⁻ → Zn⁺², 2H⁺ + 2e⁻ → H₂⁰), мыс сұйылтылған қышқылмен әрекеттеспейді.
2-тәжірибе: қара мыс(II) оксидіне қышқыл құйып, қыздырғанда көк ерітінді түзіледі: CuO + H₂SO₄ → CuSO₄ + H₂O; CuO + 2H⁺ → Cu²⁺ + H₂O.
3-тәжірибе: фенолфталеин тамызылған сілтіге түсі жойылғанша қышқыл тамызу — бейтараптану: 2NaOH + H₂SO₄ → Na₂SO₄ + 2H₂O.
4-тәжірибе: мыс сульфаты мен сілтіден Cu(OH)₂ көк тұнбасын алып, оны күкірт қышқылында еріту: Cu(OH)₂ + H₂SO₄ → CuSO₄ + 2H₂O.
5-тәжірибе: күкірт қышқылына барий хлоридін қосу — ақ тұнба: H₂SO₄ + BaCl₂ → BaSO₄↓ + 2HCl; Ba²⁺ + SO₄²⁻ → BaSO₄↓ (сульфат ионына сапалық реакция).
