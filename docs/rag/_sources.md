# RAG білім қоры: дереккөздер және файлдар картасы

Бұл файл `_` таңбасынан басталғандықтан, `npm run rag` оны жүктемейді. Ол мұғалімге арналған анықтама.

## Дереккөздер

1. Оспанова М.Қ., Аухадиева Қ.С., Белоусова Т.Г. Химия: жалпы білім беретін мектептің 8-сыныбына арналған оқулық. — Алматы: Мектеп, 2018.
2. Оспанова М.Қ., Аухадиева Қ.С., Белоусова Т.Г. Химия: 9-сынып, 1-бөлім. — Алматы: Мектеп, 2019.
3. Оспанова М.Қ., Аухадиева Қ.С., Белоусова Т.Г. Химия: 9-сынып, 2-бөлім. — Алматы: Мектеп, 2019.

Маңызды: файлдардағы мәтіндер оқулықтардан көшірілмеген. Олар оқулықтардың құрылымы (тараулар, параграфтар, зертханалық және практикалық жұмыстар) бойынша өз сөзімізбен жазылған қысқаша конспектілер. Мысал-есептер де өзіміз құрастырған. Әр бөлімнің тақырыбында параграф нөмірі мен оқулықтағы бет көрсетілген, сондықтан AI-көмекшінің жауабынан кейін оқушы оқулықтың тиісті бетін ашып, толық мәтінді оқи алады.

## Пішім

- Барлық файл UTF-8, `.md`, атаулары латынша. Тілі — қазақша (атауында `.ru` немесе `.en` жоқ).
- Әр файл бір тарау: `# ...` — тарау атауы, `## §N ...` — параграф. Абзацтар бос жолмен бөлінген, бір абзац 1000 таңбадан аспайды, сондықтан әр бөлім бірнеше үзіндіге дұрыс бөлінеді.
- Барлығы 26 файл, шамамен 200 000 таңба (≈ 350 үзінді).

## Мұғалімге ұсыныс

1. Жүктемес бұрын мәтіндерді оқып шығыңыз. Қажет болса түзетіп, өз мысалдарыңызды қосыңыз.
2. Файлды өзгерткен соң `npm run rag` командасын қайта іске қосыңыз.
3. Жаңа тақырып қосқыңыз келсе, осы үлгімен жаңа файл ашыңыз: `# Тарау`, содан кейін `## Тақырып (оқулық, бет)`, абзацтар арасы — бос жол.
